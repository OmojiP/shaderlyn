• For a Unity project, open the project root (the folder that contains Assets and ProjectSettings). Package headers are resolved automatically.
  • Unreal Engine .usf and .ush files are analyzed as Unreal Engine without any configuration. To resolve engine headers (/Engine/...), set the engine location (unreal: engine) in .shaderlyn.yaml.
  • For other environments (plain HLSL and so on), set environment in .shaderlyn.yaml (environments).
  • Rule severities are configured in .shaderlyn.yaml (configuration).
  • Plugin settings are under Settings > Tools > Shaderlyn.
