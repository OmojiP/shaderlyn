# SL1011: タグの値が不正です

分類: Correctness / 既定の重要度: 警告

## 何を検出するか

既知のタグに、そのタグが受け付けない値が指定されている箇所です。

| タグ                               | 受け付ける値                                                                                                              |
| ---------------------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| `Queue`                            | `Background` / `Geometry` / `AlphaTest` / `Transparent` / `Overlay`、数値オフセット可 (`Transparent+100`)、純粋な数値も可 |
| `IgnoreProjector` ほかの真偽値タグ | `True` / `False`                                                                                                          |
| `DisableBatching`                  | `True` / `False` / `LODFading`                                                                                            |
| `PreviewType`                      | `Sphere` / `Plane` / `Skybox`                                                                                             |

## なぜ問題か

Unity は不正なタグ値をエラーにせず、既定値で動作させます。
たとえば `"Queue" = "Transparnt"` と書いた場合、
描画キューは既定の Geometry のままになり、
半透明オブジェクトが不透明として描画されます。

## どう直すか

上の表にある値を指定してください。

## 誤検出だと思ったら

`RenderType` と `LightMode` の値はこのルールでは検証していません。
`RenderType` は `Camera.RenderWithShader` による置き換え用に
プロジェクトが自由な値を使えるためです。
`LightMode` の妥当な値はレンダーパイプラインごとに異なるため、
RP プロファイルを持つルールの領分としています。
