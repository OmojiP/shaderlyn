# SG0362: 実験中のモジュールを import するには、実験中の機能を有効にしてください

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

Slang のファイルで、実験中のモジュールを import している状態です。slangc は `-experimental-feature` を渡さない場合は、そのモジュールを読み込まず、コンパイルの誤り (E00104) にします。

```slang
import slang.neural;         // 実験中のモジュール
import slang.numerics;
import slang.functional;
import experimental.workgraph;
```

実験中のモジュールは、`slang.neural`・`slang.numerics`・`slang.functional` (とその中のモジュール) と、`experimental.` で始まるモジュールです。

## なぜ問題か

`-experimental-feature` を渡さない slangc では、そのモジュールを使用するファイルをコンパイルできません。

## どう直すか

slangc に `-experimental-feature` を渡してコンパイルする場合は、設定ファイルの [`slang: experimental-features`](../guide/configuration.md#slang) を `true` にしてください。この報告をしなくなります。

```yaml
slang:
  experimental-features: true
```

渡さない場合は、実験中のモジュールを使用しない書き方にしてください。
