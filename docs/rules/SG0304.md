# SG0304: 属性の値が正しくありません

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

Slang のファイルで、属性に使用できない値を書いている状態です。slangc はコンパイルの誤り (E31102・E31103・E31123・E31209 など) にします。

```slang
[numthreads(0, 1, 1)]             // 1 より小さい値
[WaveSize(5)]                     // 4 から 128 までの 2 の累乗でない
void main() { }

[COM("not-a-valid-guid")]         // GUID でない (- を除いて 16 進数 32 桁)
interface IFoo { void f(); }

[RemovedSince(10000, "old")]      // バージョンが -1 から 9999 の外
void old() { }
```

`[DerivativeGroupLinear]` の `[numthreads]` はスレッドの数の積が 4 の倍数、`[DerivativeGroupQuad]` の `[numthreads]` は x と y が 2 の倍数でなければなりません (E31211・E31210)。

`[WaveSize]` は、最初の値だけを見ます (slangc と同じ)。値をマクロや式で書いたものは見ません。

`[shader("…")]` のステージの名前が存在しないもの (`[shader("invalid")]`) も報告します (E36105)。`_` を含む名前 (`ser_motion_raygen` など、ステージを含む能力の名前) は見ません。

レイペイロード (`[raypayload]`) のフィールドのアクセス修飾子 (`: read(caller) : write(closesthit)`) に、`anyhit`・`closesthit`・`miss`・`caller` でないステージ名を書いたもの (`read(anyht)`) も報告します (E40001)。

関数の外の宣言とエントリポイントの仮引数の `ParameterBlock<T>` の `[[vk::binding(b, s)]]` の b が 0 でないものも報告します (E39015)。`ParameterBlock` は記述子のセットを丸ごと使用します。

利用者が定義した属性 (`[__AttributeUsage(…)]` を書いた `struct …Attribute`) の実引数も見ます。
実引数は static でないフィールドに順に入るので、初期値が存在しないフィールドより少ないもの (E31001) と、フィールドより多いもの (E39999) を報告します。
数のフィールドに文字列を書いたものと、`String` のフィールドに文字列でないリテラルを書いたものも報告します (E30019)。

```slang
[__AttributeUsage(_AttributeTargets.Struct)]
struct MyStructAttribute { int iParam; float fParam; };

[MyStruct(0)]                     // 実引数が足りない
[MyStruct(0, "stringVal")]        // float のフィールドに文字列
struct A { float x; };
```

## なぜ問題か

slangc がコンパイルできません。

## 修正方法

`[numthreads]` には 1 以上の数を、`[WaveSize]` には 4・8・16・32・64・128 のどれかを書いてください。
`[COM]` の GUID は、16 進数 32 桁で書きます (`"00000000-0000-0000-0000-000000000001"`)。
