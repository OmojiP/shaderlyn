# HL0349: ベクトルに使用できない演算子です (HLSL 2021)

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

HLSL 2021 でコンパイルされるコードで、ベクトルや行列に `&&` / `||` を使っている式と、条件がベクトルの条件演算子 (`?:`) です。

```hlsl
float3 a, b;
bool3 x = a && b;          // 報告する。and(a, b) と書く
bool3 y = a || b;          // 報告する。or(a, b) と書く
float3 z = a > 0 ? a : b;  // 報告する。select(a > 0, a, b) と書く
bool n = a.x > 0 && b.x;   // 正しい。スカラー
```

1 成分のベクトル (`float1`) と行列も報告します。DXC 1.8 (`-HV 2021`) で確かめました。

## なぜ問題か

HLSL 2021 の `&&` / `||` / `?:` は C++ と同じく短絡評価になり、ベクトルには使用できません。コンパイルに失敗します
(`operands for short-circuiting logical binary operator must be scalar, for non-scalar types use 'and'`)。

FXC と DXC 2021 より前は、ベクトルに使うと成分ごとに計算します。2021 へ移すときに引っかかる書き方です。

## どう直すか

成分ごとに計算するなら `and()` / `or()` / `select()` を使ってください (DXC の組み込み関数)。

```hlsl
bool3 x = and(a, b);
float3 z = select(a > 0, a, b);
```

## 環境による違い

コードをコンパイルする方言がどれも HLSL 2021 のときだけ報告します (汎用の HLSL の既定)。
Unity (FXC と DXC の HLSL 2018) では報告しません。
