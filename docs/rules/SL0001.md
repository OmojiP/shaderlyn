# SL0001: 構文エラー

分類: Syntax / 既定の重要度: エラー

## 何を検出するか

ShaderLab の構文として解釈できない記述です。

## なぜ問題か

Unity のシェーダーコンパイラもこの箇所で失敗するため、シェーダーは動作しません。
また、構文が壊れた箇所より後の解析結果は信頼できません。
パーサはエラーからの回復を試みますが、回復の仕方によっては
本来の意図とは異なる構造として解釈される可能性があります。

## どう直すか

メッセージが示す位置で、何が期待されていたかを確認してください。
よくある原因は次のとおりです。

- 波括弧・丸括弧・角括弧の対応が取れていない
- プロパティ宣言の書式ミス (`_Name ("表示名", 型) = 既定値` の形になっていない)
- 文字列の閉じ忘れ
- `CGPROGRAM` に対する `ENDCG` の書き忘れ

## 誤検出だと思ったら

このルールが誤検出を出す場合、それはパーサの不具合です。
対象ファイルを添えて不具合として報告してください。
