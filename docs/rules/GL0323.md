# GL0323: 関数の宣言どうしが食い違っています

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

GLSL のファイルで、仮引数の型が同じ関数を 2 度宣言し (プロトタイプと定義など)、次のどれかが前の宣言と違うものです。

- 仮引数の記憶域 (`in`・`const in`・`out`・`inout`。何も書かなければ `in`)
- 仮引数の精度の修飾子 (`highp`・`mediump`・`lowp`。ES で、両方に書いたときだけ比べます)
- 戻り値の型

関数の属性 (`GL_EXT_function_control_attributes` の `[[inline]]` と `[[noinline]]`) は前の宣言の分と合わせ、両方があれば報告します (`[[inline, noinline]]` と書いたものも)。

```glsl
#version 450
layout(location = 0) out vec4 color;

float shade(in float x);
float shade(out float x)    // 記憶域が前の宣言 (in) と違う
{
    x = 1.0;
    return x;
}

int shade(float x);         // 仮引数が同じなのに戻り値の型が違う

void main()
{
    float v;
    color = vec4(shade(v));
}
```

## なぜ問題か

GLSL は仮引数の型だけで関数を区別します。修飾子や戻り値の型だけが違う宣言は別の関数 (多重定義) にならず、同じ関数の食い違った宣言になります。
glslang (Vulkan の SDK の `glslangValidator` と `glslc`) がコンパイルを止めます。

## どう直すか

プロトタイプと定義の修飾子と戻り値の型をそろえてください。別の関数にしたいなら、名前か仮引数の型を変えてください。
