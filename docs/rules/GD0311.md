# GD0311: 条件が bool ではありません

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

Godot シェーダー言語のファイルで、`if`・`while`・`do`・`for`・`?:` の条件に、`bool` でない値を書いている状態です。Godot はコンパイルの誤りにします。

```glsl
shader_type spatial;

void fragment() {
    int count = 1;
    if (count) {          // int は条件にならない
        ALBEDO = vec3(1.0);
    }
}
```

Godot シェーダー言語は、整数や浮動小数点数を `bool` へ暗黙に変換しません。`bvec2` などのベクトルも条件になりません。

条件の型が分からないとき (構成によって型が変わるときを含む) は検査しません。

## なぜ問題か

Godot がシェーダーをコンパイルできず、マテリアルが描画されません。

## どう直すか

比べる式にしてください。ベクトルは `any()` か `all()` で 1 つの `bool` にします。

```glsl
if (count != 0) {
    ALBEDO = vec3(1.0);
}
```
