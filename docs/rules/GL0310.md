# GL0310: writeonly の値を読んでいます

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

GLSL のファイルで、`writeonly` を付けた buffer のブロック (かそのメンバー) の値を読んでいる状態です。glslang はコンパイルの誤りにします。

```glsl
#version 450
layout(local_size_x = 64) in;

layout(binding = 0) writeonly buffer Output { float values[]; } outputs;

void main()
{
    uint i = gl_GlobalInvocationID.x;
    outputs.values[i] = 1.0;                  // 書き込みは良い
    outputs.values[i] = outputs.values[i] * 2.0;   // 読めない
}
```

glslang が読み取りを検査する所と同じ、次の所を見ます。

- 演算子の項 (`+`、`==`、`~`、`++` など)
- 代入の右辺と初期化子
- `?:` の条件と 2 つの枝
- 値の作成 (`vec3(…)`) の実引数

## なぜ問題か

glslang (Vulkan の SDK の `glslangValidator` と `glslc`) がコンパイルを止めます。`writeonly` のメモリは、シェーダーから読めません。

## どう直すか

値を局所変数に持って計算し、最後に書き込んでください。読む必要があるなら、`writeonly` を外してください。

```glsl
float value = compute(i);
outputs.values[i] = value * 2.0;
```
