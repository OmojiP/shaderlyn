# SL0005: 解析の対象外のコードブロックです

分類: Usage / 既定の重要度: 情報

## 何を検出するか

`GLSLPROGRAM` / `GLSLINCLUDE` のブロックです。

```
Pass
{
    GLSLPROGRAM      // ← ここを報告する
    ...
    ENDGLSL
}
```

## なぜ報告するのか

このツールは GLSL を解析しません。ブロックの中は構文の誤りも、プロパティとの対応も検査していません。

何も伝えないと、検査して問題が無かったのと区別が付きません。

## 解析しないファイル

次のファイルも解析しません。フォルダーを指定したときに見つかれば件数を、
直接指定したときはそのファイルを、標準エラーに「現在解析の対象外です」と出します。

| 拡張子 | 内容 |
| --- | --- |
| `.shadergraph` / `.shadersubgraph` | Shader Graph のグラフ |
| `.raytrace` | レイトレーシングシェーダー |
