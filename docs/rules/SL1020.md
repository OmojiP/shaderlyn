# SL1020: 半透明描画で深度書き込みが有効になっています

分類: Correctness / 既定の重要度: 警告

## 何を検出するか

描画キューが `Transparent` 系で、かつブレンドが有効で、かつ `ZWrite` が `On` である Pass です。

## なぜ問題か

`ZWrite` の既定値は `On` です。
半透明シェーダーで `ZWrite Off` を書き忘れると、
半透明オブジェクトが深度バッファへ書き込みます。
すると後ろにある半透明オブジェクトが深度テストで捨てられ、
見え方が描画順とカメラ位置に依存して破綻します。

開発中の特定の視点では正しく見えるのに、
別の角度から見ると背後のオブジェクトが消えるという形で現れるため、
気づくのが遅れがちな不具合です。

## どう直すか

```shaderlab
SubShader {
    Tags { "Queue" = "Transparent" }
    Blend SrcAlpha OneMinusSrcAlpha
    ZWrite Off        // これを追加する
    Pass { ... }
}
```

## 誤検出だと思ったら

意図的に深度を書き込む設計 (半透明だが深度も必要な特殊効果) の場合があります。
その場合はこの指摘を無視してください。

なお、次の場合は報告しません。

- `ZWrite [_ZWrite]` のようにプロパティで切り替えている場合
  (実際の値はマテリアル側で決まるため静的には判断できません)
- `Blend Off` でブレンドが無効な場合
- Pass 側で `ZWrite Off` を指定して SubShader 側の設定を上書きしている場合
