# SL1030: プロパティ名がアンダースコアで始まっていません

分類: Naming / 既定の重要度: 警告

## 何を検出するか

`Properties` ブロックで宣言されたプロパティ名が `_` で始まっていない箇所です。

## なぜ問題か

Unity のシェーダープロパティはアンダースコア始まりにするのが慣習です。
これに従わないと次の問題があります。

- HLSL 側の組み込み変数や関数名と衝突する危険がある
- プロジェクト内でプロパティを機械的に探す仕組み (命名規約に依存するツール) から漏れる

## どう直すか

```shaderlab
Properties {
    _MainTex ("Main", 2D) = "white" {}   // MainTex ではなく _MainTex
}
```

HLSL 側の uniform 宣言も同時に変更する必要があります。

## 誤検出だと思ったら

このルールはアンダースコア始まりのみを検査し、
それ以降の綴り方 (PascalCase かどうかなど) は検査しません。
適切な綴り方はプロジェクトごとに異なるため、
設定ファイルで宣言するユーザー定義ルールの領分としています。
