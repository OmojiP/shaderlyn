# GL0302: 組み込み関数に合う形がありません

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

GLSL のファイルで、組み込み関数を、どの多重定義にも合わない型の実引数で呼んでいる状態です。glslang はコンパイルの誤りにします。

```glsl
#version 450
layout(location = 0) out vec4 color;
layout(binding = 0) uniform sampler2D tex;

void main()
{
    color = texture(tex, vec3(0.5));      // sampler2D の texture の座標は vec2
    color += vec4(textureSize(tex));      // sampler2D の textureSize には詳細度 (int) も要る
}
```

glslang と同じく、次の順に探します。

1. 実引数の型と同じ仮引数を持つ形
2. 無ければ、暗黙の変換で合う形 (`int` を `float` の仮引数へ、など)。変換できるかは `#version` と有効にした拡張で決まり、
   ES の 3.10 より前とデスクトップの 1.10 では変換しません

組み込み関数の多重定義は、glslang 16.6.0 の表を、ファイルのステージと `#version` で絞ったものです。

## なぜ問題か

glslang (Vulkan の SDK の `glslangValidator` と `glslc`) がコンパイルを止めます。

## どう直すか

実引数の型を、関数の形に合わせてください (`texture(tex, uv.xy)`、`textureSize(tex, 0)` など)。

## 誤検出だと思ったら

次のときは検査しません。

- 実引数の型が分からないとき、構成によって変わるとき、配列のとき
- 型の引数を取る型 (`coopmat<…>`、`vector<…>` など) や、レイトレーシングの `hitObjectNV` などの、表から型を読み取れない仮引数を持つ関数
- 引数の数が合う形が 1 つも無いとき ([CF0402](CF0402.md) が報告します)
- 利用者が同じ名前の関数を宣言しているとき
