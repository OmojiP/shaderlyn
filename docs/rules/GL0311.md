# GL0311: 条件が bool ではありません

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

GLSL のファイルで、`if`・`while`・`do`・`for`・`?:` の条件に、`bool` のスカラーでない値を書いている状態です。glslang はコンパイルの誤りにします。

```glsl
#version 450
layout(location = 0) flat in int count;
layout(location = 0) out vec4 color;

void main()
{
    color = vec4(0.0);
    if (count)            // int は条件にならない
        color = vec4(1.0);
}
```

C や HLSL と違い、GLSL は整数や浮動小数点数を `bool` へ暗黙に変換しません。`bvec2` などのベクトルも条件になりません。

条件の型が分からないとき (構成によって型が変わるときを含む) は検査しません。

## なぜ問題か

glslang (Vulkan の SDK の `glslangValidator` と `glslc`) がコンパイルを止めます。

## どう直すか

比べる式にしてください。ベクトルは `any()` か `all()` で 1 つの `bool` にします。

```glsl
if (count != 0)
    color = vec4(1.0);

if (any(lessThan(v, vec2(0.0))))
    discard;
```
