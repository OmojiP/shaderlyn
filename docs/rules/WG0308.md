# WG0308: 配列の大きさが正しくありません

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

WGSL のファイルで、`array<T, N>` の `N` が 0 以下か、整数 (i32 か u32) でない定数式の状態です。naga はコンパイルの誤りにします。

```wgsl
const length: f32 = 2.718;
alias A = array<f32, 0>;       // 1 以上
alias B = array<f32, -1>;
alias C = array<f32, length>;  // 整数の定数式
alias D = array<f32, true>;
```

## なぜ問題か

シェーダーモジュールを作れず、パイプラインが作られません。

## 修正方法

大きさを 1 以上の整数にしてください。大きさを決めない配列 (`array<f32>`) は、ストレージのバッファーの最後のメンバーにだけ書けます。
