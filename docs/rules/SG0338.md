# SG0338: 戻り値を使わなければならない関数です

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

Slang のファイルで、`[NoDiscard]` を書いた関数・メソッドの戻り値を捨てている状態です。slangc はコンパイルの誤り (E30059) にします。

```slang
struct Texture
{
    [NoDiscard]
    float4 load() { return float4(0); }
}

void f(Texture t, bool cond)
{
    t.load();                              // 文として呼んで捨てている
    for (int i = 0; i < 1; t.load()) { }   // for の更新の式も捨てる
    cond && t.load().x > 0;                // && の右も捨てる
    let v = t.load();                      // 受けて使うのはよい
}
```

捨てたものとするのは、文として書いた呼び出し、`for` の更新の式と、それが括弧・`?:` の枝・`&&` と `||` の右・`,` の両側にあるものです。

## なぜ問題か

`[NoDiscard]` は、戻り値を使わない呼び出しが誤りであることを示す印です。slangc がコンパイルできません。

## どう直すか

戻り値を使ってください。

## 誤検出だと思ったら

同じ名前の関数 (多重定義) のどれかが `[NoDiscard]` でなければ検査しません。
