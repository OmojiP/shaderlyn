# WG0403: その宣言には使用できない型です

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

WGSL のファイルで、その場所には使用できない型を使用している状態です。naga はコンパイルの誤りにします。

```wgsl
struct Bad { data: texture_2d<f32> }             // 構造体のメンバーはデータの型だけ
struct Unsized { data: array<f32>, other: f32 }  // 大きさを決めない配列は最後のメンバーだけ
alias A = array<sampler, 4>;                     // 配列の要素もデータの型だけ
var input: u64;                                  // アドレス空間を書かない var は資源の型だけ
var<workgroup> w: u32 = 0u;                      // var<workgroup> に初期値は書けない

fn f(arg: ptr<storage, array<f32>>) { }          // 仮引数のポインターは function か private
fn g() {
    var x: atomic<u32>;                          // 局所の var にアトミックは置けない
    let y = array<u32>(0, 1, 2);                 // 大きさを決めない配列の値は作れない
}
```

今は次のものを検査します。

- 構造体のメンバー: 資源の型 (テクスチャ・サンプラー)、最後でないメンバーの大きさを決めない配列、大きさを決めない配列を含む構造体
- 配列の要素: 資源の型、大きさを決めない配列 (を含む型)。`binding_array` の `texture_external`
- 局所の `var`: ポインター・資源・アトミック・大きさを決めない配列を含む型。`let` と `const` の、`override` で大きさを決める配列
- 関数の仮引数: function・private 以外のポインター、大きさを決めない配列を含む型
- 関数の戻り値: ポインター・資源・アトミック・大きさを決めない配列を含む型
- 関数の外の `var`: アドレス空間を書かない数の型、private・function・workgroup の `binding_array`、storage と uniform の構造体でない `binding_array` の要素、
  `var<immediate>` の 16 ビットの型 (f16・i16・u16)、storage 以外の大きさを決めない配列、workgroup・storage・uniform・immediate の初期値
- 値の作成: 大きさを決めない配列、`override` で大きさを決める配列、アトミック、それを含む構造体

## なぜ問題か

シェーダーモジュールを作れず、パイプラインが作られません。

## どう直すか

その場所で使用できる型にしてください。資源の型は、関数の外の `var` (アドレス空間を書かない) にだけ置けます。
大きさを決めない配列は、`var<storage>` の変数か、その構造体の最後のメンバーにだけ置けます。
