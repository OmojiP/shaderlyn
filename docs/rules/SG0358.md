# SG0358: ジェネリックの仮引数の書き方が正しくありません

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

Slang のジェネリックの仮引数を、正しくない形で書いている状態です。slangc はコンパイルの誤り (E30624・E30625・E30401・E30117・E30855・E30408) にします。

```slang
void a<let N>() { }                        // 値の仮引数に型が無い
void b<let F : float>() { }                // 値の仮引数の型は整数・列挙型・bool
struct C<D : int> { }                      // 制約に int (値の仮引数なら let D : int)
struct Foo { }
void d<T : Foo>(T x) { }                   // 制約に構造体 (インターフェイスを書く)
interface IFloat { }
interface IFoo<T : IFloat> { }
void e<Foo : IFoo<T>, T : IFloat>() { }    // 制約が後ろの仮引数 T を指す
extension<T> int { }                       // T が拡張する型に出てこない
Buffer b0;                                 // 型引数の要るジェネリックの型
```

型引数の要るジェネリックの型は、`Buffer`・`Tuple` と、既定の型引数の無い利用者のジェネリックの型です。
extension の型の仮引数は、拡張する型に出てくる仮引数の制約の中に出てくれば決まります (`extension<T, U : IBuf<T>> U`)。

## なぜ問題か

slangc がコンパイルできません。

## どう直すか

値の仮引数は `let N : int` と書き、制約にはインターフェイスを書いてください。仮引数は、使うものより前に宣言してください。
