# GD0334: サンプラーの仮引数に設定の違うテクスチャを渡しています

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

Godot シェーダー言語のファイルで、利用者の関数の同じサンプラーの仮引数に、設定の違うテクスチャを渡している状態です。Godot はコンパイルの誤りにします。

```glsl
shader_type canvas_item;

uniform sampler2D a : filter_linear;
uniform sampler2D b : filter_nearest;

vec4 f(sampler2D s) { return texture(s, UV); }

void fragment() {
    COLOR = f(a) + f(b);      // フィルターが違う
    COLOR += f(TEXTURE);      // uniform と組み込みのテクスチャを混ぜている
}
```

Godot は、サンプラーの仮引数ごとに、最初に渡した uniform のフィルター (`filter_*`)・繰り返し (`repeat_*`)・ヒント
(`hint_screen_texture`・`hint_depth_texture`・`hint_normal_roughness_texture`) か、組み込みのテクスチャの名前を覚え、ほかのものを渡すと誤りにします。
仮引数をそのまま別の関数に渡したものは、渡した先の仮引数でも比較します。

`sky` の `RADIANCE` は、利用者の関数に渡せません。

## なぜ問題か

Godot がシェーダーをコンパイルできず、マテリアルが描画されません。Godot はサンプラーの設定を関数ごとに 1 つに決めてコードを作ります。

## 修正方法

設定ごとに関数を分けるか、関数の外でサンプリングして、結果の値を渡してください。

## 誤検出だと思ったら

同じ名前の関数が多重定義されているときは、名前の最初の関数の仮引数で比較します。
