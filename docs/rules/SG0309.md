# SG0309: 書き込めない値です

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

Slang のファイルで、`[mutating]` を付けていない構造体 (かクラス) のメソッドの中で、自分のフィールドに書き込んでいる状態です。
代入は「left of '=' is not an l-value」(E30011)、`++` / `--` と複合代入は「argument must be l-value」(E30047) として、slangc はコンパイルの誤りにします。

```slang
struct Sphere
{
    float3 center;
    float radius;
    RWStructuredBuffer<float> buf;

    void setCenter(float3 v) { center = v; }           // 報告する
    void grow() { this.radius += 1; }                  // 報告する
    [mutating] void setRadius(float r) { radius = r; } // 正しい
    __init() { radius = 0; }                           // 正しい。__init は自分を作る
    void write(float x) { buf[0] = x; }                // 正しい。資源の中身は自分ではない
}
```

## なぜ問題か

Slang のメソッドは、既定では自分 (`this`) を読むだけです。書き換えるメソッドは `[mutating]` で示し、書き換えてよい値 (変数) に対してだけ呼べます。

## どう直すか

メソッドに `[mutating]` を付けてください。自分を変えずに結果を返すなら、新しい値を返すメソッドにしてください。

## 見ないもの

`static` のメソッドとフィールド、ポインターのフィールドの先 (`*p = x`)、資源の要素 (`buf[0] = x`) は見ません。
添字の後ろのメンバー (`items[0].v = x`) と、構造体のフィールドをたどった先が数でない書き込みは見ません。
