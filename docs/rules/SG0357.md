# SG0357: 配列の大きさが正しくありません

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

Slang のファイルで、配列の大きさの式が 0 で割っているか、配列の大きさを負の数にしている状態です。slangc はコンパイルの誤り (E30002・E30025) にします。

```slang
void f()
{
    int a[1 / 0];                  // 0 での割り算
}

func bar() -> int[-1];             // 負の大きさ
```

大きさを数のリテラルで書いたものを見ます。ジェネリックの値の仮引数 (`int a[N / M]`) は、型引数で決まるので見ません。

## なぜ問題か

配列の大きさが決まりません。

## 修正方法

配列の大きさを 1 以上の数にしてください。
