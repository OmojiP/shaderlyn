# SG0401: その宣言にはアクセスできません

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

Slang のファイルで、構造体の `private` のメンバーを、その構造体の外から使っている状態です。slangc はコンパイルの誤り (E30600) にします。

```slang
struct MyType
{
    private int member;
    private int func() { return member; }
    int func1() { return member; }     // 構造体の中からは使える
}

void test()
{
    MyType t;
    t.func1();                         // public のメソッドは使える
    t.func();                          // private のメソッドは使えない
    t.member = 2;                      // private のフィールドも使えない
}
```

`private` のメンバーは、その構造体と、その中に定義した構造体の中でだけ使えます。

## なぜ問題か

slangc がコンパイルできません。

## どう直すか

メンバーを `public` (か `internal`) にするか、構造体の中の public のメソッドを通して使ってください。

## 誤検出だと思ったら

モジュールをまたぐ `internal` と、言語のバージョンで変わる既定の可視性はまだ検査しません。
