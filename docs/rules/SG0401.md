# SG0401: その宣言にはアクセスできません

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

Slang のファイルで、構造体の `private` のメンバーをその構造体の外から使用しているか、`import` した別のモジュールの public でない宣言を使用している状態です。slangc はコンパイルの誤り (E30600) にします。

```slang
struct MyType
{
    private int member;
    private int func() { return member; }
    int func1() { return member; }     // 構造体の中からは使用できる
}

void test()
{
    MyType t;
    t.func1();                         // public のメソッドは使用できる
    t.func();                          // private のメソッドは使用できない
    t.member = 2;                      // private のフィールドも使用できない
}
```

`private` のメンバーは、その構造体と、その中に定義した構造体の中でだけ使用できます。

## 別のモジュールの宣言

関数の外の宣言 (関数・構造体・列挙型・変数) は、`public` を書かなければ internal で、宣言したモジュールの中でだけ使用できます。
`public` の構造体のメンバーの既定は、宣言したモジュールの言語のバージョンで決まります。2025 (既定) の場合は internal、2026 (`#language slang 2026`) の場合は public です。

```slang
// lib.slang
module lib;
public struct P { int x; public int y; }
int helper() { return 1; }

// main.slang
import lib;
int test(P p)
{
    return p.y        // 使用できる
         + p.x        // 報告する。2025 の言語では、public の構造体のメンバーも internal が既定
         + helper();  // 報告する。public でない関数
}
```

`module` の宣言も可視性の修飾子も存在しないファイルは、古い書き方のモジュールとして、すべての宣言を public とみなします (slangc と同じ)。

public の構造体の中に定義した構造体と列挙型 (`PublicOuter.Inner`) も、メンバーと同じ既定に従います。`internal` か `private` を書いたものは、2026 の言語でも使用できません。public の名前空間のメンバー (`Space.value`) は、`public` を書かなければ internal です。

```slang
// outer.slang
#language slang 2026
module outer;
public struct PublicOuter
{
    struct Inner { int a; }          // public (public の構造体の中で、2026 の言語)
    internal enum Hidden { A, B }
}
public namespace Space
{
    static int internalVar;
}

// user.slang
import outer;
void test(PublicOuter.Inner inner)  // 使用できる
{
    PublicOuter.Hidden h;            // 報告する
    Space.internalVar = 1;           // 報告する
}
```

## なぜ問題か

slangc がコンパイルできません。

## どう直すか

宣言かメンバーを `public` にするか (同じモジュールの中だけで使用する場合は `internal` でもかまいません)、構造体の中の public のメソッドを経由して使用してください。

## 誤検出だと思ったら

`implementing` と `__include` で複数のファイルに分けたモジュールは、どのファイルが同じモジュールかをまだ決めないので、モジュールをまたぐ検査をしません。
