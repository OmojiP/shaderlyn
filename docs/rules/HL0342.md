# HL0342: out の引数に書き戻せません

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

`out` / `inout` の仮引数に、書き戻す先が無い式を渡している状態です。

```hlsl
void split(float2 uv, out float3 rgb) { rgb = float3(uv, 0); }

float3 got;
split(uv, got);                // 正しい
split(uv, float3(0, 0, 0));    // 書き戻す先が無い
split(uv, a + b);              // 演算の結果にも書き戻せない
```

## なぜ問題か

`out` / `inout` の仮引数は、呼び出し側の変数へ値を書き戻します。
リテラル、関数の戻り値、演算の結果には書き戻す先がありません。

コンパイルに失敗します。

## どう直すか

いったん変数へ受けてから渡してください。

```hlsl
float3 got;
split(uv, got);
```

## 誤検出だと思ったら

このルールは、書き戻せないと言い切れる形だけを報告します。

- リテラル
- 関数の呼び出しの結果
- 二項演算の結果
- キャストの結果
- 三項演算子の結果

それ以外は分からないものとして扱い、何も言いません。

宣言が 1 つも見えていない関数は対象外です。
