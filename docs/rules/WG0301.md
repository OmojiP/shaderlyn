# WG0301: この型には演算子を使えません

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

WGSL のファイルで、`&&` と `||` を bool のスカラーでない値に使っている状態です。naga はコンパイルの誤りにします。

```wgsl
fn f(a: vec2<bool>, b: vec2<bool>) {
    let y = a && b;   // ベクトルには & を使う
}
```

## なぜ問題か

`&&` と `||` は、右の式を評価するかを左の値で決める (短絡する) ので、1 つの bool にだけ使えます。シェーダーモジュールは作られません。

## どう直すか

成分ごとの論理演算は `&` と `|` で書きます。1 つの bool にまとめるなら `all(a)`・`any(a)` を使います。
