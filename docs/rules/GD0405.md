# GD0405: 組み込みの名前を再宣言できません

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

Godot シェーダー言語のファイルで、組み込みの変数か定数の名前 (`TIME`・`PI`・`ALBEDO` など) で変数・仮引数・関数を宣言しているか、
組み込み関数の名前 (`sin` など) で関数を宣言している状態です。Godot はコンパイルの誤りにします。

```glsl
shader_type spatial;

const float PI = 3.14159;          // 組み込みの定数
uniform float ALBEDO;              // 関数の外の宣言には、どのステージ関数の組み込みの名前も使用できない
float sin(float x) { return x; }   // 組み込み関数の名前の関数
float f(float UV) { return UV; }   // 仮引数も同じ

void fragment() {
    float TIME = 1.0;              // その関数で使用できる組み込みの名前の局所変数
}
```

局所変数は、その関数で使用できる組み込みの名前 (`fragment` の中の `TIME`・`ALBEDO`、利用者の関数の中の `TIME`・`PI`) だけが誤りです。
`vertex` の中の局所変数 `ALBEDO` は書けます。構造体の名前と、関数の外の `const` の名前には、組み込み関数の名前も使用できます。

局所変数が関数の外の `const`・`uniform`・`varying` と同じ名前のときは、[CF0314](CF0314.md) として報告します (Godot は名前の隠しを許しません)。

## なぜ問題か

Godot がシェーダーをコンパイルできず、マテリアルが描画されません。

## 修正方法

名前を変えてください。円周率は組み込みの `PI` をそのまま使用できます。

## 誤検出だと思ったら

`.gdshaderinc` (シェーダーの種類が決まらないファイル) では調べません。
