# HL0302: シェーダーステージが指定されていません

分類: Correctness / 既定の重要度: 警告

## 何を検出するか

`HLSLPROGRAM` / `CGPROGRAM` のブロックに、
どの関数をどのステージとして使うかを指定する `#pragma` が 1 つも無い状態です。

次のいずれかがあれば指定されているとみなします。

`vertex` / `fragment` / `surface` / `kernel` / `raytracing` / `geometry` / `hull` / `domain`

## なぜ問題か

この Pass はコンパイルできません。

よくある経緯は、共通コード片に書いたつもりの `#pragma` が届いていない場合です。

```shaderlab
SubShader
{
    HLSLINCLUDE
    #pragma vertex vert       // この SubShader の Pass にしか届かない
    ENDHLSL

    Pass { HLSLPROGRAM ... ENDHLSL }
}

SubShader
{
    Pass { HLSLPROGRAM ... ENDHLSL }   // 上の #pragma は届いていない
}
```

`HLSLINCLUDE` は、同じブロックの中にある Pass にしか差し込まれません。
`SubShader` をコピーして増やしたときに起きがちです。

## どう直すか

必要な `#pragma` をそのブロックか、そのブロックを含む `HLSLINCLUDE` に書きます。

```hlsl
#pragma vertex vert
#pragma fragment frag
```

## 判定できる範囲

取り込まれる前提の断片 (`.hlsl` / `.cginc` / `.hlslinc`) を単体で解析したときは報告しません。
ステージは取り込む側の `.shader` が決めるためです。
`.compute` は 1 ファイルで完結するので報告します。

## 誤検出だと思ったら

このツールが知らない書き方でステージが決まる場合、
「指定が無い」と誤って報告される可能性があります。
その場合は抑制コメントを使い、あわせて不具合として報告してください。

```hlsl
// shaderlyn-disable-next-line HL0302
```
