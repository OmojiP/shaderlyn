# SL1031: プロパティ属性の引数が不正です

分類: Correctness / 既定の重要度: 警告

## 何を検出するか

既知のプロパティ属性に、必要な引数が渡されていないか、余分な引数が渡されている箇所です。

| 属性                                                | 引数                                      |
| --------------------------------------------------- | ----------------------------------------- |
| `Toggle` / `ToggleOff`                              | 0 個または 1 個 (シンボル名)            |
| `KeywordEnum`                                       | 1〜9 個                                   |
| `Enum`                                              | 列挙型名 1 個、または名前と値の組を偶数個 |
| `PowerSlider`                                       | 1 個                                      |
| `Header`                                            | 1 個                                      |
| `MainTexture` / `MainColor` / `Normal` / `HDR` など | 0 個                                      |

## なぜ問題か

Unity のインスペクタは引数が不正な属性を無視します。
`[KeywordEnum]` を引数なしで書いても警告は出ず、
意図したインスペクタ表示にならないだけです。

## どう直すか

```shaderlab
[KeywordEnum(None, Add, Multiply)] _Blend ("Blend Mode", Float) = 0
[Enum(UnityEngine.Rendering.CullMode)] _Cull ("Cull", Float) = 2
[Enum(Off, 0, On, 1)] _ZWrite ("ZWrite", Float) = 1
```

## 誤検出だと思ったら

未知の属性名は報告しません。
`MaterialPropertyDrawer` を継承したクラスを書けば、
属性はプロジェクトごとに自由に追加できるためです。
