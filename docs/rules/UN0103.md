# UN0103: キーワードの構成が #error に到達します

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

`multi_compile` / `shader_feature` で宣言したキーワードの構成のうち、展開が `#error` に到達するものです。

```hlsl
#pragma multi_compile _ _LEGACY_MODE

#if defined(_LEGACY_MODE)
#error _LEGACY_MODE is no longer supported   // UN0103
#endif
```

```text
Example.shader(13:14): error UN0103: 構成：_LEGACY_MODE は #error (Example.shader の 13 行目) に到達するため、コンパイルに失敗します。
```

## なぜ問題か

Unity は宣言したキーワードの構成をすべてコンパイルします。Unreal Engine の `ShouldCompilePermutation` のように構成を除く仕組みはありません。

Unity 6.6 (FXC、DX12) で確かめた結果は次のとおりです。

- `multi_compile` の構成が到達すると、インポートがエラーになり、キーワードを有効にしていないマテリアルも含めて、シェーダー全体がピンクになる
- `shader_feature` の構成が到達すると、そのキーワードを有効にしたマテリアルがピンクになる
- どちらでも、ビルドは「成功」と表示され、エラーはログにだけ残る

## どう直すか

その構成を使わないなら、キーワードの宣言から外してください。

```hlsl
#pragma multi_compile _ _LEGACY_MODE   // 宣言から外す
```

使うなら、`#error` の条件を見直してください。

## 報告しないもの

- どの構成でも到達するもの。解析のマクロが実際と違うためのことが多いので、[HL0009](HL0009.md) (情報) で伝える
