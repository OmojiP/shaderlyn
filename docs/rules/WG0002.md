# WG0002: このステージでは使えません

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

WGSL のファイルで、そのステージのエントリポイントからは使えない操作を使っている状態です。エントリポイントから呼ぶ関数の中も見ます。naga はコンパイルの誤りにします。

```wgsl
@vertex
fn vs() -> @builtin(position) vec4f {
    if true {
        discard;              // discard はフラグメントシェーダーだけ
    }
    return vec4f();
}

@fragment
fn fs() -> @location(0) vec4f {
    workgroupBarrier();       // 同期は計算シェーダーだけ
    return vec4f();
}
```

| 操作 | 使えるステージ |
| --- | --- |
| `discard`、`dpdx` などの微分、`textureSample`・`textureSampleBias`・`textureSampleCompare` (暗黙の微分) | フラグメント |
| `workgroupBarrier`・`storageBarrier`・`textureBarrier`・`subgroupBarrier`・`workgroupUniformLoad` | 計算 |

## なぜ問題か

シェーダーモジュールを作れず、パイプラインが作られません。

## どう直すか

そのステージで使える書き方にしてください。頂点シェーダーでテクスチャを読むなら、微分の要らない `textureSampleLevel` か `textureLoad` を使います。
