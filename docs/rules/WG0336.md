# WG0336: シフトの量か定数の演算の結果が範囲を超えています

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

WGSL のファイルで、シフトの量 (`<<` と `>>` の右) が左の型のビットの幅以上の定数か、`const` の初期値の演算の結果が型の範囲を超えている状態です。naga はコンパイルの誤りにします。

```wgsl
const a: u32 = 1u >> 32;           // u32 のビットの幅は 32
const b: i32 = 1i << 31;           // i32 に収まらない
const c: u32 = 0xFFFFFFFFu << 1;   // u32 に収まらない
fn f() {
    var x: i32;
    var n = x << 32;               // 実行時の値でも、シフトの量が定数なら誤り
}
```

## なぜ問題か

シェーダーモジュールを作れず、パイプラインが作られません。

## どう直すか

シフトの量を型のビットの幅より小さくしてください。結果が収まらないなら、大きい型 (`u32`、`i64`) にします。

## 誤検出だと思ったら

演算のあふれは、`const` の初期値の中だけを検査します (naga は関数の中の数どうしの演算のあふれを誤りにしません)。
