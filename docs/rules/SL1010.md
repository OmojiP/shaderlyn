# SL1010: タグ名にスペルミスの可能性があります

分類: Usage / 既定の重要度: 警告

## 何を検出するか

`Tags { ... }` に、既知のタグ名によく似た、しかし一致しない名前が指定されている箇所です。

知らないタグ名それ自体は報告しません。
タグの名前空間は開かれており、レンダーパイプラインや地形システムが独自のタグを自由に追加します。
既知のタグから編集距離 2 以内のものだけを、スペルミスの疑いとして報告します。

## なぜ問題か

Unity はタグ名のスペルミスをエラーにせず、そのまま無視します。
`"RendrType" = "Opaque"` と書いても何の警告も出ず、
「設定したつもりが効いていない」という形でしか現れません。

## どう直すか

綴りを確認してください。よく間違えられるもの:

| 誤り                       | 正しい綴り       |
| -------------------------- | ---------------- |
| `RendrType` / `Rendertype` | `RenderType`     |
| `LightMod`                 | `LightMode`      |
| `RenderPipline`            | `RenderPipeline` |

## 誤検出だと思ったら

この指摘は「誤りである」ではなく「スペルミスに見える」と言っています。
レンダーパイプラインは独自のタグを定義でき、このツールがすべてを知ることはできません。
意図した独自タグであれば、この指摘は無視して構いません。
