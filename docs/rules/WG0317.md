# WG0317: 定数式が要ります

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

WGSL のファイルで、定数式が要るところ (`const` の初期値と `const_assert` の条件) に、実行時の値を使っている状態です。naga はコンパイルの誤りにします。

```wgsl
override o: i32;
var<private> v: i32;
fn f() {
    let a = 5;
    const b = a;          // let の値
    const c = o;          // override の値 (パイプラインを作るときに決まる)
    const d = v;          // var の値
    const_assert a != 0;  // const_assert も定数式
}
```

## なぜ問題か

`const` の値はシェーダーモジュールを作るときに決まらなければなりません。naga はシェーダーモジュールを作れず、パイプラインが作られません。

## どう直すか

`const` を `let` にするか、初期値を `const` と数のリテラルだけで書いてください。`override` の値を使う定数は `override` で宣言します。
