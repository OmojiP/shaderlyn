# WG0332: 関数は自分自身を呼べません

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

WGSL のファイルで、関数が直接か、ほかの関数を通して自分自身を呼んでいる状態です。WGSL では再帰の呼び出しができません。naga はコンパイルの誤りにします。

```wgsl
fn f() { g(); }
fn g() { f(); }   // f → g → f
fn h() { h(); }   // 自分自身
```

## なぜ問題か

GPU には呼び出しを積む場所が無いので、WGSL は再帰を禁じています。シェーダーモジュールを作れず、パイプラインが作られません。

## どう直すか

ループに書き換えてください。深さの決まった再帰なら、深さごとに別の関数にします。
