# WG0309: 書き込めない値です

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

WGSL のファイルで、書き込めない値に代入か `++` / `--` で書き込んでいる状態です。naga はコンパイルの誤りにします。

```wgsl
@group(0) @binding(0) var<storage> data: array<f32>;  // read_write でない

fn f(x: f32) {
    let a = 10;
    a = 20;          // let は書き換えられない
    x = 1.0;         // 仮引数も書き換えられない
    data[0] = 1.0;   // 読み取りだけのバッファー
    var v = vec2(0);
    v.xy = vec2(1);  // スウィズルには代入できない
}
```

書き込めないのは次のものです。

- `let`・`const`・`override` の値と、そのメンバー・要素
- 関数の仮引数
- `var<uniform>` の変数と、`read_write` でない `var<storage>` の変数 (`var<storage>`・`var<storage, read>`)
- 2 つ以上の成分のスウィズル (`v.xy`)。1 成分 (`v.x`) には書ける
- 変数でない値 (演算の結果、関数の呼び出しの結果、数)

## なぜ問題か

シェーダーモジュールを作れず、パイプラインが作られません。

## どう直すか

書き換える値は `var` で宣言してください。仮引数を書き換えたいときは、`var` の局所変数に写してから書き換えます。
バッファーに書き込む場合は `var<storage, read_write>` にします (バインドグループのレイアウトも書き込める種類にします)。
スウィズルへの代入は、成分ごとの代入にするか、ベクトル全体を作り直して代入してください。

## 誤検出だと思ったら

ポインターを経由した書き込み (`*p = 1.0`) は、指す先が不明なため検査しません。
