# SG0366: #language の指令が誤っているか、ほかの指令と一致しません

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

Slang の言語を選ぶ指令 (`#language`・`#lang`) の、次の誤りです。

| 書き方 | slangc の誤り |
| --- | --- |
| バージョンを書いていない (`#language`・`#language slang`) か、整数でない (`#language 2026.0`) | E15206 |
| Slang が知らないバージョン (`#language 2024`) | E15207 |
| Slang 以外の言語の名前 (`#language glsl`・`#language hlsl`) | E15208 |
| 1 つの翻訳単位に、`#language` と GLSL の `#version` を両方書いた | E00121 |
| 1 つの翻訳単位に、違うバージョンの `#language` を 2 つ書いた | E00126 |

翻訳単位は、解析するファイルと、`#include` で取り込んだファイルを合わせたものです。
書けるバージョンは `2018`・`2025`・`2026`・`legacy` (`2018` と同じ)・`latest` (`2026` と同じ) です。slangc は `202a` (`2025` と同じ)・`202b` (`2026` と同じ)・`202c` (`2026` より新しいバージョン)・`202e` も受け付けます。

```slang
#language 2026
#version 450   // 報告する。#language と #version を両方書いている
```

## なぜ問題か

slangc がコンパイルの誤りにします。
`#version` を書いた `.slang` のファイルは、slangc が GLSL として解析します。そのため、Slang を選ぶ `#language` と一緒には書けません。

## 修正方法

- Slang のファイルでは `#version` を消してください
- `#language` は翻訳単位に 1 つだけ書くか、同じバージョンにそろえてください

## 誤検出だと思ったら

このルールは次の場合に発火しません。

- `__include` で取り込んだ別のファイルとの不一致 (slangc の E00123)
- `#version` だけを書いた `.slang` のファイル (slangc は GLSL として解析し、警告 E00120 を出します)
