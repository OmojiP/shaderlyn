# SG0348: property と __subscript の書き方が正しくありません

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

Slang のファイルで、`property` と `__subscript` を正しくない形で書いている状態です。slangc はコンパイルの誤り (E30901・E31112・E31108・E31109・E30621・E30318) にします。

```slang
struct T
{
    int val[4];

    __subscript(int x)             // -> で戻り値の型を書いていない
    {
        get { return val[x]; }
    }

    property p : int
    {
        get(a) { return 0; }       // get に仮引数 (と型が存在しない仮引数)
        set(a, b) { }              // set の 2 つの仮引数
    }

    property q : float
    {
        set(c : int) { }           // property の型と違う型
    }
}
```

`set(v)` の 1 つの仮引数は、型を書かなくても property の型になります。

インターフェイスの `property` と `__subscript` の accessor に既定の実装を書く場合は、すべての accessor に書きます。片方だけに本体を書くと誤りです (E30318)。

```slang
interface IFoo
{
    property int value
    {
        get;
        set { }                    // get に本体が存在しない
    }
}
```

## なぜ問題か

slangc がコンパイルできません。

## どう直すか

`__subscript(int x) -> int` のように戻り値の型を書いてください。`get` に仮引数は書かず、`set` には property の型の仮引数を 1 つだけ書いてください。
