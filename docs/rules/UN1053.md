# UN1053: DX11 で使えなくなるコンパイラの指定です

分類: Correctness / 既定の重要度: 警告

## 何を検出するか

パスを DX11 でも DXC でコンパイルさせる指定です。DXC でコンパイルしたシェーダーは DX11 では使えません
(Unity がコンパイルしないか、作っても使いません)。対象の API に DX11 があるときだけ報告します。

| 書いたもの | 報告する条件 | 直し方 |
| --- | --- | --- |
| DXC が要る `require` (キーワードの条件なし) | いつでも | `require 値 : キーワード` のように条件を付け、DXC が要る構成と FXC でよい構成を分ける |
| `use_dxc d3d11` | Unity 6.5 以前 | DX11 でも使うなら `use_dxc` を外す。Unity 6.6 からは `dx12` で DX12 だけを DXC にできる |
| `use_dxc` (API なし) | Unity 6.5 以前 | DX11 でも使うなら `use_dxc` を外し、FXC で使える書き方にする。Unity 6.6 からは API を書かなくても DX11 は FXC |

DXC が要る `require` の値は `wavebasic` / `wavevote` / `waveballot` / `wavemath` / `wavemultiprefix` / `waveshuffle` / `quadshuffle` /
`int64` / `native16bit` / `barycentrics` / `int64bufferatomics` / `int64groupsharedatomics` (Unity 6.4 以降は `inlineraytracing` も) です。

```
Assets/Shaders/B.shader(13:29): warning UN1053: require int64 がキーワードの条件なしで書かれています。
    このパスは DXCコンパイルされるため、Graphics API for Windows: DX11 では動作しません。
    Graphics API for Windows: DX11 でも使用する場合、require int64 : キーワード のように条件を付け、DXC と FXC の構成を分けてください。
```

規則は Unity 2022.3〜6.6 (DX11 / DX12 / Vulkan) で確かめました。

## なぜ問題か

DX11 の環境では、そのシェーダー (パス) が使われず、描画されないか、フォールバックに切り替わります。
エディタでは DX12 で動いていて気づかず、DX11 のプレイヤーで初めて分かることがあります。

## 環境による違い

Unity の環境だけで動きます。対象の API は `unity: graphics-apis`、無ければプロジェクトの設定、それも無ければ DX11 と DX12 です
([設定](../guide/configuration.md#シェーダーのコンパイラ))。DX12 だけを対象にするなら、このルールを無効にしてかまいません。
