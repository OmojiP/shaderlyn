# HL0370: 配列の添字が範囲を超えています

分類: Correctness / 既定の重要度: エラー

対応する HLSL のコード: 3030 (`ERR_PARSE_ARRAY_INDEX_OUT_OF_BOUNDS`) / 3504

## 何を検出するか

配列の長さを超えた添字です。

```hlsl
float arr[3] = {1, 2, 3};

return arr[5];   // 使えるのは 0 から 2 まで
```

添字は 0 から始まるので、長さ 4 の配列で使えるのは 0 から 3 までです。

## 誤検出だと思ったら

このルールは次の場合に発火しません。

- 添字が数字で書かれていない場合。変数の添字は実行時に決まります
- 配列の長さが数字で書かれていない場合。
  マクロや定数で書かれた長さは求めません
- その位置で名前が指す宣言を決められない場合や、構成によって長さが違う場合。
  名前はその位置で指す宣言から引くので、
  別の関数に同じ名前の配列があっても取り違えません
