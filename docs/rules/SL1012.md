# SL1012: タグの値にスペルミスの可能性があります

分類: Usage / 既定の重要度: 警告

## 何を検出するか

`Tags { ... }` の値に、既知の値によく似た、しかし一致しない文字列が指定されている箇所です。

現在の対象は `RenderType` です。

```
Tags { "RenderType" = "Opaqu" }
```

知らない値それ自体は報告しません。
`RenderType` は `Camera.RenderWithShader` によるシェーダー置き換えの目印であり、
プロジェクトが自由な値を付けてよいものです。
既知の値から編集距離 2 以内のものだけを、スペルミスの疑いとして報告します。

## なぜ問題か

Unity はタグ値のスペルミスをエラーにせず、そのまま無視します。

`"RenderType" = "Opaqu"` と書いても何の警告も出ません。
その結果、次のことが起きても気づけません。

- `Camera.RenderWithShader` / `SetReplacementShader` の置き換え対象から外れる
  （深度テクスチャやカスタムの G-Buffer 生成など、`RenderType` を見る仕組みが素通りする）
- シェーダーの分類を `RenderType` で行っているエディタ拡張やツールから漏れる

いずれも実行して初めて、しかも「なぜか一部のオブジェクトだけ描かれない」という
分かりにくい形でしか現れません。

## どう直すか

綴りを確認してください。Unity の組み込みの値は次のとおりです。

| 値                                                       | 用途                               |
| -------------------------------------------------------- | ---------------------------------- |
| `Opaque`                                                 | 不透明。ほとんどのシェーダーがこれ |
| `Transparent`                                            | 半透明                             |
| `TransparentCutout`                                      | アルファテストによる切り抜き       |
| `Background`                                             | スカイボックス                     |
| `Overlay`                                                | ハローやフレアなど                 |
| `TreeOpaque` / `TreeTransparentCutout` / `TreeBillboard` | 地形の樹木                         |
| `Grass` / `GrassBillboard`                               | 地形の草                           |

## 誤検出だと思ったら

この指摘は「誤りである」ではなく「スペルミスに見える」と言っています。

`RenderType` に独自の値を使い、それが偶然に組み込みの値と似ている場合、
この指摘は無視して構いません。設定ファイルで無効にもできます。

```yaml
rules:
  SL1012: none
```
