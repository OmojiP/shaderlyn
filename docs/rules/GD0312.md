# GD0312: 関数を値として使っています

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

Godot シェーダー言語のファイルで、関数の名前を呼び出しの外で値として使っている状態です。Godot はコンパイルの誤りにします。

```glsl
shader_type spatial;

float f() { return 1.0; }

void fragment() {
    float a = f;      // f() と書く
    float b = sin;    // 組み込み関数も同じ
}
```

## なぜ問題か

Godot がシェーダーをコンパイルできず、マテリアルが描画されません。Godot シェーダー言語には関数を値として扱う仕組みがありません。

## どう直すか

`f()` のように呼び出してください。

## 誤検出だと思ったら

同じ名前の変数があれば、その変数を指すものとして報告しません。
