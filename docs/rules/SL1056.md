# SL1056: Unity は UTF-16 のファイルを読めません

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

UTF-16 (LE / BE、BOM の有無によらない) で保存した `.shader` と、それが取り込む `.hlsl` / `.cginc` などです。
取り込んだファイルは、取り込んでいる `#include` の行に報告します。

```
Assets/Shaders/A.shader(1:1): error SL1056: このファイルは UTF-16 で保存されています。
    Unity は UTF-16 のファイルを読めず (BOM があっても)、シェーダーがエラーになります。
    UTF-8 で保存し直してください。
Assets/Shaders/B.shader(12:22): error SL1056: 取り込む 'Common.hlsl' は UTF-16 で保存されています。
    Unity は UTF-16 のファイルを読めず (BOM があっても)、このシェーダーがエラーになります。
    'Common.hlsl' を UTF-8 で保存し直してください。
```

## なぜ問題か

Unity は UTF-8 のファイルしか読めません。Unity 2022.3 / 6.3 / 6.6 (DX12) で次を確かめました。

| ファイル | Unity の結果 |
| --- | --- |
| `.shader` UTF-8 (BOM の有無によらない) | 読める |
| `.shader` UTF-16 LE / BE (BOM あり・なし) | `Parse error: syntax error, … expecting TOK_SHADER` |
| 取り込む `.hlsl` UTF-16 LE (BOM あり) | `Unexpected directive` |
| 取り込む `.hlsl` UTF-16 LE (BOM なし) | コンパイラの構文エラー |

Visual Studio などのエディタは、日本語を含むファイルを UTF-16 で保存することがあります。
見た目では分からないので、Unity のエラーから原因に辿り着きにくい誤りです。

Shaderlyn は UTF-16 のファイルも読んで解析を続けます (DXC は UTF-16 を読めるので、Unity 以外の環境ではそのまま解析します)。
この規則は Unity の環境だけで動きます。

## どう直すか

エディタで UTF-8 を選んで保存し直します。BOM はあってもなくても構いません。
