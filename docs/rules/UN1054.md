# UN1054: Unity のバージョンでコンパイラが変わる指定です

分類: Correctness / 既定の重要度: 警告

## 何を検出するか

同じコードブロックに `#pragma never_use_dxc` と、DXC が要る `#pragma require` (キーワードの条件なし) の両方を書いたものです。

```
Assets/Shaders/C.shader(10:21): warning UN1054: 同じコードブロックに never_use_dxc と、DXC を要する require wavebasic が書かれています。
    Unity 6.5 以前は FXC、6.6 からは DXC でコンパイルされます。
```

Unity 6.5 以前は `never_use_dxc` が勝ち、6.6 からは `require` が勝ちます。Unity 2022.3〜6.6 で確かめました。
Unity のバージョンが分からなくても報告します (どのバージョンでも、もう一方のバージョンでは結果が変わるため)。

## なぜ問題か

Unity を 6.6 に上げただけで、FXC でコンパイルしていたパスが DXC でコンパイルされるようになります (またはその逆)。
DXC でコンパイルされると DX11 では使えなくなり ([UN1053](UN1053.md))、FXC でコンパイルされると `require` の機能は使えません。

## どう直すか

どちらか一方にします。DXC が要る機能を使うなら `never_use_dxc` を外し、FXC でコンパイルしたいなら `require` を外します。
