# SG0405: テクスチャの要素にできない型です

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

Slang のファイルで、テクスチャ (`Texture2D`・`RWTexture2D`・`Sampler2D` など) か型付きバッファー (`Buffer`・`RWBuffer`) の要素の型に、行列・構造体・`bool`・資源の型を書いている状態です。
slangc はコンパイルの誤り (E38029) にします。

```slang
struct S { float a; }

Texture2D<float4x4> t1;   // 行列
RWBuffer<Sampler1D> t2;   // 資源の型
Texture2D<S> t3;          // 構造体
Texture2D<bool> t4;       // bool
Texture2D<half2> ok1;     // bool でないスカラーとベクトルは書ける
StructuredBuffer<S> ok2;  // StructuredBuffer は構造体を入れられる
```

## なぜ問題か

テクスチャと型付きバッファーの要素は、テクセルとして読み書きできる型 (`ITexelElement`) でなければなりません。それは `bool` でないスカラーとベクトルだけです。

## どう直すか

行列や構造体を入れるなら `StructuredBuffer<T>` を使ってください。`bool` は `uint` にしてください。
