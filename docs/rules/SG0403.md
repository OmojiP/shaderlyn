# SG0403: この型の配列は作れません

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

Slang のファイルで、アドレスを持たない型の配列を宣言している状態です。slangc はコンパイルの誤り (E30028) にします。

```slang
struct WithBlock { ParameterBlock<Params> block; }
struct WithUnbounded { int data[]; }

uniform ParameterBlock<float> qs[2];      // ParameterBlock の配列
WithBlock arr[2];                         // ParameterBlock を含む構造体の配列
WithUnbounded many[3];                    // 大きさを決めない配列を含む構造体の配列
int arrayOfUnbounded[3][];                // 大きさを決めない配列の配列
```

## なぜ問題か

slangc がコンパイルできません。

## どう直すか

配列の要素ごとに別の変数にするか、ParameterBlock の中に配列を置いてください。
