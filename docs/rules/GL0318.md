# GL0318: const の変数には初期値が要ります

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

GLSL のファイルで、`const` を付けた変数を初期値なしで宣言している状態です。glslang はコンパイルの誤りにします。

```glsl
#version 450
layout(location = 0) out vec4 color;

const int count;                       // 初期値が無い
const struct Light { vec3 dir; } sun;  // 構造体の宣言に続けて宣言した変数も同じ

void main()
{
    const float scale;                 // 関数の中も同じ
    color = vec4(1.0);
}
```

関数の外と関数の中の変数を見ます。仮引数の `const` は対象にしません。

## なぜ問題か

`const` の変数の値は宣言で決めなければならず、後から代入できません。glslang (Vulkan の SDK の `glslangValidator` と `glslc`) がコンパイルを止めます。

## どう直すか

宣言に初期値を書いてください (`const int count = 4;`)。後から値を決めるなら、`const` を外してください。
