# SG0359: インターフェイスの要件を満たしていません

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

Slang のファイルで、インターフェイスに適合する型が、インターフェイスの要件 (本体の無いメソッド) を満たしていない状態です。slangc はコンパイルの誤り (E38100・E38105) にします。

```slang
interface IFoo
{
    void bar();
    static int count();
    int value();
}

struct T : IFoo
{
    // bar が無い
    int count() { return 1; }          // 要件は static
    [mutating] int value() { return 0; } // 要件は [mutating] でない
}
```

extension で足されうる型 (`extension T { … }`) とインターフェイス、ジェネリックのインターフェイス、基底の構造体を持つ型は見ません。

## なぜ問題か

インターフェイスを通して呼ぶとき、要件の形のメソッドが要ります。

## どう直すか

要件と同じ名前・仮引数・static と [mutating] の有無のメソッドを書いてください。
