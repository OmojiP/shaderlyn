# SG0359: インターフェイスの要件を満たしていません

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

Slang のファイルで、インターフェイスに適合する型が、インターフェイスの要件 (本体の無いメソッド) を満たしていない状態です。slangc はコンパイルの誤り (E38100・E38105) にします。

```slang
interface IFoo
{
    void bar();
    static int count();
    int value();
}

struct T : IFoo
{
    // bar が無い
    int count() { return 1; }          // 要件は static
    [mutating] int value() { return 0; } // 要件は [mutating] でない
}
```

継承したインターフェイス (`interface IB : IA`) の要件も見ます。継承の並びのどこかで本体を書いた (既定の実装のある) 要件は、満たしているものとします。

extension で足されうる型 (`extension T { … }`・`extension<T> Box<T> { … }`) とインターフェイス、ジェネリックのインターフェイス、基底の構造体を持つ型、利用者のインターフェイスでないもの (標準ライブラリのインターフェイスなど) を継承したインターフェイスは見ません。どの型にも当たる extension (`extension<T : IM> T { … }`) は、その制約 (IM) に適合しうる型にだけメソッドを足しうるものとします。

要件を満たすメソッドの書き方が要件と合わないもの (E38105) と、型の大きさ・使う機能も見ます。

- throws の無い要件を、throws のメソッドで満たすもの
- 要件と `where nonempty(…)` の制約が合わないもの
- 要件より強い制約を型の仮引数に書いたもの (要件が `<T : IA>` で、実装が `<T : IA & IB>`)。弱い制約は通ります
- `[anyValueSize(N)]` のインターフェイスに適合する構造体の大きさが N バイトを超えるもの (E41019)。インターフェイスの型の値を作るコード (エントリポイントから届く関数か、グローバルの宣言) のあるファイルの、フィールドが 4 バイトのスカラー・ベクトルとその配列だけの構造体を見ます
- `[require(…)]` のインターフェイスか要件を満たすメソッドが、呼んでいる関数の `[require(…)]` で、許されない機能を使うもの (E36110)。module の宣言かエントリポイントのあるファイルの、SPIR-V の拡張 (spv で始まる名前) の機能だけを見ます

継承したインターフェイスの要件が無いときは、slangc と同じく、そのインターフェイスを継承の並びに書いた位置 (`interface IDerived : IBase` の IBase) で伝えます。

```slang
enum MyError { Fail = 1 };
interface IA {}
interface IB {}
interface IFoo
{
    int run();
    void f<T : IA>();
}
struct MyFoo : IFoo
{
    int run() throws MyError { return 1; }   // 要件は throws でない
    void f<T : IA & IB>() {}                 // 要件より強い制約
}
```

## なぜ問題か

インターフェイスを通して呼ぶとき、要件の形のメソッドが要ります。

## どう直すか

要件と同じ名前・仮引数・static と [mutating] の有無のメソッドを書いてください。
