# HL0304: cbuffer の中の関数は DXC でエントリポイントにできません

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

エントリポイントの関数が cbuffer (`CBUFFER_START` / `CBUFFER_END`) の中に書かれていて、そのコードが DXC でコンパイルされるものです。
DXC になるのは、Unity なら `#pragma use_dxc` や、プロジェクトの設定で DX12 を DXC にした場合などです (`--env` で確かめられます)。
汎用の HLSL と Unreal Engine の環境は DXC です。

```
Lit.shader(11:30): error HL0304: #pragma fragment が指定する関数 'Main_PS' は cbuffer 'UnityPerMaterial' の中にあります。
    dx12 (Unity の DXC (HLSL 2018)) では DXC がエントリポイントを見つけられず、コンパイルできません (Unity ではコンパイラが落ちます)。
    関数を cbuffer の外へ出してください。
```

FXC でだけコンパイルされるなら、この指摘ではなく [HL0303](HL0303.md) (警告) になります。

## なぜ問題か

DXC は、cbuffer の中の関数をエントリポイントとして扱えません。

- スタンドアロンの DXC (1.8): `error: cannot find entry function Main_PS`
- Unity 6.6 の DXC: `Lost connection with shader compiler process. Suspected crash in DXC.` (行番号なし)

cbuffer の中で呼ぶだけの関数や、構造体・`static const` は DXC でも通ります。

## どう直すか

関数を cbuffer の外へ出してください。直し方の例は [HL0303](HL0303.md) にあります。

## 誤検出だと思ったら

コンパイル先の判定が実際と違う可能性があります。`--env` の「シェーダーのコンパイラ」を確かめてください。
