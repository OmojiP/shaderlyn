# SG0311: 条件にはスカラーの値が要ります

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

Slang のファイルで、`if`・`while`・`for`・`do` の条件にベクトル・行列・構造体・資源の型の値を書いているか、`?:` の条件か `!` の値に構造体・資源の型の値を書いている状態です。
slangc はコンパイルの誤り (E30019・E39999) にします。

```slang
struct S { int a; }

void f(S s, float3 v, int i, bool4 mask)
{
    if (s) { }                        // 報告する。構造体
    while (v) { break; }              // 報告する。ベクトル
    int x = s ? 1 : 2;                // 報告する。構造体
    if (i) { }                        // 正しい。int のスカラー
    float4 c = mask ? 1.0 : 0.0;      // 正しい。?: のベクトルの条件は成分ごとに選ぶ
    bool4 n = !mask;                  // 正しい。! のベクトルは成分ごとに働く
}
```

## なぜ問題か

条件は 1 つの真偽で分岐を決めます。ベクトルや構造体の値は、どの値を真とするかが決まりません。

## どう直すか

ベクトルなら `any(v)` か `all(v)` で 1 つの真偽にしてください。構造体なら、そのフィールドを比べてください。
