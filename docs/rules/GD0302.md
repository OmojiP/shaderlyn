# GD0302: 組み込み関数に、実引数の型に合う形がありません

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

Godot シェーダー言語のファイルで、組み込み関数か値の作成 (`vec2(…)` など) に、どの形にも合わない型の実引数を渡している状態です。Godot はコンパイルの誤りにします。

```glsl
shader_type spatial;

void fragment() {
    float a = sin(vec2(1.0), 2.0);   // sin に (vec2, float) の形は存在しない
    int i = 1;
    vec2 b = vec2(i, 1.0);           // vec2 に (int, float) の形は存在しない
}
```

形の表は Godot 4.7.2 のシェーダーのコンパイラ (`builtin_func_defs`) と同じです。Godot には暗黙の変換が存在しないので、実引数の型は仮引数とちょうど同じでなければなりません。

例外は、実引数に書いた整数のリテラルです。`float` / `uint` の仮引数へ変換されます (`sin(1)`、`vec2(1, 2)`、`mix(0, 1, 0.5)`)。
定数の名前 (`const int K`)・式 (`1 + 2`)・変数は変換されません。

実引数の数が合う形が存在しないものは [CF0402](CF0402.md) が報告します。

## なぜ問題か

Godot がシェーダーをコンパイルできず、マテリアルが描画されません。

## どう直すか

実引数の型を、形に合わせて変換してください。

```glsl
float a = sin(1.0) * 2.0;
vec2 b = vec2(float(i), 1.0);
```

## 誤検出だと思ったら

型が不明な実引数がある呼び出しと、利用者が同じ名前の関数を宣言したものは検査しません。
