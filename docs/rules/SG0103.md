# SG0103: レジスタの種類が資源の型と合いません

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

Slang のファイルで、`register(…)` の種類が資源の型と合わない状態です。slangc はコンパイルの誤り (E31222) にします。

```slang
Texture2D tex : register(u5);                    // Texture2D は t
RWStructuredBuffer<float> buf : register(t0);    // RW… は u
SamplerState samp : register(t11);               // サンプラーは s
ConstantBuffer<Params> params : register(t1);    // 定数バッファーは b
```

| 種類 | 資源の型 |
| --- | --- |
| `t` | 読むだけの資源 (`Texture2D` などのテクスチャ、`StructuredBuffer`、`ByteAddressBuffer`、`Buffer`、`RaytracingAccelerationStructure`) |
| `u` | 書ける資源 (`RW…`、`RasterizerOrdered…`、`AppendStructuredBuffer`・`ConsumeStructuredBuffer`、`FeedbackTexture2D`) |
| `s` | `SamplerState`・`SamplerComparisonState` |
| `b` | `ConstantBuffer` |

## なぜ問題か

slangc がコンパイルできません。

## どう直すか

資源の型に合う種類のレジスタを書いてください。
