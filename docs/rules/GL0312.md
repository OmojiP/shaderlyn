# GL0312: 変数を関数として呼んでいます

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

GLSL のファイルで、関数の中の変数か仮引数に隠された関数を呼んでいる状態です。glslang はコンパイルの誤りにします。

```glsl
#version 450
layout(location = 0) out vec4 color;

void main()
{
    float degrees = 90.0;
    color = vec4(degrees(1.0));   // degrees はここでは変数。組み込み関数 degrees() は呼べない
}
```

GLSL では、変数と関数は同じ名前の空間にあります。関数の中で宣言した変数と仮引数は、同じ名前の関数 (組み込み関数を含む) を、その範囲の中で隠します。

宣言している最中の変数は、まだ見えません。`S S = S(0);` の右の `S` は構造体の値の作成として読めます。
デスクトップの `#version 110` では関数と変数の名前の空間が分かれているので (glslang と同じ)、報告しません。

## なぜ問題か

glslang (Vulkan の SDK の `glslangValidator` と `glslc`) がコンパイルを止めます。

## どう直すか

変数か仮引数の名前を変えてください。

```glsl
float angle = 90.0;
color = vec4(degrees(1.0));
```
