# GD0101: この修飾子はここに書けません

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

Godot シェーダー言語のファイルで、`instance` / `global` / `varying` を書けないところに書いている状態です。Godot はコンパイルの誤りにします。

```glsl
shader_type spatial;

instance uniform sampler2D tex;   // instance uniform にサンプラーは使えない
instance uniform mat4 m;          // 行列も使えない
global uniform float g[2];        // global uniform と instance uniform は配列にできない
```

```glsl
shader_type particles;

varying float v;                  // varying は particles・sky・fog では使えない
```

`instance uniform` は `spatial` と `canvas_item` のシェーダーでだけ使えます。

整数の varying (`int`・`ivec2`・`uint` など) には `flat` が要ります。`fragment` 関数で書き込む (`light` に渡す) ものだけは要りません。

```glsl
shader_type spatial;

varying int id;                   // varying flat int id; と書く
```

## なぜ問題か

Godot がシェーダーをコンパイルできず、マテリアルが描画されません。

## どう直すか

修飾子を外すか、使える型にしてください。行列は `vec4` などに分け、配列は要素ごとの uniform に分けます。

## 誤検出だと思ったら

`.gdshaderinc` (シェーダーの種類が決まらないファイル) では、シェーダーの種類による制限は検査しません。
