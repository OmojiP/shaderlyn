# HL0341: 引数の個数が合いません

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

呼び出しの引数の個数が、その構成に存在するどの宣言とも合っていない状態です。

```hlsl
half4 sampleTexture(float2 uv) { ... }

half4 frag() : SV_Target
{
    return sampleTexture(uv, 1);   // 1 個の宣言に 2 個渡している
}
```

既定値のある仮引数は省略できるものとして数えます。

```hlsl
half4 shade(float3 v, float k = 1) { ... }

shade(v);        // 正しい
shade(v, 0.5);   // 正しい
shade(v, 1, 2);  // 報告する
```

候補はその構成に存在する宣言だけに絞ります。
`#ifdef` で仮引数の数が変わる関数では、
条件を見ないと別の構成の宣言が候補に混ざります。

**個数の合う宣言が、呼び出しのあるすべての構成に存在するかを見ます。**

```hlsl
#ifdef _B
float4 F(float a, float b) { ... }
#else
float4 F(float a) { ... }
#endif
F(1, 2);   // 報告する (!_B のとき 1 個しか受け付けない)
```

存在しうる宣言のどれか 1 つが合えば通すと、`_B` の宣言にだけ合う呼び出しを `!_B` でも通してしまいます。
宣言が 1 つも無い構成は [HL0311](HL0311.md) の担当なので、ここでは報告しません。
[HL0340](HL0340.md) (型) と [HL0342](HL0342.md) (`out`) も同じ判定をします。

組み込み関数も見ます。

```hlsl
lerp(a, b);          // 報告する。lerp は 3 個
tex2D(s, uv);        // 正しい
tex2D(s, uv, dx, dy); // 正しい。勾配を渡す形もある
```

組み込み関数が受け付ける個数は、DirectXShaderCompiler の組み込み関数の表
(`utils/hct/gen_intrin_main.txt`) から作っています (`tools/intrinsics/generate.mjs`)。

## なぜ問題か

その構成ではコンパイルに失敗します。

引数を増やしたり減らしたりしたときに、
呼び出し側の一部を直し忘れると起きます。

## どう直すか

宣言に合わせて引数を足すか減らしてください。
メッセージには、その構成の宣言が受け付ける個数が書かれています。

## 誤検出だと思ったら

このルールは次の場合に発火しません。

- 宣言が 1 つも見えていない関数で、組み込み関数の表にも無い名前
- 組み込み関数の名前で、同じ名前の関数がどこか (取り込んだヘッダを含む) で宣言されている場合、
  または取り込めなかったヘッダがある場合。そこに同じ名前の関数やマクロがあるかもしれません
- 組み込み関数と同じ名前で多重定義した関数で、組み込み関数の側がその個数を受け付ける場合
- 個数の合う宣言が 1 つでもある場合
- その構成に宣言が 1 つも無い場合。
  呼べる関数が無いという話なので、[HL0311](HL0311.md) の担当です
- 出現条件が分からない場合 ([SL0004](SL0004.md) が代わりに報告されます)
