# GD0103: uniform のヒントか既定値が正しくありません

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

Godot シェーダー言語のファイルで、uniform のヒント (`:` の後ろ) か既定値 (`=` の後ろ) が正しくない状態です。Godot はコンパイルの誤りにします。

```glsl
shader_type spatial;

uniform float a : source_color;                    // source_color は vec3・vec4・サンプラーだけ
uniform vec4 b : color_conversion_disabled;        // 前に source_color が必要
uniform vec2 c : hint_range(0.0, 1.0);             // hint_range は float と int だけ
uniform float d : hint_enum("A", "B");             // hint_enum は int だけ
uniform float e : filter_linear;                   // フィルターと繰り返しの指定はサンプラーだけ
uniform sampler2D f : hint_normal, hint_default_white; // ヒントは 1 つだけ
uniform sampler2D g : filter_linear, filter_nearest;   // フィルターも 1 つだけ
uniform float h[2] : hint_range(0.0, 1.0);         // 配列に書けるのは source_color とフィルターと繰り返しだけ
instance uniform float i : instance_index(16);     // instance_index は 0 から 15
uniform float j = vec2(1.0);                       // 既定値を uniform の型に変換できない
uniform float k[2] = {1.0, 2.0};                   // 配列の uniform には既定値を書けない
```

ほかに、次のものも報告します。

- そのシェーダーの種類では使用できないヒント (`hint_screen_texture` は `spatial` と `canvas_item`、`hint_depth_texture` と `hint_normal_roughness_texture` は `spatial`、`hint_blit_source0` などは `texture_blit` だけ)
- `instance_index` の 2 度目と負の数
- `hint_range` の引数の、定数でない名前
- `hint_enum` の、文字列でない引数
- 17 個目の `instance uniform` (`instance_index` を書いていないもの)

既定値は、同じ型のほか、`int` と `uint` の定数を `float` に、`int` と `uint` を互いに変換できます (負の数は `uint` にできません)。

## なぜ問題か

Godot がシェーダーをコンパイルできず、マテリアルが描画されません。

## 修正方法

uniform の型に合うヒントを、種類ごとに 1 つずつ書いてください。既定値は uniform と同じ型にしてください。

## 誤検出だと思ったら

`hint_normal_roughness_texture` が Forward+ の描画でだけ使用できることは検査しません。
