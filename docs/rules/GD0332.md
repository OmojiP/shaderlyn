# GD0332: 関数は自分自身を呼べません

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

Godot シェーダー言語のファイルで、関数の中でその関数自身を呼んでいる状態です。Godot はコンパイルの誤りにします。

```glsl
shader_type spatial;

float f(float x) {
    return f(x - 1.0);   // 再帰は使用できない
}
```

Godot には関数の前方宣言が存在せず、後ろで定義した関数も呼べないので、関数どうしが呼び合う形も書けません ([CF0310](CF0310.md)・CF0001)。

## なぜ問題か

Godot がシェーダーをコンパイルできず、マテリアルが描画されません。GPU のシェーダーは再帰を扱えません。

## どう直すか

ループに書き換えてください。

## 誤検出だと思ったら

同じ名前の局所変数を呼んでいるときは報告しません。
