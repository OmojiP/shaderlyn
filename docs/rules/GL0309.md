# GL0309: 書き込めない値です

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

GLSL のファイルで、書き込めない値に書き込んでいる状態です。glslang はコンパイルの誤りにします。

```glsl
#version 450
layout(location = 0) in vec4 inColor;
layout(location = 0) out vec4 color;
layout(binding = 0) uniform Params { vec4 tint; };

void main()
{
    inColor.a = 1.0;      // ステージの入力には書き込めない
    tint = vec4(1.0);     // uniform には書き込めない
    color = inColor * tint;
}
```

次の書き込みを見ます。

- 代入の左辺 (`=`、`+=` など)
- `++` / `--`
- 利用者の関数の `out` / `inout` の仮引数と、`modf` / `frexp` の第 2 引数に渡す実引数

書き込む先のもとの変数 (添字・メンバー・成分の選び出しを外したもの) が次のものなら報告します (どれも glslang と同じ)。

- `const` の変数と仮引数
- uniform の変数とブロック
- ステージの入力 (`in`、`attribute`、頂点シェーダーでない所の `varying`)
- `readonly` の buffer のブロック、`shaderRecordEXT` の buffer のブロック
- 交差のシェーダーでない所の `hitAttributeEXT`、メッシュシェーダーの `taskPayloadSharedEXT`
- 変数でない値 (`(a, b)`、`(a = b)`、関数の戻り値など)

テッセレーションの制御シェーダーで、頂点ごとの出力の配列 (`gl_out` と `patch` でない `out` の配列) を `gl_InvocationID` でない添字で引いて書き込むものも報告します。

`gl_` の組み込みの変数は検査しません。`buffer_reference` を宣言したファイルでは、メンバーを通る書き込み (`block.ref.x = …`) は、参照の指す buffer への書き込みかもしれないので検査しません。

## なぜ問題か

glslang (Vulkan の SDK の `glslangValidator` と `glslc`) がコンパイルを止めます。

## どう直すか

書き込める局所変数にコピーしてから書き換えてください。

```glsl
vec4 c = inColor;
c.a = 1.0;
```
