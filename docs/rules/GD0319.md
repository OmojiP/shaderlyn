# GD0319: 配列の大きさが合いません

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

Godot シェーダー言語のファイルで、配列の大きさが合っていない状態です。Godot はコンパイルの誤りにします。

```glsl
shader_type spatial;

const float G[3] = { 1.0, 2.0 };          // 要素が 2 個しかない

void f(float x[2]) {}

void fragment() {
    float a[2] = float[](1.0, 2.0, 3.0);  // 値の作成の要素の数
    float b[2] = float[2](1.0, 2.0, 3.0); // 値の作成に書いた大きさと要素の数
    float c[3];
    a = c;                                // 大きさの違う配列の代入
    f(c);                                 // 大きさの違う配列を仮引数に渡す
}
```

`{ … }` の要素の型が配列の要素の型と違うもの (`float a[2] = { 1, 2 };`) は [CF0410](CF0410.md) として報告します。Godot はこのときも整数のリテラルを変換しません。

## なぜ問題か

Godot がシェーダーをコンパイルできず、マテリアルが描画されません。

## どう直すか

要素の数を配列の大きさにそろえてください。

## 誤検出だと思ったら

大きさが計算できない配列 (`const` の値が式で決まるもの) は調べません。
