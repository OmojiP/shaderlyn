# WG0324: 型の引数が正しくありません

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

WGSL のファイルで、型の引数 (`<…>` の中) が正しくない状態です。naga はコンパイルの誤りにします。

```wgsl
var<private> a: vec2<vec2f>;                  // ベクトルの要素はスカラー
var<private> m: mat3x3<i32>;                  // 行列の要素は f32 か f16
var t: texture_2d<bool>;                      // テクスチャの要素は f32・i32・u32
var s: texture_storage_1d<rgba, write>;       // rgba という形式は無い
@group(0) @binding(0) var<bad> x: f32;        // bad というアドレス空間は無い
var<storage, unknown_access> y: array<u32>;   // アクセスは read か read_write
var<workgroup> z: atomic<f16>;                // アトミックは i32 か u32
fn f() {
    _ = mat2x2();                             // 要素の型が決まらない
}
```

## なぜ問題か

シェーダーモジュールを作れず、パイプラインが作られません。

## どう直すか

型の引数を、その型が受け付けるものにしてください。ストレージのテクスチャの形式は `rgba8unorm`・`r32float` などの名前です。
要素の型が決まらない値の作成には、型の引数を書きます (`mat2x2<f32>()`)。
