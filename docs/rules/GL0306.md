# GL0306: 実引数に渡せない値です

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

GLSL のファイルで、決まった種類の変数を渡さなければならない組み込み関数の実引数に、別のもの (局所変数、演算の結果など) を渡している状態です。
glslang はコンパイルの誤りにします。

```glsl
#version 450
layout(local_size_x = 64) in;
layout(binding = 0) buffer Counters { uint total; };

shared uint groupTotal;
uint localTotal;

void main()
{
    atomicAdd(total, 1u);        // 良い: buffer のブロックのメンバー
    atomicAdd(groupTotal, 1u);   // 良い: shared の変数
    atomicAdd(localTotal, 1u);   // buffer でも shared でもない
}
```

今は次のものを検査します (どれも glslang と同じ)。

| 関数 | 実引数 | 渡せるもの |
| --- | --- | --- |
| `interpolateAtCentroid`、`interpolateAtSample`、`interpolateAtOffset` | 第 1 引数 | 入力の変数 (`in`) か、その配列の要素・ブロックのメンバー |
| `atomicAdd`、`atomicMin`、`atomicMax`、`atomicAnd`、`atomicOr`、`atomicXor`、`atomicExchange`、`atomicCompSwap`、`atomicLoad`、`atomicStore` | 第 1 引数 | buffer のブロックか shared の変数 (`taskPayloadSharedEXT` も) と、その要素・メンバー |
| `coopMatLoad`、`coopMatStore` と、その NV の関数、`coopVecLoadNV`、`coopVecStoreNV` | 第 2 引数 | buffer のブロックか shared の変数と、その要素・メンバー |
| `tensorWriteARM` / `tensorReadARM` | 第 1 引数 | `readonly` でない / `writeonly` でないテンソル |
| `coopVecMatMulNV`、`coopVecMatMulAddNV`、`coopVecOuterProductAccumulateNV` | 解釈・M・K・行列の配置・転置 | 定数の式 (const の付いていない変数は渡せません) |
| `imageAtomicAdd` などイメージのアトミックの関数 | 第 1 引数 | 整数のイメージは `layout(r32i)` か `layout(r32ui)` (64 ビットは `r64i` / `r64ui`)。ES の浮動小数点数のイメージは `layout(r32f)` |

`interpolateAt*` には、次の決まりもあります。

- 成分の選び出し (`v.xy`) とベクトルの添字 (`v[0]`) は、デスクトップの 4.40 から使えます。ES とそれより前のバージョンでは使えません
- ES では、構造体 (ブロックでないもの) のメンバーを渡せません

もとの変数を言い切れないとき (インスタンスの名前を持つブロック、`gl_` の組み込みの変数、`buffer_reference` の参照を通るかもしれない式) は報告しません。

サンプラーの作成 (`sampler2D(t, s)`) の実引数も見ます。1 つ目はサンプラーの型と次元・値の型が同じ配列でないテクスチャ (`sampler2DShadow` なら `texture2D`)、
2 つ目は配列でない `sampler` か `samplerShadow` でなければなりません。

## なぜ問題か

glslang (Vulkan の SDK の `glslangValidator` と `glslc`) がコンパイルを止めます。
補間の関数は入力の変数そのものを別の位置で補間し直すので、値をコピーした変数では働きません。
アトミックの関数は、ほかの呼び出しと共有するメモリ (buffer と shared) にしか意味がありません。

## どう直すか

入力の変数、buffer のブロック、shared の変数を直接渡してください。成分を選びたいときは、補間した結果から選びます。

```glsl
vec2 uv = interpolateAtCentroid(texcoord).xy;
```
