# UN0204: Unity のバージョンでコンパイラが変わる指定です

分類: Correctness / 既定の重要度: 警告

## 何を検出するか

同じコードブロックに `#pragma never_use_dxc` と、DXC が必要な `#pragma require` (キーワードの条件なし) の両方を書いたものです。

```
Assets/Shaders/C.shader(10:21): warning UN0204: 同じコードブロックに never_use_dxc と、DXC を要する require wavebasic が書かれています。
    Unity 6.5 以前は FXC、6.6 からは DXC でコンパイルされます。
```

Unity 6.5 以前は `never_use_dxc` が勝ち、6.6 からは `require` が勝ちます。Unity 2022.3〜6.6 で確認しました。
Unity のバージョンが不明でも報告します (どのバージョンでも、もう一方のバージョンでは結果が変わるため)。

## なぜ問題か

Unity を 6.6 に上げただけで、FXC でコンパイルしていたパスが DXC でコンパイルされるようになります (またはその逆)。
DXC でコンパイルされると DX11 では使用できなくなり ([UN0203](UN0203.md))、FXC でコンパイルされると `require` の機能は使用できません。

## どう直すか

どちらか一方にします。DXC が必要な機能を使用する場合は `never_use_dxc` を外し、FXC でコンパイルしたい場合は `require` を外します。
