# WG0103: メモリの配置の指定が正しくありません

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

WGSL のファイルで、構造体のメンバーの `@align` / `@size` が正しくないか、`var<uniform>` の配列の要素の間隔が 16 の倍数でない状態です。naga はコンパイルの誤りにします。

```wgsl
struct A {
    @align(7) data: array<f32>,      // 2 の累乗
}
struct B {
    @align(8) data: vec3<f32>,       // vec3<f32> の揃えは 16
}
struct C {
    @size(0) data: array<f32, 1>,    // 型の大きさ (4) 以上
}
@group(0) @binding(0)
var<uniform> input: array<vec2<u32>, 2>;   // 要素の間隔は 8 (uniform は 16 の倍数)
```

配置は WGSL の仕様の規則で求めます (スカラーは 4 バイト、vec3 の揃えは 16 など)。

## なぜ問題か

シェーダーモジュールを作れず、パイプラインが作られません。

## 修正方法

`@align` は 2 の累乗で、型の揃え以上にしてください。`@size` は型の大きさ以上にします。
uniform の配列は、要素を `vec4` にするか、`@align(16)` か `@size(16)` で間隔を 16 の倍数にした構造体にしてください。
