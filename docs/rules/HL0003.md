# HL0003: この環境では使えない構文です

分類: Syntax / 既定の重要度: エラー

## 何を検出するか

HLSL の文法としては正しくても、コードをコンパイルするコンパイラ (FXC / DXC) や HLSL のバージョンによって使えない構文と型を検出します。
Unity では `#line` 指令も報告します。

1 つのコードが API ごとに別のコンパイラや HLSL のバージョンでコンパイルされるときは (Unity の `#pragma use_dxc` など)、
どれかの API で使えなければ、その API とコンパイラを添えて報告します。

診断メッセージの文末は環境によって変わります。Unity では「環境：Unity では使えません」、
汎用の HLSL・Unreal ではコンパイラと HLSL のバージョンの名前 (`FXC` / `HLSL 2018` など) で言います。

```hlsl
enum Mode { First, Second };                        // enum 宣言 (FXC と DXC 2016)
template<typename T> T Twice(T x) { return x + x; } // template 宣言 (DXC 2021 より前と FXC)

struct S
{
    float4 v;
    S operator+(S o) { ... }                        // operator による演算子の多重定義 (DXC 2021 より前と FXC)
    uint flags : 4;                                 // ビットフィールド (DXC 2021 より前と FXC。4 の位置を報告する)
};

#line 100                                           // #line 指令 (Unity)

int64_t big;                                        // 64 ビットの整数 (FXC)
float32_t3 v;                                       // 明示のビット幅の型 (FXC と DXC 2016 / 2017)
float16_t h;                                        // 16 ビットの型 (FXC と、-enable-16bit-types の無い DXC)

interface ILight { float3 Get(); };
ILight g_light;                                     // interface 型のグローバル変数 (DXC と、シェーダーモデル 5.0 より前の FXC)
```

Unity で API を添える例です。

```
enum は 環境：dx11 (FXC) では使えません。               // 6.6 で #pragma use_dxc を書いたパス (DX11 は FXC)
型 float16_t は 環境：UNITY_DEVICE_SUPPORTS_NATIVE_16BIT が無効な構成の dx12 (FXC) では使えません。
```

Unity (FXC) は次のようなエラーで拒みます。

```
syntax error: unexpected token 'operator'
syntax error: unexpected token 'line'
```

## 環境による違い

どの構文が使えるかは、コンパイラと言語のバージョンで決まります。手元の FXC (Windows SDK 10.0.26100) と DXC 1.8 で確かめた表です。

| 構文 | FXC | DXC 2016 | 2017 | 2018 | 2021 |
| --- | --- | --- | --- | --- | --- |
| `template` / 演算子の多重定義 / ビットフィールド | × | × | × | × | ○ |
| `enum` / `enum class` | × | × | ○ | ○ | ○ |
| `class` / `interface` / 構造体の継承 / メソッド / `this` / `namespace` | ○ | ○ | ○ | ○ | ○ |
| `int64_t` / `uint64_t` | × | ○ | ○ | ○ | ○ |
| `float32_t` / `int32_t` / `uint32_t` / `float64_t` | × | × | × | ○ | ○ |
| `float16_t` / `int16_t` / `uint16_t` | × | × | × | △ | △ |
| interface 型のグローバル変数 | △ | × | × | × | × |
| `sampler2D` などの DX9 の型、`tex2D` などの DX9 の組み込み関数 | ○ | × | × | × | × |
| エントリ関数の `uniform` 引数 | ○ | × | × | × | × |

△: 16 ビットの型は `-enable-16bit-types` (Unity は `#pragma require native16bit` と `UNITY_DEVICE_SUPPORTS_NATIVE_16BIT` の構成) のときだけ。
interface 型の変数は FXC のシェーダーモデル 5.0 以降だけ (動的リンク)。
DX9 の型と組み込み関数は、Unity の DXC では使えます (Unity が変換していると考えられます)。FXC で `tex2D` を使うには互換モード (`/Gec`。Unity は使う) が要りますが、その設定は分からないので FXC では報告しません。
`sampler_state { ... }` は DXC では警告 (無視される) なので報告しません。

- Unity の既定のコンパイラは FXC です。Unity が DXC でコンパイルするパスは HLSL 2018 です。
  パスごと・API ごとにどちらでコンパイルされるかを判定し ([設定](../guide/configuration.md#シェーダーのコンパイラ))、
  キーワードの構成も踏まえます (`#ifdef UNITY_DEVICE_SUPPORTS_NATIVE_16BIT` の中の `float16_t` は報告しない)。
  使えない API (DXC になるパスの DX11 など) のエラーは利用者に見えないので報告しません。
- 汎用の HLSL では、型 (`int64_t` など) は見ません (コンパイルの設定が分からないと決められないため)。interface の変数、DX9 の書き方、エントリの `uniform` 引数は、コンパイラと HLSL のバージョンで見ます。
- 汎用の HLSL の既定は DXC の HLSL 2021 です (`hlsl: compiler` / `hlsl: version` で変えられます)。
- `class` / `interface` はどのコンパイラと HLSL のバージョンでも使えるので報告しません (0.1 では誤って報告していました)。
- 使えるコンパイラと HLSL のバージョンでは、`enum`・演算子の多重定義・`template` (明示的な特殊化 `template<>` を含む)・ビットフィールドを構文木にして検査します。
  `template` の型引数 `T` を含む型は、分からない型として扱います。
- `#line` は Unity の環境だけで報告します。

## 解析できるもの

構造体のメソッドは使えます。構造体の外での定義 (`uint Wave::GetIndex() { ... }`) も読みます。
SRP の `ThreadingEmuImpl.hlsl` がこの書き方をしていて、D3D11 でもコンパイルされます。

## この構文があると何が起きるか

その構文は読み飛ばします。中のメソッドもフィールドも、
波括弧の後ろに続く変数 (`enum Mode { ... } mode;` の `mode`) も木に載りません。

そのコードブロックでは「宣言が見つからない」ことを根拠とする検査を行いません。
uniform の一覧に抜けがある状態で「対応する宣言が無い」と報告すれば、
書かれていない誤りを指摘することになります。
見送ったことは [CF0101](CF0101.md) が同じファイルに報告します。

## どう直すか

そのコンパイラと HLSL のバージョンで使える書き方にしてください。

- `enum` は `#define` か `static const uint` の定数に
- `template` は型ごとの関数か、型名を `#define` で切り替える形に
- `operator` は通常の関数 (`S Add(S a, S b)`) に
- ビットフィールドは `uint` 1 つに詰めて、シフトとマスクで取り出す形に
- `#line` は消す

DXC でコンパイルできる環境なら、コンパイラや HLSL のバージョンを変える手もあります
(汎用の HLSL は `hlsl: version: 2021`、Unity は `#pragma use_dxc` ですが、Unity の DXC は HLSL 2018 なので `enum` までです)。
