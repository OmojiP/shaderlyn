# GD0001: このレンダラーでは使用できません

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

Godot シェーダー言語のファイルで、プロジェクトのレンダラーでは使用できないものを使用している状態です。Godot はコンパイルの誤りにします。

```glsl
shader_type spatial;

uniform sampler2D t;
uniform sampler2D nr : hint_normal_roughness_texture;  // Forward+ でだけ使用できる

void fragment() {
    // Compatibility では high-end の組み込み関数を使用できない
    ALBEDO = textureGather(t, UV).rgb;
}
```

今は次のものを検査します。

- Compatibility のレンダラーでの high-end の組み込み関数。`textureGather`・`textureQueryLod`・`textureQueryLevels`・`dFdxCoarse` / `dFdxFine` / `dFdyCoarse` / `dFdyFine` / `fwidthCoarse` / `fwidthFine`・
  `fma`・`frexp`・`ldexp`・`bitCount`・`bitfieldExtract`・`bitfieldInsert`・`bitfieldReverse`・`findLSB`・`findMSB`・`uaddCarry`・`usubBorrow`・`umulExtended`・`imulExtended` です (Godot 4.7.2 の表で high-end の印が付いたもの)
- Mobile と Compatibility のレンダラーでの `hint_normal_roughness_texture`

レンダラーは次の順に決まります。

1. 設定ファイルの [`godot: renderer`](../guide/configuration.md#godot) (`forward_plus` / `mobile` / `gl_compatibility`)
2. ファイルから上へ辿って最初に見つけた `project.godot` の `rendering/renderer/rendering_method`
3. どちらも存在しなければ Forward+ (Godot の既定)

プリプロセッサの `CURRENT_RENDERER` も、このレンダラーで決まります (`RENDERER_FORWARD_PLUS` は 2、`RENDERER_MOBILE` は 1、`RENDERER_COMPATIBILITY` は 0)。

## なぜ問題か

Godot がシェーダーをコンパイルできず、マテリアルが描画されません。Forward+ で作ったシェーダーを Compatibility のプロジェクト (Web や古い携帯機器向け) へ持っていくと起こります。

## 修正方法

そのレンダラーで使用できる書き方にしてください。`textureGather` は `texture` を 4 回、`dFdxFine` は `dFdx` で置き換えられます。
レンダラーごとに書き分ける場合は、`#if CURRENT_RENDERER == RENDERER_COMPATIBILITY` で分けます。

## 誤検出だと思ったら

`project.godot` の `rendering_method.mobile` と `rendering_method.web` (書き出し先ごとの設定) は読みません。エディターで使用するレンダラー (`rendering_method`) で検査します。
書き出し先のレンダラーで検査したいときは、`godot: renderer` を指定してください。
