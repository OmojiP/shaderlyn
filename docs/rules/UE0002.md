# UE0002: マテリアルごとに生成されるファイルの中身が分からないため、一部の検査を行っていません

分類: Usage / 既定の重要度: 情報

Unreal Engine の環境 (`environment: unreal`) だけで出ます。

## 何を検出するか

`/Engine/Generated/Material.ush` か `/Engine/Generated/VertexFactory.ush` を (ヘッダを経由しても) 取り込むシェーダー、
つまりマテリアルのシェーダーです。生成されるファイルのうち、欠けているのがこの 2 つだけのときに出ます。

```
BasePassPixelShader.usf(1:1): info UE0002: 宣言が無いことを根拠にする検査 (HL0301 / HL0310 など) を行っていません。マテリアルごとに生成されるファイル (/Engine/Generated/Material.ush, /Engine/Generated/VertexFactory.ush) の中身が分からないため、宣言の一覧が不完全です。
```

uniform buffer の宣言などほかの生成ファイルも欠けていれば、この指摘ではなく [UE0001](UE0001.md) が出ます。

## なぜ問題か

これは「検査していない」ことを伝えるための指摘です。

`Material.ush` と `VertexFactory.ush` は、エンジンがマテリアルと頂点ファクトリごとに作ります。
中に書かれる関数や構造体はマテリアルで変わるので、そのままでは分かりません。宣言の一覧が揃わないので、
宣言が見つからないことを根拠にするルール (HL0301 / HL0310 / HL0315 など) は検査を見送ります。

型の検査など、取り込んだ先を見なくてよい検査は行います。

## どう直すか

`--unreal-generate` で C++ から生成されるファイルを作り、`unreal: generated` に書いてください
([Unreal Engine の環境](../guide/environments.md#c-から生成されるファイルを作る))。
`Material.ush` と `VertexFactory.ush` の代わりも作るので、マテリアルのシェーダーでも宣言を検査します (この指摘は出なくなります)。

作らずに知らせだけが要らなければ、設定ファイルでこのルールを無効にしてください。

```yaml
rules:
  UE0002: none
```

無効にしても、マテリアルのシェーダーで宣言の検査が働いていないことは変わりません。

## 誤検出だと思ったら

マテリアルのシェーダーでないのに出るなら、取り込んでいるヘッダのどれかが `Material.ush` を取り込んでいます。
`--inspect` で取り込みの経路を確かめられます。
