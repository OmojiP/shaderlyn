# UE0002: マテリアルのシェーダーが取り込む生成ファイルが無いため、一部の検査を行っていません

分類: Usage / 既定の重要度: 情報

Unreal Engine の環境 (`environment: unreal`) だけで出ます。

## 何を検出するか

`/Engine/Generated/Material.ush` か `/Engine/Generated/VertexFactory.ush` を (ヘッダを経由しても) 取り込むシェーダー、
つまりマテリアルのシェーダーで、この 2 つが見つからないときに出ます。
`--unreal-generate` で生成ファイルを作っていない (設定ファイルに `unreal: generated` が無い) ときがこれにあたります。

```
BasePassPixelShader.usf(1:1): info UE0002: 宣言が無いことを根拠にする検査 (CF0301 / CF0310 など) を行っていません。マテリアルのシェーダーが取り込む生成ファイル (/Engine/Generated/Material.ush, /Engine/Generated/VertexFactory.ush) が無いため、宣言の一覧が不完全です。
```

uniform buffer の宣言などほかの生成ファイルも欠けていれば、この指摘ではなく [UE0001](UE0001.md) が出ます。

## なぜ問題か

これは「検査していない」ことを伝えるための指摘です。

`Material.ush` と `VertexFactory.ush` は、エンジンがマテリアルと頂点ファクトリごとに作ります。ディスクには無いので、そのままでは中身が分かりません。
中で宣言される関数や変数が分からないので、「無い」と言い切る検査はそのシェーダーでは行いません。

| 検査 | ルール |
| --- | --- |
| エントリポイントがあるか | CF0301 / HL0303 / HL0304 |
| 名前・変数・関数の定義があるか | CF0310 / CF0311 / CF0315 |
| 呼び出しの引数と多重定義の照合 | CF0401 / CF0402 / CF0403 / CF0405 / HL0345 など |

型の不一致・構文・構造体のメンバー (CF0312 / CF0313) など、取り込んだ先を見なくてよい検査は行います。

## どう直すか

`--unreal-generate` で生成ファイルを作り、`unreal: generated` に書いてください
([Unreal Engine の環境](../guide/environments.md#c-から生成されるファイルを作る))。
`Material.ush` と `VertexFactory.ush` の代わりも作るので、この指摘は出なくなり、上の検査をすべて行います。

作った `Material.ush` は、どのマテリアルでもない代わりです。マテリアルのノードが書くコード (カスタムノードなど) は入らないので、
それに関わる誤りは見つけられません。

生成ファイルを作らずに、知らせだけが要らなければ、設定ファイルでこのルールを無効にしてください。
無効にしても、上の検査を行っていないことは変わりません。

```yaml
rules:
  UE0002: none
```

## 誤検出だと思ったら

マテリアルのシェーダーでないのに出るなら、取り込んでいるヘッダのどれかが `Material.ush` を取り込んでいます。
`--inspect` で取り込みの経路を確かめられます。

生成ファイルを作ってあるのに出るなら、0.3.0 より前の `--unreal-generate` で作ったものです。作り直してください。
