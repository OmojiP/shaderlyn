# GD0102: 描画のモードかステンシルのモードが正しくありません

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

Godot シェーダー言語のファイルの `render_mode` か `stencil_mode` に、次のものを書いている状態です。Godot はコンパイルの誤りにします。

- そのシェーダーの種類に存在しないモード (`canvas_item` の `cull_back`、`sky` の `unshaded` など)
- 同じモードを 2 度 (別の `render_mode` の行に書いたものも数えます)
- 同じモードの別の選択肢 (`blend_mix` と `blend_add`、`cull_back` と `cull_front`、`compare_equal` と `compare_less`)
- 2 つ目のステンシルの参照値と、255 を超える参照値

```glsl
shader_type spatial;

render_mode nope;                       // 知らないモード
render_mode blend_mix, blend_add;       // blend はすでに mix
stencil_mode read, compare_equal, 256;  // 参照値は 0 から 255
```

使用できるモードの表は Godot 4.7.2 のソース (`servers/rendering/shader_types.cpp`) から作りました。

## なぜ問題か

Godot がシェーダーをコンパイルできず、マテリアルが描画されません。

## 修正方法

そのシェーダーの種類のモードを 1 度ずつ書いてください。モードの一覧は Godot の文書の、シェーダーの種類ごとのページにあります。

## 誤検出だと思ったら

`.gdshaderinc` では、どのシェーダーの種類のモードも書けるものとして調べます (Godot と同じです)。
Godot は、選択肢が存在しないモードを名前で始まるかだけで調べます (`unshaded_x` も通ります)。Shaderlyn も同じです。
