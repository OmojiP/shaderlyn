# GL0201: 精度を決めていない型です

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

GLSL ES のファイルで、既定の精度の無い型を、精度の修飾子を付けずに宣言している状態です。glslang はコンパイルの誤りにします。

```glsl
#version 300 es
out vec4 color;          // フラグメントシェーダーの float には既定の精度が無い

void main() { color = vec4(1.0); }
```

ES の既定の精度は次のとおりです (glslang と同じ)。

| 型 | フラグメントシェーダー | ほかのステージ |
| --- | --- | --- |
| `float` (`vec4`、`mat3` などを含む) | 無い | `highp` |
| `int` / `uint` | `mediump` | `highp` |
| `sampler2D` / `samplerCube` / `samplerExternalOES` | `lowp` | `lowp` |
| ほかのサンプラー・テクスチャ・イメージ (`sampler3D`、`image2D` など) | 無い | 無い |

変数・仮引数・関数の戻り値・構造体とブロックのメンバーの宣言を検査します。
デスクトップの GLSL では既定がすべて `highp` なので、報告しません。

## なぜ問題か

glslang と、GLSL ES のドライバーのコンパイラがコンパイルを止めます。

## どう直すか

ファイルの始めで既定の精度を決めるか、宣言に精度を付けてください。

```glsl
#version 300 es
precision mediump float;
out vec4 color;
```

`precision mediump float;` は、書いた位置より後ろの宣言に効きます。
