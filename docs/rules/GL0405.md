# GL0405: 組み込み関数を宣言し直せません

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

ES の GLSL のファイルで、組み込み関数を宣言し直している状態です。glslang はコンパイルの誤りにします。

```glsl
#version 300 es
precision mediump float;
layout(location = 0) out vec4 color;

float sin(float x) { return x; }   // 組み込み関数 sin と同じ形
bool radians(bool x) { return x; } // 3.00 以降は、形が違っても組み込み関数と同じ名前にできない
float tan;                         // 3.00 以降は、関数の外の変数にも組み込み関数の名前を使えない

void main()
{
    color = vec4(sin(1.0));
}
```

- ES の全バージョンで、組み込み関数と同じ形 (仮引数の型の並び) の関数は宣言できません
- ES の 3.00 以降では、組み込み関数と同じ名前の関数 (形が違うものを含む) と、関数の外の変数も宣言できません

デスクトップ (ES でない GLSL) では、組み込み関数を同じ形で宣言し直すことも、同じ名前で多重定義することもできます。報告しません。

## なぜ問題か

glslang (Vulkan の SDK の `glslangValidator` と `glslc`) がコンパイルを止めます。

## どう直すか

関数か変数の名前を変えてください。

```glsl
float mySin(float x) { return x; }
```
