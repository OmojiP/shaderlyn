# SG0316: static const の初期値には定数式が必要です

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

Slang のファイルで、関数の外の `static const` の初期値に、定数でない値を使っている状態です。slangc はコンパイルの誤り (E31226) にします。

```slang
uniform float foo;
cbuffer CB { float Value; }
int getX() { return 1; }

static const float a = foo * 2.0;    // uniform の値
static const float b = Value;        // 定数バッファーのメンバー
static const int c = getX();         // 利用者の関数の呼び出し
static const float pi = float.getPi();   // 型の static のメソッドはよい
```

定数でない値は、uniform・定数バッファーのメンバー・`static const` でない関数の外の変数の値と、利用者の関数やメソッドの呼び出しです。特殊化定数の値は使えます。

## なぜ問題か

`static const` の値はコンパイルのときに決まらなければなりません。slangc がコンパイルできません。

## どう直すか

初期値を定数とリテラルだけで書くか、`static const` をやめて関数の中で値を求めてください。
