# GL0321: switch と break / continue の書き方が正しくありません

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

GLSL のファイルで、glslang が誤りにする `switch` の組み立てと、`break` / `continue` の置き場所です。

- `case` / `default` を、`switch` の波括弧の中にそのまま書いていないもの (波括弧や `if` の中、`switch` の外)
- 同じ値の `case` と、2 つ目の `default`
- 最初の `case` / `default` より前の文
- 最後の `case` / `default` の後に文が無い `switch` (ES の 3.00 まで・3.20 から、デスクトップの 4.30 まで・4.60 から。ほかのバージョンでは glslang の警告なので報告しません)
- ループと `switch` の外の `break`、ループの外の `continue`

```glsl
#version 450
layout(location = 0) out vec4 color;
uniform int mode;

void main()
{
    color = vec4(0.0);
    switch (mode)
    {
        color = vec4(1.0);      // 最初の case より前の文
    case 0:
        if (color.r > 0.5)
        {
        case 1:                 // if の中の case
            color.g = 1.0;
        }
        break;
    case 0:                     // 同じ値の case
        break;
    default:                    // 後ろに文が無い
    }
    continue;                   // ループの外の continue
}
```

glslang は、初期値の無い変数の宣言と空の文 (`;`) を文として数えません。`default: int x;` で終わる `switch` は、最後のラベルの後に文が無いものとして扱います。
`case` の値は、両方が定数に決まるときだけ比べます。

## なぜ問題か

glslang (Vulkan の SDK の `glslangValidator` と `glslc`) がコンパイルを止めます。
C と違い、GLSL の `case` は `switch` の波括弧の中にそのまま書かなければなりません。

## どう直すか

`case` / `default` を `switch` の波括弧の中に移し、最初のラベルより前の文はラベルの後か `switch` の前へ移してください。
最後のラベルの後には `break;` を書いてください。
ループの外の `break` / `continue` は、`return` にするか消してください。
