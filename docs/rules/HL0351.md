# HL0351: return の値が戻り値の型と合いません

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

`return` が返している値が、関数の戻り値の型と噛み合っていない状態です。
3 つの形があります。

```hlsl
float3 widen(float2 uv) { return uv; }   // 成分が足りない
void   bad()            { return 1; }    // void が値を返している
float3 empty()          { return; }      // 値を返す関数が値なしで return
```

正しいものは報告しません。

```hlsl
float2 narrow(float3 v) { return v; }    // 切り捨て。警告は出るが通る ([HL0353](HL0353.md) 参照)
float3 splat()          { return 1; }    // スカラーは全成分へ複製される
void   nothing()        { return; }
```

## なぜ問題か

コンパイルに失敗します。

戻り値の型を変えたときに `return` を直し忘れると現れます。

## どう直すか

戻り値の型に合わせてください。

```hlsl
float3 widen(float2 uv) { return float3(uv, 0); }
```

## 構成によって型が変わる場合

同じ名前を条件ごとに違う型で宣言している場合も、構成ごとに型を求めて判定します。

```hlsl
float3 Widen()
{
    #pragma multi_compile _A _B

    #if defined(_A)
    float3 a = float3(1, 2, 3);
    #elif defined(_B)
    float2 a = float2(1, 2);
    #endif

    return a;   // _B のとき float2 を float3 へ渡している
}
```

この場合、どの構成で起きるかを添えて報告します。

```
関数 'Widen' の戻り値は float3 ですが、float2 を返しています。
_B のとき、この式は float2 です。
```

成分が落ちるだけで渡せはする場合は、このルールではなく
[HL0353](HL0353.md) が警告として報告します。

## 誤検出だと思ったら

このルールは次の場合に発火しません。

- 返している式の型が分からない場合。
  構成を決めても分からない場合を含みます
- そのシェーダー自身が書いた関数でない場合
- 調べる構成が多すぎる場合。1 つの式につき 16 通りまでを見ます

関数の末尾に `return` が無い場合は [HL0360](HL0360.md) が報告します。
