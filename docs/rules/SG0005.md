# SG0005: UTF-8 として認識できないバイトがあります

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

Slang のファイルに、UTF-8 として認識できないバイトの並びがある状態です。Shift_JIS や Latin-1 で保存したファイルの、ASCII でない文字がこうなります。
コメントの中も含みます。slangc はソースを UTF-8 として扱うため、字句の誤り (E10006) にします。

行ごとに、最初の認識できないバイトの位置に 1 つ報告します。ファイルに書いた本物の置き換え文字 (U+FFFD) は報告しません。

## なぜ問題か

slangc がファイルを読み込めません。

## 修正方法

ファイルを UTF-8 で保存し直してください。
