# HL0354: HLSL 2021 では for の変数をループの外で使用できません

分類: Portability / 既定の重要度: 情報

## 何を検出するか

`for` の初期化で宣言した変数を、ループの後で使っている箇所です。

```hlsl
float s = 0;
for (int i = 0; i < 4; i++) { s += i; }
return s + i;    // 報告する。i は for の初期化で宣言した変数
```

## なぜ問題か

FXC (Unity の既定) と DXC の HLSL 2021 より前では、`for` の初期化で宣言した変数を、ループを囲む波括弧の外でも使えます。
そのため、現在の環境ではコンパイルできます。HLSL 2021 は C++ と同じく変数の有効範囲をループ内に限るため、DXC の HLSL 2021 へ移すとエラーになります
(`use of undeclared identifier 'i'`)。手元の FXC と DXC 1.8 で確かめました。

## どう直すか

ループの前で宣言してください。

```hlsl
int i;
for (i = 0; i < 4; i++) { s += i; }
return s + i;
```

## 環境による違い

コードをコンパイルするコンパイラのどれかが FXC か DXC の HLSL 2021 より前のときに報告します (Unity、Unreal、`hlsl: version` が 2021 より前)。
どれも HLSL 2021 なら、名前が見つからないので [CF0310](CF0310.md) (エラー) になります。
