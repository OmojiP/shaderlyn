# GD0317: 定数の式が必要です

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

Godot シェーダー言語のファイルで、`const` の初期値に定数でないものを書いている状態です。Godot はコンパイルの誤りにします。

```glsl
shader_type spatial;

uniform float u;
const float A = u;               // uniform は定数でない

float f() { return 1.0; }

void fragment() {
    float a = 1.0;
    const float b = a;           // const でない変数
    const float c = f();         // 利用者の関数の呼び出し
}
```

`const` の初期値には、リテラル・ほかの `const`・値の作成・演算・組み込み関数の呼び出し (`sin(1.0)`)・組み込みの変数 (`TIME`) を書けます (Godot 4.7.2 で確認しました)。

## なぜ問題か

Godot がシェーダーをコンパイルできず、マテリアルが描画されません。

## どう直すか

`const` を外して、ふつうの変数にしてください。

## 誤検出だと思ったら

名前が条件によって違う宣言を指すときは、すべてが定数でないときだけ報告します。
