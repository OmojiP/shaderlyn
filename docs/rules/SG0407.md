# SG0407: この宣言には使用できない型です

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

Slang のファイルで、宣言に使用できない型を使用している状態です。slangc はコンパイルの誤り (E30009・E31300・E31301・E32000・E31218・E38024・E41001・E38050) にします。

```slang
struct S
{
    int a : 33;                   // ビットフィールドの幅が型の幅 (32) を超える
    float b : 10;                 // ビットフィールドの型が整数でない
}

enum Bad : float { A, B }         // 列挙型の基の型が整数でない

[vk::constant_id(1)]
const int2 v;                     // 特殊化定数がスカラーでも列挙型でもない

void f()
{
    void a;                       // 変数の型に void
}
```

`enum E : bool` と、`uint8_t` などの大きさを書いた整数のビットフィールドは書けます。typedef の別名のビットフィールドは見ません。

SV_DispatchThreadID・SV_GroupID・SV_GroupThreadID の仮引数は、int か uint の 1 から 3 個の成分でなければなりません (`float3`・`uint4` は E38024)。

フィールドを通して自分を値として含む構造体も誤りです (E41001)。大きさが決まりません。ポインターのフィールド (`Node* next`) と class は通ります。

```slang
struct TA { TB tb; }
struct TB { TA ta[2]; }          // TA と TB が互いを含む
struct Outer { Outer next; }      // 自分を含む
```

エントリポイントの入力と出力 (仮引数と戻り値) に受け渡せない型も誤りです (E38050)。

```slang
[shader("vertex")]
float4 main(Atomic<int> a : A) : SV_Position;           // Atomic・DifferentialPair・DifferentialPtrPair はどのステージにも受け渡せない

[shader("vertex")]
void main(out OutputVertices<V, 3> verts);              // OutputVertices などはメッシュシェーダーだけ

[shader("vertex")]
void main(LineStream<int> s);                           // ストリームはジオメトリシェーダーだけ

[shader("mesh")] [outputtopology("triangle")] [numthreads(1, 1, 1)]
void main(OutputVertices<V, 3> v, out OutputIndices<uint4, 1> t);   // OutputIndices の要素は uint・uint2・uint3

[shader("vertex")]
float4 main(matrix<float, 4, 5> m : A) : SV_Position;   // 行列の行と列は 1 から 4
```

`CoopVec`・`CoopMat` は、頂点シェーダーとピクセルシェーダーの入力と出力に受け渡せません。
構造体のフィールドの型が受け渡せない場合も、その構造体を受け渡す仮引数か関数に報告します (slangc と同じ)。
`uniform` の仮引数は入力と出力ではないので見ません。エントリポイントのステージは [CF0302](CF0302.md) と同じく決めます。

## なぜ問題か

slangc がコンパイルできません。

## どう直すか

ビットフィールドは、型の幅に収まる幅の整数にしてください。列挙型の基の型は整数にしてください。
特殊化定数は、スカラーか列挙型の値を 1 つずつ宣言してください。
