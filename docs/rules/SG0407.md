# SG0407: この宣言には使えない型です

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

Slang のファイルで、宣言に使えない型を使っている状態です。slangc はコンパイルの誤り (E30009・E31300・E31301・E32000・E31218) にします。

```slang
struct S
{
    int a : 33;                   // ビットフィールドの幅が型の幅 (32) を超える
    float b : 10;                 // ビットフィールドの型が整数でない
}

enum Bad : float { A, B }         // 列挙型の基の型が整数でない

[vk::constant_id(1)]
const int2 v;                     // 特殊化定数がスカラーでも列挙型でもない

void f()
{
    void a;                       // 変数の型に void
}
```

`enum E : bool` と、`uint8_t` などの大きさを書いた整数のビットフィールドは書けます。typedef の別名のビットフィールドは見ません。

## なぜ問題か

slangc がコンパイルできません。

## どう直すか

ビットフィールドは、型の幅に収まる幅の整数にしてください。列挙型の基の型は整数にしてください。
特殊化定数は、スカラーか列挙型の値を 1 つずつ宣言してください。
