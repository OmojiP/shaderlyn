# UN0201: コンパイラの指定が無視されます

分類: Correctness / 既定の重要度: 警告

## 何を検出するか

`#pragma use_dxc` / `require` のうち、Unity が認識しない、または効かない場所に書いたために無視されるものです。
この指定では DXC に切り替わらず、ほかに DXC の指定が無ければ FXC でコンパイルされます。

| 書いたもの | 報告する条件 | 直し方 |
| --- | --- | --- |
| `use_dxc d3d12` | いつでも | DX12 を DXC にするなら、Unity 6.6 以降は `dx12`、6.5 以前は `d3d11` を書く (`d3d11` は DX11 も DXC にするため、DX11 では動作しない) |
| `use_dxc dx12` | Unity 6.5 以前 | 6.5 以前で DX12 を DXC にするなら `d3d11` を書く (DX11 も DXC になるため、DX11 では動作しない) |
| include ファイルの中の `use_dxc` / `require` | Unity 2023.2 以降 | コードブロックか `HLSLINCLUDE` に移す。報告はコードブロックの開始の語に出す |
| `require inlineraytracing` | Unity 2022.3 | inlineraytracing は Unity 6.4 以降で使う |

```
Assets/Shaders/A.shader(14:29): warning UN0201: use_dxc の API 名 d3d12 は、どのバージョンの Unity でも認識されず、DXCが使用されません。
    ほかに DXC の指定が無ければ FXC でコンパイルされます。
    Graphics API for Windows: DX12 で DXC を使用する場合、Unity 6.6 以降は dx12、6.5 以前は d3d11 を指定してください (d3d11 は Graphics API for Windows: DX11/DX12 どちらもDXCコンパイルするため、DX11 では動作しません)。
```

文は「何が起きているか」「何でコンパイルされるか」「どう直すか」の順です (include ファイルの中の指定と 2022.3 の `inlineraytracing` は 2 文)。規則は Unity 2022.3〜6.6 (DX11 / DX12 / Vulkan) で確かめました。

## なぜ問題か

DXC でしか使えない機能 (64 ビットの整数、ウェーブの命令など) を使うつもりで DXC を指定しても、FXC でコンパイルされます。
FXC はその機能を知らないので、コンパイルエラーになるか、意図しない書き方で通ります。
Unity はこの指定を無視したことを伝えません (`inlineraytracing` の 2022.3 だけは「unknown feature」の警告を出します)。

## 環境による違い

Unity の環境だけで動きます。バージョンで変わるものは、Unity のバージョンが分かるとき
(`--unity-project` のプロジェクトの `ProjectVersion.txt`、または設定の `unity: version`) だけ報告します
([設定](../guide/configuration.md#シェーダーのコンパイラ))。

## 関連

コンパイラの指定の誤りは、直し方の種類で ID を分けています。DX12 だけを対象にするプロジェクトは UN0203 だけを無効にできます。

- [UN0203](UN0203.md) — DX11 で使えなくなる指定
- [UN0204](UN0204.md) — Unity のバージョンでコンパイラが変わる指定
- [UN0202](UN0202.md) — コンパイラの指定についての注意
- [HL0003](HL0003.md) — この環境では使えない構文
