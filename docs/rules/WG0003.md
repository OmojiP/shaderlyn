# WG0003: 無い拡張の名前です

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

WGSL のファイルで、`enable` か `requires` に naga が知らない拡張の名前を書いている状態です。naga はコンパイルの誤りにします。

```wgsl
requires buffer_view;   // 言語の拡張は packed_4x8_integer_dot_product など
enable f61;             // enable の拡張は f16・subgroups など
```

naga 30 が知っている名前は次のものです。

- `enable`: `clip_distances`・`draw_index`・`dual_source_blending`・`f16`・`primitive_index`・`subgroups`・`wgpu_binding_array`・`wgpu_cooperative_matrix`・`wgpu_int16`・`wgpu_mesh_shader`・`wgpu_per_vertex`・`wgpu_ray_query`・`wgpu_ray_query_vertex_return`・`wgpu_ray_tracing_pipeline`
- `requires`: `packed_4x8_integer_dot_product`・`pointer_composite_access`・`readonly_and_readwrite_storage_textures`・`unrestricted_pointer_parameters`

## なぜ問題か

シェーダーモジュールを作れず、パイプラインが作られません。

## どう直すか

名前の綴りを修正するか、その拡張を使用しない書き方にしてください。ブラウザーの WebGPU は、naga と違う拡張を持つことがあります。

## 誤検出だと思ったら

naga (wgpu) より新しい実装の拡張は知りません。naga で使用しないシェーダーの場合は、設定ファイルでこのルールを止めてください。
