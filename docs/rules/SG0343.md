# SG0343: 条件に代入は書けません

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

Slang のファイルで、`if`・`while`・`for`・`do` の条件に、括弧で包まない代入を書いている状態です。slangc はコンパイルの誤り (E30057) にします。

```slang
void f(int a)
{
    if (a = 0) { }             // 誤り
    while (a = next()) { }     // 誤り
    if ((a = 0)) { }           // 括弧で包めばコンパイルできる
    bool b = (a = 1) ? true : false; // ?: の条件は見ない
}
```

## なぜ問題か

`==` の書き間違いであることが多いので、slangc は括弧で包まない代入を条件に認めません。

## どう直すか

等しいかどうかを判定するには `==` を使用してください。代入した値を条件に使用する場合は、代入を括弧で包んでください (`if ((a = next()))`)。
