# SG0341: 取り除かれた宣言を使用しています

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

Slang のファイルで、`[RemovedSince(バージョン, "説明")]` を書いた宣言を使用している状態です。
バージョンがファイルの言語のバージョン (`#language slang 2026` など。書かなければ slangc 2026.19 の既定の 2025) 以下の場合は、その宣言は取り除かれています。slangc はコンパイルの誤り (E31207) にします。

```slang
[RemovedSince(-1, "This struct is removed")]
struct RemovedStruct { int x; }

void f()
{
    RemovedStruct s;     // 取り除かれた構造体
}
```

バージョンの `-1` は、いつも取り除かれていることを表します。

言語のバージョン 2026 (`#language slang 2026`) では、ベクトルを含んで成分が不足している値の作成 (`float4(v.xy, 1)`) と並び (`int4 v = { int2(1, 2), 3 };`) も、
取り除かれた書き方として報告します (E31207)。2025 では非推奨の警告 ([CF0404](CF0404.md)) です。

## なぜ問題か

slangc がコンパイルできません。取り除かれた宣言は、ライブラリが使用しないように決めたものです。

## 修正方法

説明に書かれた代わりの宣言を使用してください。

## 誤検出だと思ったら

多重定義の一部だけが取り除かれた関数は、どれを呼ぶか決められないので検査しません。
