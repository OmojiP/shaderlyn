# SG0341: 取り除かれた宣言を使っています

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

Slang のファイルで、`[RemovedSince(版, "説明")]` を書いた宣言を使っている状態です。
版がファイルの言語のバージョン (`#language slang 2026` など。書かなければ slangc 2026.19 の既定の 2025) 以下なら、その宣言は取り除かれています。slangc はコンパイルの誤り (E31207) にします。

```slang
[RemovedSince(-1, "This struct is removed")]
struct RemovedStruct { int x; }

void f()
{
    RemovedStruct s;     // 取り除かれた構造体
}
```

版の `-1` は、いつも取り除かれていることを表します。

## なぜ問題か

slangc がコンパイルできません。取り除かれた宣言は、ライブラリが使わないように決めたものです。

## どう直すか

説明に書かれた代わりの宣言を使ってください。

## 誤検出だと思ったら

多重定義の一部だけが取り除かれた関数は、どれを呼ぶか決められないので検査しません。
