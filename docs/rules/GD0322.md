# GD0322: ステージ関数の形が正しくありません

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

Godot シェーダー言語のファイルで、ステージ関数に仮引数を書いたか、戻り値を `void` 以外にした状態です。Godot はコンパイルの誤りにします。

ステージ関数は、シェーダーの種類 (`shader_type`) ごとに決まっています。

| シェーダーの種類 | ステージ関数 |
| --- | --- |
| `spatial` / `canvas_item` | `vertex`・`fragment`・`light` |
| `particles` | `start`・`process` |
| `sky` | `sky` |
| `fog` | `fog` |

```glsl
shader_type spatial;

void fragment(float x) {     // 仮引数は書けない
}

float light() {              // 戻り値は void
    return 1.0;
}
```

ほかの種類のステージ関数の名前 (`particles` のシェーダーの `fragment`) は、ただの利用者の関数なので報告しません。

## なぜ問題か

Godot がシェーダーをコンパイルできず、マテリアルが描画されません。

## どう直すか

仮引数を消し、戻り値を `void` にしてください。値は組み込みの変数 (`ALBEDO` など) に書きます。
