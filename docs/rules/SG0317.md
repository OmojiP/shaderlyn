# SG0317: 定数の初期値が自分自身に依っています

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

Slang のファイルで、`static const` の初期値が、直接か、同じ入れ物 (ファイルの直下か同じ構造体) のほかの `static const` を通して、自分自身の値を使用している状態です。slangc はコンパイルの誤りにします。

```slang
struct S
{
    static const int kVal = kVal;       // 自分自身
    static const int kA = kB;           // kA → kB → kA
    static const int kB = kA;
}
```

ジェネリックの型の static const の初期値が、同じ型の別の特殊化の同じ定数を読み取り (`static const int value = Loop<x + 1>::value;`)、その型の外で値を読み取るもの (`Loop<0>::value`) も報告します。
値を求めるのが終わらないので、slangc は「recursive generic evaluation exceeded maximum depth」(E39998) にします。条件で止めるもの (`? :`) は見ません。

```slang
struct Loop<let x : int>
{
    static const int value = Loop<x + 1>::value;   // 終わりの条件が存在しない
}
int useValue = Loop<0>::value;
```

## なぜ問題か

値が決まらないので、slangc がコンパイルできません。

## どう直すか

どれかの定数の初期値を、ほかの定数に依らない値にしてください。
