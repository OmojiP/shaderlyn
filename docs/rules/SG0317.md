# SG0317: 定数の初期値が自分自身に依っています

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

Slang のファイルで、`static const` の初期値が、直接か、同じ入れ物 (ファイルの直下か同じ構造体) のほかの `static const` を通して、自分自身の値を使っている状態です。slangc はコンパイルの誤りにします。

```slang
struct S
{
    static const int kVal = kVal;       // 自分自身
    static const int kA = kB;           // kA → kB → kA
    static const int kB = kA;
}
```

## なぜ問題か

値が決まらないので、slangc がコンパイルできません。

## どう直すか

どれかの定数の初期値を、ほかの定数に依らない値にしてください。
