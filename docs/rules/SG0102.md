# SG0102: この修飾子はここに書けません

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

Slang のファイルで、修飾子をその宣言に書けない状態です。slangc はコンパイルの誤り (E31224・E31201) にします。

```slang
const float k = 1.0;              // 関数の外の const には static が要る (static const)
constexpr uint N = 4;             // constexpr も同じ (static constexpr)
uniform float u = 2.0;            // uniform に初期値は書けない

struct S
{
    __ref float r;                // 構造体のフィールドに __ref は書けない
}

void f()
{
    groupshared int a;            // 局所変数に groupshared は書けない (static groupshared は書ける)
}
```

次のものも誤りです (E30623・E30078・E20019・E20017・E31219・E31220)。

```slang
groupshared uint shared = 1;      // groupshared に初期値は書けない
globallycoherent int* p;          // ポインターに coherent / globallycoherent は書けない
typedef volatile float VF;        // typedef に volatile は書けない
constexpr int* q;                 // C の書き方のポインターに constexpr は書けない
[vk::constant_id(1)]
static const int x = 2;           // 特殊化定数は static にできない
[push_constant]
[vk::constant_id(2)]
const int y;                      // push constant と特殊化定数の両方にはできない
__magic_type(FloatType)
struct MyFloat { }                // slangc の標準のモジュールにだけ書ける修飾子 (E31229)
[MaybeDifferentiable]
float bar(float x);               // [MaybeDifferentiable] はインターフェイスの要件にだけ書ける (E30314)
```

インターフェイスの要件に `[TreatAsDifferentiable]` は書けません (E30313)。

同じ関数に、1 つしか書けない属性 (`[numthreads]`・`[shader]`・`[NodeLaunch]` など) を 2 度書くことと、可視性 (`public`・`internal`・`private`) を 2 つ書くことも誤りです (E31202)。

特殊化定数 (`[vk::constant_id(0)]`・`[vk::specialization_constant]`・`[SpecializationConstant]`・`layout(constant_id = 0)`) の `const` には、初期値を書けます。
GLSL の書き方のファイル (`#version` のあるもの) は検査しません。

## なぜ問題か

slangc がコンパイルできません。Slang では、関数の外の `static` の無い `const` は uniform (アプリケーションから値が入る) になります。

## どう直すか

定数なら `static const` と書いてください。uniform の値はアプリケーションから入れます。
