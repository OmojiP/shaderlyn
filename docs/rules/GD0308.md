# GD0308: 配列の大きさが正しくありません

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

Godot シェーダー言語のファイルで、配列の大きさが正しくない状態です。Godot はコンパイルの誤りにします。

```glsl
shader_type spatial;

uniform float u[];               // uniform・varying・構造体のメンバー・仮引数・戻り値では大きさを省けない
void f(float x[]) {}

void fragment() {
    int n = 2;
    float a[0];                  // 大きさは正の整数の定数
    float b[2.0];
    float c[n];                  // 変数は書けない
}
```

大きさには、正の整数のリテラル (`2`、`2u`、`0x2`) と、整数の `const` を使った式 (`N + 1`) を書けます。
大きさを省けるのは、`{ … }` で初期化する局所変数と `const` だけです (`float a[] = { 1.0, 2.0 };`)。

## なぜ問題か

Godot がシェーダーをコンパイルできず、マテリアルが描画されません。

## どう直すか

大きさを正の整数の定数で書いてください。

## 誤検出だと思ったら

`const` の値が式で決まり、Shaderlyn が計算できないときは、大きさの値を調べません。
