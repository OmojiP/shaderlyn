# SG0321: switch と break / continue の書き方が正しくありません

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

Slang のファイルで、次のどれかを書いている状態です。slangc はコンパイルの誤りにします。

- `case` か `default` を、`switch` の本体の直下でない場所 (`switch` の外、`case` の中の `{ }` の中) に書いた
- `break` をループと `switch` の外に、`continue` をループの外に書いた
- 1 つの `switch` に `default` を 2 つ書いた
- 1 つの `switch` に、値の同じ `case` を 2 つ書いた (列挙子は値で比較します)
- `switch` の値が、整数でも列挙型でもない (`float` など)
- `case` の値が、定数でない変数 (uniform・仮引数・const でない局所変数。E39999)

```slang
enum F { X = 1, Y = 1 }

void f(uint i, float v)
{
    case 0:                    // switch の外
    break;                     // ループと switch の外
    switch (i)
    {
    case 0:
        {
        case 1:                // case の中の { } の中
            break;
        }
    case F.X: break;
    case F.Y: break;           // F.X と同じ値 (1)
    default: break;
    default: break;            // 2 つ目の default
    }
    switch (v) { }             // float の値
}
```

## なぜ問題か

slangc がコンパイルできません。HLSL の DXC は、入れ子のブロックの中の `case` も解析しますが、Slang は解析しません。

## 修正方法

`case` と `default` を `switch` の本体の直下に移してください。`break` と `continue` はループの中 (`break` は `switch` の中でも可) に書いてください。
重なる `case` と 2 つ目の `default` は、1 つにまとめてください。`switch` の値は整数か列挙型にしてください (`switch ((int)v)`)。
