# SG0321: case と default は switch の本体にだけ書けます

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

Slang のファイルで、`case` か `default` を、`switch` の本体の直下でない場所に書いている状態です。slangc はコンパイルの誤りにします。

```slang
void f(uint i)
{
    case 0:                    // switch の外
    switch (i)
    {
    case 0:
        {
        case 1:                // case の中の { } の中
            break;
        }
    default:
        break;
    }
}
```

## なぜ問題か

slangc がコンパイルできません。HLSL の DXC は、入れ子のブロックの中の `case` も読みますが、Slang は読みません。

## どう直すか

`case` と `default` を `switch` の本体の直下に移してください。
