# UE0001: エンジンが生成するファイルが無いため、一部の検査を行っていません

分類: Usage / 既定の重要度: 情報

Unreal Engine の環境 (`environment: unreal`) だけで出ます。

## 何を検出するか

ビルドのときにエンジンが生成するファイル (`/Engine/Generated/GeneratedUniformBuffers.ush`、`UniformBuffers/…`、
`GeneratedInstancedStereo.ush` など) を取り込んでいて、そのファイルが無いシェーダーです。

```
MyPass.usf(1:1): info UE0001: 宣言が無いことを根拠にする検査 (HL0301 / HL0310 など) を行っていません。ビルドのときにエンジンが生成するファイル (/Engine/Generated/GeneratedUniformBuffers.ush) の中身が分からないため、宣言の一覧が不完全です。--unreal-generate で C++ から作り、設定ファイルの unreal: generated に書くと検査できます。
```

位置はファイルの先頭です。原因は特定の行ではなく、そのファイルの解析状況そのものにあるためです。

解決できなかった取り込みに、生成されるファイルではないものが混ざっていれば、この指摘ではなく [HL0005](HL0005.md) が出ます。
その場合は `unreal:` の `engine` / `virtual-paths` を確かめてください。

## なぜ問題か

これは「検査していない」ことを伝えるための指摘です。

エンジンは、C++ に書いた uniform buffer の構造体 (`BEGIN_GLOBAL_SHADER_PARAMETER_STRUCT` など) から、
シェーダーをコンパイルする直前に `/Engine/Generated/` の宣言をメモリ上で作ります。ディスクには無いので、そのままでは宣言の一覧が揃いません。
その状態で「宣言されていない」と報告すると、`View.ViewSizeAndInvSize` のような正しい参照を誤りとして指摘することになるため、
宣言が見つからないことを根拠にするルール (HL0301 / HL0310 / HL0315 など) は検査を見送ります。

型の検査など、取り込んだ先を見なくてよい検査は行います。

## どう直すか

エンジンとプロジェクトの C++ から、生成されるファイルを作ってください。

```sh
shaderlyn --config .shaderlyn.yaml --unreal-generate Intermediate/Shaderlyn/Generated
```

書き出したフォルダーを設定ファイルの `unreal: generated` に書くと、`/Engine/Generated` に割り当てて解析します。

```yaml
unreal:
  engine: C:/Program Files/Epic Games/UE_5.5/Engine
  project: .
  generated: Intermediate/Shaderlyn/Generated
```

詳しくは [C++ から生成されるファイルを作る](../guide/environments.md#c-から生成されるファイルを作る) を見てください。

## 誤検出だと思ったら

作ったフォルダーを `unreal: generated` に書いたのに出続けるなら、`--env` で `/Engine/Generated` の割り当てを確かめてください。
エンジンかプロジェクトの C++ を変えたあとは、作り直してください。
