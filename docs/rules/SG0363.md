# SG0363: ジェネリックの型引数が決まりません

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

Slang のファイルで、型引数を書かずにジェネリックの関数を呼んでいて、型の仮引数か値の仮引数が決まらない状態です。slangc はコンパイルの誤り (E30439・E30442・E39999) にします。

仮引数が決まるのは、関数の仮引数の並び (仮引数の型か配列の大きさ) に出てきて実引数から決まるときか、既定の値を書いたときです。

```slang
T pick<T>() { T v; return v; }          // T は戻り値にしか出てこない
void h<let N : int>(int x) { }          // N は仮引数の並びに出てこない
void sum<let N : int>(int a[N]) { }     // N は配列の大きさから決まる

void main()
{
    pick();                             // T が決まらない
    h(3);                               // N が決まらない
    int a[3];
    sum(a);                             // コンパイルできる
}
```

1 つの型の仮引数に、違う型 (片方が構造体) か、違う大きさの配列が当たるものも報告します (E30442)。組み込みの数の型どうし (`int` と `float`) は、変換して合わせるので通ります。

```slang
struct A { int v; }
struct B { int v; }
void foo<T>(T a, T b) { }
void bar<let N : int>(int a[N], int b[N]) { }

void main(A a, B b)
{
    foo(a, b);                          // T に A と B が当たる
    int x[3]; int y[4];
    bar(x, y);                          // N に 3 と 4 が当たる
}
```

次のものも決まりません。

- `where countof(TIndex) == N` の N (並びの数からは決まりません。E39999)。`load<3>(1, 2, 3)` と書いてください
- 関数の型の仮引数 (`f : functype()->vector<float, N>`) の N に、数でも数のベクトルでもない型 (`Array`・構造体) を返すラムダ式か、そういう型の `IFunc<…>` に適合する構造体の値を渡したもの (E30439)。`float`・`int2` を返す関数なら決まります

```slang
func foo<let N : int>(f : functype()->vector<float, N>)->vector<float, N> { return f(); }
void load<let N : int, each TIndex>(expand each TIndex indices) where countof(TIndex) == N {}

void main()
{
    foo(() => Array<int, 2>());           // Array<int, 2> は vector<float, N> にならない
    foo(() => float2(1, 2));              // コンパイルできる (N は 2)
    load(1, 2, 3);                        // N が決まらない
}
```

同じ名前の関数が 2 つ以上あるものと、メソッドの呼び出し (`obj.f()`) は見ません。

## なぜ問題か

slangc は、型引数を実引数の型から決めます (戻り値を受け取る変数の型からは決めません)。決まらなければ、どの型で関数を作るか分かりません。

## 修正方法

型引数を書いてください (`pick<float>()`・`h<4>(3)`)。いつも同じ型の場合は、既定の値を書くこともできます (`T pick<T = float>()`)。
