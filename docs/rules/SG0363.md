# SG0363: ジェネリックの型引数が決まりません

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

Slang のファイルで、型引数を書かずにジェネリックの関数を呼んでいて、型の仮引数か値の仮引数が決まらない状態です。slangc はコンパイルの誤り (E30439) にします。

仮引数が決まるのは、関数の仮引数の並び (仮引数の型か配列の大きさ) に出てきて実引数から決まるときか、既定の値を書いたときです。

```slang
T pick<T>() { T v; return v; }          // T は戻り値にしか出てこない
void h<let N : int>(int x) { }          // N は仮引数の並びに出てこない
void sum<let N : int>(int a[N]) { }     // N は配列の大きさから決まる

void main()
{
    pick();                             // T が決まらない
    h(3);                               // N が決まらない
    int a[3];
    sum(a);                             // 通る
}
```

同じ名前の関数が 2 つ以上あるものと、メソッドの呼び出し (`obj.f()`) は見ません。

## なぜ問題か

slangc は、型引数を実引数の型から決めます (戻り値を受け取る変数の型からは決めません)。決まらなければ、どの型で関数を作るか分かりません。

## どう直すか

型引数を書いてください (`pick<float>()`・`h<4>(3)`)。いつも同じ型なら、既定の値を書くこともできます (`T pick<T = float>()`)。
