# WG0338: 戻り値を使わなければならない関数です

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

WGSL のファイルで、`@must_use` を書いた関数を、戻り値を使わずに文として呼んでいる状態です。naga はコンパイルの誤りにします。

```wgsl
@must_use
fn use_me(a: i32) -> i32 { return 10; }

fn useless() -> i32 {
    use_me(1);     // 戻り値を捨てている
    return 0;
}
```

## なぜ問題か

`@must_use` は、戻り値を使わない呼び出しが誤りであることを示す印です。シェーダーモジュールは作られません。

## どう直すか

戻り値を使ってください。わざと捨てるなら `_ = use_me(1);` と書きます。
