# SG0308: 大きさの決まらない型はここに使用できません

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

Slang のファイルで、大きさの決まらない型を、使用できない場所に使用している状態です。大きさの決まらない型は、大きさを書かない配列 (`int a[]`) と、それを最後のフィールドに持つ構造体です。
slangc はコンパイルの誤り (E30070・E30071・E30072・E30031・E31215) にします。

```slang
struct V
{
    int c[];                      // 最後でないフィールド
    int n;
}

struct W { int n; int data[]; }   // 最後のフィールドなら書ける
struct Q { int id; W w; }         // 大きさの決まらない構造体をフィールドに持つ
StructuredBuffer<W> items;        // StructuredBuffer の要素

cbuffer ubo
{
    float4 values[];              // 定数バッファーのメンバー
}

void f()
{
    float a[];                    // 初期値が存在しない局所変数
    W w;                          // 大きさの決まらない構造体の局所変数
}
```

関数の外の大きさを決めない配列 (`Texture2D textures[];`) と、初期値のある局所の配列 (`int a[] = { 1, 2 };`) は書けます。

## なぜ問題か

slangc がコンパイルできません。大きさの決まらない型は、メモリーの最後にしか置けず、値として作れません。

## どう直すか

配列の大きさを書くか、大きさを決めない配列を外側の構造体の最後のフィールドに置いてください。
StructuredBuffer の要素の中の配列は、大きさを書くか、別のバッファーに分けてください。
