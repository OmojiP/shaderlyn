# GL0401: 予約された名前です

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

GLSL のファイルで、予約された名前の変数・仮引数・ブロックのメンバーを宣言している状態です。glslang はコンパイルの誤りにします。

```glsl
#version 450
layout(location = 0) out vec4 color;

void main()
{
    float gl_scale = 2.0;   // gl_ で始まる名前は宣言できない
    color = vec4(gl_scale);
}
```

予約された名前は次のとおりです (どれも glslang と同じ)。

- `gl_` で始まる名前。ただし、関数の外で組み込みの変数を宣言し直すこと (`gl_ClipDistance`、`gl_FragDepth`、`gl_FragCoord`、`gl_Layer` など決まった名前) は、
  デスクトップの 1.30 以降と、ES の 3.20 以降か `GL_EXT_shader_io_blocks` を有効にしたときにできます。
  組み込みのブロックの宣言し直し (`out gl_PerVertex { … };`) も検査しません
- `__` を含む名前 (ES の 3.00 より前だけ。それ以降とデスクトップは glslang でも警告です)

`GL_EXT_spirv_intrinsics` を有効にしていれば、どちらも宣言できます。

組み込みの変数を宣言し直せる名前は、その版とステージに組み込みの変数があるかまでは確かめません。
無い組み込みの変数を宣言し直していても報告しません。

## なぜ問題か

glslang (Vulkan の SDK の `glslangValidator` と `glslc`) がコンパイルを止めます。
`gl_` で始まる名前は、言語の組み込みの変数と関数のために取ってあります。

## どう直すか

`gl_` で始まらない、`__` を含まない名前に変えてください。

```glsl
float scale = 2.0;
```
