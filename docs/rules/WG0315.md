# WG0315: 数が型に収まりません

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

WGSL のファイルで、数のリテラルがその型の範囲を超えているか、型を書かない整数を範囲に収まらない型に変換している状態です。naga はコンパイルの誤りにします。

```wgsl
const i32min = -0x80000000i;   // 0x80000000i は i32 に収まらない (-2147483648i か i32(-2147483648) と書く)
fn f() {
    let x: u32 = -1;           // -1 は u32 に収まらない
    let y = 1u << -1;          // シフトの量は u32
}
```

型の範囲は、`i32` が -2147483648 から 2147483647、`u32` が 0 から 4294967295 です。型を書かない整数 (AbstractInt) は 64 ビットの符号付きの範囲に収まらなければなりません。

## なぜ問題か

シェーダーモジュールを作れず、パイプラインが作られません。

## 修正方法

範囲に収まる値にするか、大きい型 (`u32`、`i64`) にしてください。
