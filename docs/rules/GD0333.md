# GD0333: 整数のベクトルを 0 で割っています

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

Godot シェーダー言語のファイルで、定数の整数のベクトルを、0 の成分を持つ定数で割っている (か、その剰余を求めている) 状態です。
Godot はコンパイルのときにこの式を計算し、誤りにします。

```glsl
shader_type spatial;

void fragment() {
    ivec2 a = ivec2(4) / ivec2(1, 0);  // 2 番目の成分が 0
    ivec2 b = ivec2(4) / 0;            // スカラーの 0 も同じ
    uvec2 c = uvec2(4u) % uvec2(0u);   // 剰余は uvec も
}
```

Godot 4.7.2 は、スカラーどうしの `4 / 0` と、`uvec` の割り算を誤りにしません。Shaderlyn も同じに扱います。

## なぜ問題か

Godot がシェーダーをコンパイルできず、マテリアルが描画されません。

## どう直すか

割る数を 0 でない値にしてください。

## 誤検出だと思ったら

リテラルと、リテラルだけで作った値 (`ivec2(4)`) の式だけを調べます。`const` の名前を使った式は調べません。
