# GD0104: varying が多すぎます

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

Godot シェーダー言語のファイルで、varying の数が上限を超えている状態です。Godot はコンパイルの誤りにします。

```glsl
shader_type spatial;

varying vec4 a[10];
varying vec4 b[8];   // Forward+ の spatial では、組み込みの 15 と合わせて 33 になり、上限の 32 を超える
```

数え方は Godot 4.7.2 と同じです。

- varying 1 つを 1 と数えます。`float` も `vec4` も 1 です
- 行列は列の数 (`mat3` は 3、`mat4` は 4)、配列は要素の数を掛けます
- Forward+ と Mobile のレンダラーでは、組み込みの varying が先に `spatial` で 15、`canvas_item` で 9 を使います。Compatibility では使いません
- 宣言した順に数え、最初に上限を超えた varying で報告します

上限は 32 とします。本来は GPU で決まり、デスクトップの GPU では Vulkan・D3D12・OpenGL のどれも 32 です。
レンダラーの決め方は [GD0001](GD0001.md) と同じです。

## なぜ問題か

Godot がシェーダーをコンパイルできず、マテリアルが描画されません。

## どう直すか

varying をまとめてください。`float` を 4 つ使っているなら `vec4` 1 つにできます。
フラグメントで計算し直せる値は、varying で渡さずに計算します。

## 誤検出だと思ったら

配列の大きさが整数のリテラルでない (`const` の名前を使った) varying は 1 と数えます。少なく数えるので、誤検出にはなりません。
Metal (上限 31) や携帯機器の GPU では、Godot だけがこのルールの上限より少ない数で誤りにすることがあります。
