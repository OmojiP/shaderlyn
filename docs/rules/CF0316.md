# CF0316: 既定値のある仮引数の後ろに、既定値のない仮引数があります

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

関数の仮引数に既定値を書いた後ろに、既定値のない仮引数を書いている状態です。

```hlsl
float Blend(float a, float b = 1.0, float c)   // 報告する。c に既定値がない
{
    return a * b + c;
}
```

構造体のメソッドと、Slang の名前空間の中の関数も検査します。

## なぜ問題か

コンパイルエラーになります。呼び出しで省略できるのは後ろの実引数だけなので、既定値の後ろに既定値のない仮引数を置けません。
FXC (`X3044: missing default value for parameter 'c'`)・DXC (`missing default argument on parameter 'c'`)・slangc (`E30704`) で確認しました。

## 修正方法

既定値のある仮引数を後ろへ移すか、後ろの仮引数にも既定値を書いてください。

```hlsl
float Blend(float a, float c, float b = 1.0)
```
