# GD0307: 添字が正しくありません

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

Godot シェーダー言語のファイルで、添字 (`a[i]`) が正しくない状態です。Godot はコンパイルの誤りにします。

```glsl
shader_type spatial;

struct S { float a[3]; };

void fragment() {
    float a[2] = { 1.0, 2.0 };
    vec2 v = vec2(1.0);
    S s;
    float b = a[2];        // 配列の長さの外
    float c = v[-1];       // ベクトルの成分の数の外
    float d = s.a[3];      // 構造体のメンバーの配列も調べる
    float e = v[1.0];      // 添字は int か uint のスカラー
    float f = TIME[0];     // float には添字を付けられない
}
```

範囲は、添字がリテラル (`-` を付けたものを含む) のときだけ調べます。`const` の名前を添字にしたもの (`a[K]`) は、Godot も調べません。

## なぜ問題か

Godot がシェーダーをコンパイルできず、マテリアルが描画されません。

## 修正方法

添字を範囲の中にしてください。ベクトルの成分は `v.x` のようにも書けます。

## 誤検出だと思ったら

関数の戻り値の配列と、条件によって違う型になる名前の添字は調べません。
