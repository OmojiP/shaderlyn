# GD0403: その宣言には使用できない型です

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

Godot シェーダー言語のファイルで、宣言に使用できない型を使用している状態です。Godot はコンパイルの誤りにします。

```glsl
shader_type spatial;

struct S { float a; };
uniform S u;                 // uniform に構造体は使用できない
uniform void w;              // void も使用できない
varying sampler2D v;         // varying は数・ベクトル・行列だけ
varying S s;
struct T { sampler2D t; };   // 構造体のメンバーにサンプラーと void は使用できない
struct R { nope n; };        // 型でない名前
```

## なぜ問題か

Godot がシェーダーをコンパイルできず、マテリアルが描画されません。

## どう直すか

構造体の uniform はメンバーごとの uniform に分けてください。サンプラーは uniform か関数の仮引数にだけ書けます。

## 誤検出だと思ったら

構造体のメンバーの型は、その構造体より前に宣言した構造体と組み込みの型だけを型と見なします (Godot と同じです)。
