# GL0102: layout にこの名前はありません

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

GLSL のファイルで、`layout(…)` に GLSL に無い名前か、そのステージでは使えない名前を書いている状態です。glslang はコンパイルの誤りにします。

```glsl
#version 450
layout(location = 0, colour_space) out vec4 color;   // colour_space という名前は無い

void main() { color = vec4(1.0); }
```

```glsl
#version 450
layout(local_size_x = 8) in;   // local_size_x はコンピュート・タスク・メッシュのシェーダーの名前。頂点シェーダーには無い

void main() { gl_Position = vec4(1.0); }
```

値を取る名前 (`location`、`binding` など) に値を書いていないときと、値を取らない名前 (`std140` など) に値を書いたときも当たります。
名前は glslang と同じく、大文字と小文字を区別しません。

## なぜ問題か

glslang (Vulkan の SDK の `glslangValidator` と `glslc`) がコンパイルを止めます。

## どう直すか

名前の綴りを確かめてください。値を取る名前なら `location = 0` のように値を書いてください。
ステージで決まる名前 (`triangles`、`local_size_x`、`early_fragment_tests` など) は、そのステージのファイルにだけ書けます。

## 誤検出だと思ったら

ステージはファイルの拡張子で決まります (`.vert` は頂点シェーダー、`.frag` はフラグメントシェーダーなど)。
ステージを表さない拡張子 (`.glsl`) のファイルでは、ステージで決まる名前を検査しません。
