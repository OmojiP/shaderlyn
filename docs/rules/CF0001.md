# CF0001: 構文エラー

分類: Syntax / 既定の重要度: エラー / 0.3.1 より前の ID: HL0001

## 何を検出するか

HLSL の構文として解釈できない記述です。

## なぜ問題か

シェーダーコンパイラがこの箇所で処理を止めるため、シェーダーをコンパイルできません。

## どう直すか

まずマクロを疑ってください。
この解析はプリプロセス後のコードに対して行われるため、
エラーの位置にマクロが使われている場合、原因はマクロの定義側にあることがあります。

よくある原因は次のとおりです。

- 波括弧・丸括弧の対応が取れていない
- セミコロンの書き忘れ
- マクロの引数の個数が定義と合っていない
- ビットフィールド (`uint a : 8;`) を書いている。Unity はビットフィールドをサポートしません。
  構造体のメンバーでコロンの後ろに書けるのは、セマンティクス名 (`float4 pos : SV_POSITION;`) です。

## 誤検出だと思ったら

次の場合、このツールの制約により誤検出が出ることがあります。

- 別の構成でのみ定義されるマクロを使っている場合。解析は単一の構成で行うため、その構成で未定義のマクロは展開されずに残ります。
- ヘッダを単体で解析した場合。他のヘッダが先に取り込まれる前提のファイルは、単体では成立しません
  (Unity 自身も単体ではコンパイルできません)。

設定で定義済みマクロを追加すると解消する場合があります。
