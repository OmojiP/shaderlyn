# SL1021: レンダーステートの値が不正です

分類: Correctness / 既定の重要度: 警告

## 何を検出するか

`Cull` / `ZWrite` / `ZTest` / `Blend` / `BlendOp` などのレンダーステート命令や、
`Stencil` ブロック内の命令に、受け付けられない値が指定されている箇所です。

## なぜ問題か

Unity は不正な値をエラーにせず、既定値へ倒して動作を続けます。
`Cull Backk` と書いても警告は出ず、カリング設定は既定のままになります。
スペルミスは「設定したつもりが効いていない」という形でしか現れません。

## どう直すか

診断メッセージに指定できる値の一覧が出ています。そこから選んでください。

間違えやすいもの:

| 誤り                  | 正しい値                                        |
| --------------------- | ----------------------------------------------- |
| `Decr` / `Incr`       | `DecrSat` / `DecrWrap` / `IncrSat` / `IncrWrap` |
| `LEqal` / `LessEqual` | `LEqual`                                        |
| `OneMinusSrcAlpa`     | `OneMinusSrcAlpha`                              |

## 誤検出だと思ったら

次の引数は検証していません。

- `Cull [_Cull]` のようなプロパティ参照 (実際の値はマテリアル側で決まります)
- 数値の引数 (`Blend 1 SrcAlpha OneMinusSrcAlpha` の `1` はレンダーターゲット番号です)
- このツールが知らない命令の引数
