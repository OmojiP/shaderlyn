# SG0301: この型には演算子を使用できません

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

Slang のファイルで、組み込みの演算子 (算術・比較・ビット・シフト・`&&` / `||`) か複合代入 (`+=` など) を、形の違う値どうしに使用している状態です。
形とは、ベクトルの長さと、行列の行と列の数です。slangc は組み込みの演算子が見つからない誤り (「no overload for '+' applicable to arguments of type …」) にします。

```slang
float3 a; float4 b; float2x2 m; float2 v;

let r1 = a + b;    // 報告する。長さが違う
a *= b;            // 報告する。複合代入も同じ
let r2 = v * m;    // 報告する。ベクトルと行列 (行列の積は mul(v, m))
let r3 = a + 1.0;  // 正しい。スカラーはどの形とも組める
let r4 = a + b.xyz; // 正しい。長さがそろっている
```

スカラーと 1 成分の値 (`float1`) は、どの形とも組めます。

## 構造体の値への演算子

利用者が演算子を定義していない構造体の値には、組み込みの演算子 (算術・比較・`==`・単項の `-` など) を使用できません。

```slang
struct S { int a; }
let t = s * 2;      // 報告する
bool b = s == s;    // 報告する
```

同じファイル (と取り込んだモジュール) に、その演算子の定義 (`operator*` など) があれば見ません。
`IArithmetic`・`IComparable` などに適合する構造体 (基底を書いた構造体) は、標準ライブラリの演算子が働くので見ません。

## ?: の枝の型

`?:` の 2 つの枝は、同じ型にそろえられなければなりません。形の違うベクトル・行列 (`float3` と `float4`)、違う構造体どうし、構造体と数、
列挙型と、その基になる型でも `int` でもない値 (`int` の列挙型と `uint`・`float`、別の列挙型) は合いません。

```slang
enum E { A, B }
let a = c ? u : E.B;                 // 報告する (u は uint、E は int の列挙型)
let b = c ? float3(1) : float4(1);   // 報告する
let d = c ? E::A : i;                // 正しい (i は int)
let e = c ? float3(1) : 2.0;         // 正しい。スカラーはどの形とも組める
```

微分する関数 (`[Differentiable]`・`[ForwardDifferentiable]`・`[BackwardDifferentiable]`) の中では、ベクトルか行列を条件にした `?:` (成分ごとに選ぶもの) を使用できません (E30055)。
`no_diff` の中も同じです。`select(条件, 真の値, 偽の値)` を使用してください。

```slang
[Differentiable]
float2 f(float2 x)
{
    return (x > float2(0)) ? x : -x;           // 報告する
    // return select(x > float2(0), x, -x);    // 正しい
}
```

## ビット演算とシフトの浮動小数

ビット演算 (`&` `|` `^` `~`) とシフト (`<<` `>>`) には、整数 (と `bool`) の値が必要です。浮動小数 (`float`・`half`・`double` とそのベクトル・行列) の値に使用すると、slangc は誤り (「bitwise/shift operator '|' requires integer operands」) にします。

```slang
float r0 = a | b;   // 報告する (a・b は float)
int r1 = i << a;    // 報告する。シフトの量も整数でなければならない
float r2 = ~a;      // 報告する
uint u = 1;
u |= a;             // 正しい。複合代入の右は左の型 (uint) へ変換される (slangc は警告)
```

次のものも誤りです (E30101・E30013・E30099)。

```slang
struct T { int member; }

int f()
{
    T val;
    val->member = 2;               // -> はポインターにだけ使用できる
    int x;
    return x[0] + sizeof(f);       // スカラーの添字、関数の名前の sizeof
}

struct Dog { int bark; }
struct Cat { float meow; }
bool g(Dog d) { return d is Cat; } // 関わりがない具体的な型どうしの is / as (E30304)
```

`as` の右にはインターフェイスを書けません (E30302)。制約が存在しないジェネリックの型の値に、`is` でインターフェイスを調べることもできません (E30301)。制約のある型 (`<T : IFoo>`・`where optional T : IFoo`) と、具体的な型の値の `is` は通ります。

制約が存在しないジェネリックの型の値どうしの算術の演算子 (`T add<T>(T a, T b) { return a + b; }`) も報告します (E39999)。`<T : IArithmetic>` のような制約を付けてください。

`sizeof(T, L)` の 2 つ目に数か制約が存在しない型の仮引数を書いたもの (データの並べ方の型 `DefaultDataLayout` などを書く。E30086) と、エントリポイントの中の、大きさの違う組み込みの型どうしの `bit_cast<To, From>` (E41202) も報告します。

```slang
interface IFoo { int get(); }
struct Impl : IFoo { int get() { return 1; } }
IFoo f(Impl v) { return v as IFoo; }    // as の右のインターフェイス
bool g<T>(T t) { return t is IFoo; }     // 制約が存在しない T の is
```

エントリポイントから届く関数の中の、インターフェイスの型への `bit_cast<IFoo>(raw)` も報告します (E41204。具体的な型の決まらない型の値は作れません)。

## なぜ問題か

HLSL は長い方を短い方に切り詰めて (警告を報告して) 計算しますが、Slang は形の違う値どうしの組み込みの演算子を持ちません。

## 修正方法

成分を取り出して形をそろえてください (`a + b.xyz`)。行列とベクトルの積は `mul` で書いてください。

## 見ないもの

型が不明な値、構成で型が変わる値、配列は見ません。利用者が演算子を定義したファイル (`operator+` など) では、その演算子を見ません。
`import glsl;` を書いたファイルの、行列を含む `*` は行列の積なので見ません。
