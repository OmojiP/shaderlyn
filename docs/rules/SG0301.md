# SG0301: この型には演算子を使えません

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

Slang のファイルで、組み込みの演算子 (算術・比較・ビット・シフト・`&&` / `||`) か複合代入 (`+=` など) を、形の違う値どうしに使っている状態です。
形とは、ベクトルの長さと、行列の行と列の数です。slangc は組み込みの演算子が見つからない誤り (「no overload for '+' applicable to arguments of type …」) にします。

```slang
float3 a; float4 b; float2x2 m; float2 v;

let r1 = a + b;    // 報告する。長さが違う
a *= b;            // 報告する。複合代入も同じ
let r2 = v * m;    // 報告する。ベクトルと行列 (行列の積は mul(v, m))
let r3 = a + 1.0;  // 正しい。スカラーはどの形とも組める
let r4 = a + b.xyz; // 正しい。長さがそろっている
```

スカラーと 1 成分の値 (`float1`) は、どの形とも組めます。

## なぜ問題か

HLSL は長い方を短い方に切り詰めて (警告を出して) 計算しますが、Slang は形の違う値どうしの組み込みの演算子を持ちません。

## どう直すか

成分を取り出して形をそろえてください (`a + b.xyz`)。行列とベクトルの積は `mul` で書いてください。

## 見ないもの

型の分からない値、構成で型が変わる値、配列は見ません。利用者が演算子を定義したファイル (`operator+` など) では、その演算子を見ません。
`import glsl;` を書いたファイルの、行列を含む `*` は行列の積なので見ません。
