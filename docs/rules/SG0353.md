# SG0353: 取り込んだモジュールに誤りがあります

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

Slang のファイルで `import` したモジュールに、構文の誤りがある状態です。そのモジュールがさらに取り込んだモジュールの誤りも含みます。
slangc はそのモジュールを読めないので、`import` の行もコンパイルの誤り (E39999「import failed due to compilation error」) にします。

```slang
// b.slang
import c;

// c.slang
int a(;                    // 構文の誤り

// main.slang
import b;                  // SG0353: b がたどって取り込んだ c に構文の誤りがある
```

モジュールの中の誤りそのものは、そのモジュールのファイルを解析したときに報告します。ここでは `import` の行に 1 つだけ報告します。
モジュールの意味の誤り (宣言されていない名前など) は見ません。

## なぜ問題か

slangc がコンパイルできません。

## どう直すか

モジュールのファイルを解析して、その構文の誤りを直してください。
