# URP0002: 定数バッファにテクスチャまたはサンプラが含まれています

分類: Correctness / 既定の重要度: 警告

## 何を検出するか

`CBUFFER_START(UnityPerMaterial)` … `CBUFFER_END` の中に、
テクスチャまたはサンプラの宣言が含まれている状態です。

## なぜ問題か

定数バッファに入れられるのは数値だけです。
テクスチャとサンプラは別の種類のリソースであり、定数バッファへは入れられません。

グラフィックス API によって現れ方が違います。
コンパイルエラーになる場合もあれば、
通ってしまったうえで SRP Batcher が無効になる場合もあります。
後者は気づきにくく、URP0001 と同じく「ただ遅くなる」形で残ります。

## どう直すか

テクスチャとサンプラの宣言をバッファの外へ出し、
スケールとオフセット (`_ST`) だけをバッファに残します。

```hlsl
// 誤り
CBUFFER_START(UnityPerMaterial)
    TEXTURE2D(_BaseMap);
    SAMPLER(sampler_BaseMap);
    float4 _BaseMap_ST;
CBUFFER_END

// 正しい
TEXTURE2D(_BaseMap);
SAMPLER(sampler_BaseMap);

CBUFFER_START(UnityPerMaterial)
    float4 _BaseMap_ST;
CBUFFER_END
```

## 誤検出だと思ったら

型名を判別できた宣言についてのみ報告します。
マクロを展開できなかった場合や、ユーザー定義の型の場合は報告しません。

依存関係を解決できていない場合は検査自体を行いません (SL0002 を参照)。
