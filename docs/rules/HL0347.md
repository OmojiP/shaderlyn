# HL0347: enum の値の型が一致しません

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

HLSL 2021 の `enum` の値を、変換できない型との間でやり取りしている式と、使えない演算子を使っている式です。

```hlsl
enum class Mode { A, B };
enum Plain { P0, P1 };

Mode m = 1;              // 報告する。数は enum へ暗黙に変換されない
Mode n = (Mode)1;        // 正しい
Plain p = P0;
Mode q = p;              // 報告する。別の enum の値
int x = Mode::A;         // 報告する。enum class の値は数へ暗黙に変換されない
int y = P0;              // 正しい。ふつうの enum の値は数になる
bool b = m == Mode::B;   // 正しい
bool c = m == 1;         // 報告する
int d = Mode::A + 1;     // 報告する。enum class に + は使えない
int e = (int)m * 2;      // 正しい
p++;                     // 報告する。enum に ++ は使えない
```

見る場所は、変数の初期化・代入・`return`・関数の実引数と、演算子です。

| | enum class | ふつうの enum |
| --- | --- | --- |
| 同じ enum の値を入れる | 使える | 使える |
| 数・別の enum の値を入れる | 型変換が要る | 型変換が要る |
| 数として使う (`int x = v`) | 型変換が要る | 使える |
| `==` / `!=` | 同じ enum どうしだけ | 使える |
| ほかの演算子 (`+` / `<` / `!` / `|=` など) | 使えない | 使える |
| `++` / `--` | 使えない | 使えない |

規則は DXC (`-HV 2021`) で確かめました。
無い列挙子 (`Mode::C`) は [HL0312](HL0312.md) が報告します。

## なぜ問題か

コンパイルに失敗します。

## どう直すか

型変換を書いてください。

```hlsl
Mode m = (Mode)index;
uint bits = (uint)Mode::A;
```

## 環境による違い

HLSL 2021 (汎用の HLSL の既定) だけの構文です。
Unity の環境 (HLSL 2018) では `enum` そのものを [HL0003](HL0003.md) で報告します。

## 誤検出だと思ったら

このルールは次の場合に発火しません。

- 値の型が分からない場合
- 同じ名前の関数が、仮引数の型の違う形で多重定義されている場合 (実引数を見ない)
- `out` / `inout` の仮引数
- 同じ名前の enum が 2 つ以上ある場合 (名前空間が違うなど)
