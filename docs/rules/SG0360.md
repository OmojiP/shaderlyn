# SG0360: 微分の関数の書き方が正しくありません

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

Slang のファイルで、自分で書いた微分の関数 (`[ForwardDerivative]`・`[BackwardDerivative]` などで指した関数) の形が、元の関数から決まる形と合わないか、`no_diff` を正しくない場所で使っている状態です。slangc はコンパイルの誤り (E31149・E31150・E31156・E38031・E38033) にします。

微分の関数の仮引数は、元の関数の仮引数から決まります。

- 前向きの微分 (`[ForwardDerivative]`): 微分する型 (float・half・double とそのベクトル・行列) の仮引数 `T` は `DifferentialPair<T>`。ほかの型 (整数・bool) は `T` のまま
- 後ろ向きの微分 (`[BackwardDerivative]`): 微分する型の仮引数 `T` は `inout DifferentialPair<T>`。ほかの型は `T` のまま。戻り値が微分する型なら、最後にその微分 (`T` か `T.Differential`) の仮引数を足す

```slang
[ForwardDerivative(fwd_f)]
float f(float x) { return x * x; }
DifferentialPair<float> fwd_f(int x) { … }       // 1 番目は DifferentialPair<float>

[BackwardDerivative(bwd_g)]
float g(float x, float y) { return x + y; }
void bwd_g(float dout) { }                        // 3 個 (inout DifferentialPair<float> を 2 つと float) が要る

struct S
{
    [ForwardDerivative(fwd_m)]
    static float m(float x) { return x * x; }
    DifferentialPair<float> fwd_m(DifferentialPair<float> x) { … }  // static のメソッドの微分も static にする
}
```

`no_diff` は関数の呼び出しにだけ書けます。微分しない関数の中では使えません。

```slang
[ForwardDifferentiable]
float m(float x)
{
    float y = no_diff x;                          // 呼び出しでない
    return no_diff f(x);                          // 書ける
}

float n(float x)
{
    return no_diff g(x);                          // n は微分しない関数
}
```

微分する関数・微分の関数 (`[ForwardDerivativeOf]` などを書いたもの、ほかの関数の微分の属性で指したもの)・`[TreatAsDifferentiable]` の関数の中の `no_diff` は通ります。`no_diff float2 pos = …;` (微分しない局所変数の宣言) も通ります。

仮引数の形を見るのは、ジェネリックでなく、同じ名前の関数が 1 つだけで、仮引数の型がどれも組み込みの数の型で、元の関数の仮引数に `out`・`inout`・`no_diff` を書いていないものだけです。
型のメソッド (static でないもの) の微分は、最初に自分の `DifferentialPair` を受け取るので見ません。

## なぜ問題か

slangc は、微分の関数を元の関数から決まる形で呼びます。形が合わなければ、微分の関数として使えません。

## どう直すか

微分の関数の仮引数を、上の形に合わせてください。`no_diff` は、微分しない関数の呼び出しに付けてください。
