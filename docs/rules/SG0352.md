# SG0352: この実引数はコンパイル時の定数でなければなりません

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

Slang のファイルで、テクスチャの `Sample`・`SampleBias`・`SampleLevel`・`SampleCmp`・`SampleCmpLevelZero`・`SampleGrad`・`Load` の offset の実引数か、
ByteAddressBuffer の `LoadAligned`・`Store`・`StoreAligned` の揃え (alignment) の実引数に、定数でない値を使用している状態です。slangc はコンパイルの誤り (E40012) にします。

```slang
Texture2D t;
SamplerState s;
cbuffer U { float2 uv; int2 offset; };

float4 f()
{
    float4 r = t.Sample(s, uv, int2(0, 0));    // コンパイルできる
    r += t.Sample(s, uv, offset);               // 誤り: 定数バッファーのメンバー
    int ii = 0;
    if (uv.x > 0) { ii = 1; }
    r += t.Sample(s, uv, int2(ii, ii));         // 誤り: 代入し直す変数
    for (int j = 0; j < 4; j++)
    {
        r += t.Sample(s, uv, int2(j, 0));       // 誤り: ループの変数
    }
    return r;
}
```

定数でないと言えるのは、定数バッファーのメンバー、関数の外の `static const` でない変数 (uniform)、`[unroll]` / `[ForceUnroll]` が存在しないループの `for` の変数、宣言の後に代入し直す局所変数、エントリポイントの仮引数 (`SV_DispatchThreadID` など) と、それらから作った初期値の局所変数です。
初期値の局所変数を通したものは、slangc と同じく、その初期値の位置で報告します。ほかの関数の仮引数は、関数を展開すれば定数になりうるので見ません。`Gather` の offset は定数でなくても通ります。

`__floatAsInt` の実引数は、浮動小数のリテラル (`1.5`・`-2.0`・`float(1)`) でなければなりません (E30084・E30085)。

## なぜ問題か

offset は命令に埋め込む値なので、コンパイルのときに決まっていなければなりません。

## どう直すか

offset には数のリテラルか `static const` の値を書いてください。ループの変数を使用する場合は、ループに `[ForceUnroll]` を付けてください。
定数でない offset が必要な場合は、座標の側をずらしてください。
