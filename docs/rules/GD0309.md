# GD0309: 書き込めない値です

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

Godot シェーダー言語のファイルで、書き込めない値に代入 (`=`、`+=` など) か `++` / `--` で書き込んでいる状態です。Godot はコンパイルの誤りにします。

```glsl
shader_type spatial;

uniform vec3 tint;
const float K = 1.0;

float f() { return 1.0; }

void fragment() {
    tint.x = 1.0;           // uniform には書き込めない
    K += 1.0;               // const の変数
    TIME = 1.0;             // どの関数でも書き込めない組み込み
    VERTEX = vec3(1.0);     // fragment の中の VERTEX は読み取り専用
    f() = 1.0;              // 関数の呼び出しの結果
    vec3 a = vec3(1.0);
    a.xx = vec2(1.0);       // 同じ成分を 2 度選んだスウィズル
}
```

組み込みの変数が書き込めるかは関数ごとに違います (`spatial` の `VERTEX` は `vertex` 関数では書き込めて、`fragment` 関数では書き込めません)。
表は Godot 4.7.2 のソース (`servers/rendering/shader_types.cpp`) から作りました。`const` の仮引数にも書き込めません。

## なぜ問題か

Godot がシェーダーをコンパイルできず、マテリアルが描画されません。

## どう直すか

値を局所変数に写してから書き換えてください。

## 誤検出だと思ったら

varying への書き込みは、ステージの規則で別に調べます。名前が条件によって違う宣言を指すときは報告しません。
