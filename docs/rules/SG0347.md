# SG0347: 継承と override の書き方が正しくありません

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

Slang のファイルで、次のどれかを書いている状態です。slangc はコンパイルの誤り (E30820・E30853・E30854) にします。

- 2 つ以上の構造体を継承した (`struct Derived : Base1, Base2`)。基底の構造体を、継承の並びの最初に書いていない (`struct D : IFoo, Base`)
- インターフェイスの既定の実装 (本体のあるメソッド) を置き換えるメソッドに、`override` を書いていない
- 基底に、同じ名前と仮引数の数のメソッドが無いメソッドに、`override` を書いた

```slang
interface IFoo
{
    int getVal() { return 0; }     // 既定の実装
}

struct Impl : IFoo
{
    int getVal() { return 1; }     // override が要る
}

struct Impl2 : IFoo
{
    override int getVal(int x) { return x; } // 当たるメソッドが無い
}
```

基底の構造体のある型と、ほかのインターフェイスを継承したインターフェイスの要件は見ません。

## なぜ問題か

slangc がコンパイルできません。構造体が継承できる構造体は 1 つだけです。

## どう直すか

構造体の基底は 1 つにして、継承の並びの最初に書いてください。既定の実装を置き換えるメソッドには `override` を書き、置き換えないメソッドからは外してください。
