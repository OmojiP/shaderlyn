# GL0319: 配列を作る実引数の数が合いません

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

GLSL のファイルで、配列を作る式の実引数の数が正しくない状態です。glslang はコンパイルの誤りにします。

```glsl
#version 450
layout(location = 0) out vec4 color;

void main()
{
    int a[] = int[]();                      // 実引数が無い
    float b[2] = float[2](1.0, 2.0, 3.0);   // 大きさ 2 の配列に 3 つ渡している
    color = vec4(float(a.length()) + b[0]);
}
```

次のものを報告します。

- 実引数の無い式 (`int[]()`)
- 大きさを書いた配列で、実引数の数が大きさと違う式。大きさは 1 次元の整数のリテラルのときだけ見ます

配列を作る式は、デスクトップの 1.20・ES の 3.00 から書けます。それより前のバージョンで書いたものは [GL0001](GL0001.md) が報告します。

## なぜ問題か

配列を作る式には、要素ごとに 1 つずつ実引数を渡します。ベクトルや行列のように成分を平らに並べて渡すことはできません。
glslang (Vulkan の SDK の `glslangValidator` と `glslc`) がコンパイルを止めます。

## どう直すか

要素の数だけ実引数を渡してください。大きさを省いた形 (`float[](1.0, 2.0, 3.0)`) なら、実引数の数が大きさになります。
