# GL0304: 実引数の値が範囲の外です

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

GLSL のファイルで、組み込み関数の定数の実引数が、使える範囲の外にある状態です。glslang はコンパイルの誤りにします。

```glsl
#version 450
layout(location = 0) out vec4 color;
layout(binding = 0) uniform sampler2D tex;
layout(location = 0) in vec2 uv;

void main()
{
    color = textureOffset(tex, uv, ivec2(8, 0));   // テクセルのオフセットは -8 から 7
    color += textureGather(tex, uv, 4);            // 成分の番号は 0 から 3
}
```

今は次のものを検査します (どれも glslang と同じ)。

- テクセルのオフセット: -8 から 7 (glslang の既定の資源の上限 `gl_MinProgramTexelOffset` / `gl_MaxProgramTexelOffset`)
- `textureGather` などの成分の番号: 0、1、2、3 のどれか
- サブグループのクラスターの大きさ: 1 以上の 2 のべき乗

値は、リテラル・`const` の変数・演算子・値の作成 (`ivec2(1, -2)`) を畳んで求めます。求められない値は検査しません。

## なぜ問題か

glslang (Vulkan の SDK の `glslangValidator` と `glslc`) がコンパイルを止めます。

## どう直すか

範囲の中の値にしてください。
