# SL1055: Unity では #pragma once が効きません

分類: Correctness / 既定の重要度: 警告

## 何を検出するか

利用者が書いたファイル (`.shader` のコードブロックと、取り込んだ `.hlsl` など) の `#pragma once` です。

```
Assets/Shaders/Common.hlsl(1:9): warning SL1055: Unity は #pragma once を効かせません。
    このファイルを 2 度取り込むと、中の宣言が再定義のエラーになります。
    #ifndef / #define / #endif のインクルードガードで囲んでください。
```

## なぜ問題か

Unity のシェーダーのプリプロセッサは `#pragma once` を無視します。
同じファイルを 2 か所から取り込むと (別のヘッダ経由で取り込む場合も含む)、関数や構造体が再定義のエラーになります。

Unity 2022.3 / 6.3 / 6.6 (DX12) で、`#pragma once` を書いたファイルを `#include` で 2 度取り込むと
`redefinition of '…'` のエラーになることを確かめました。`#include_with_pragmas` でも同じです。
Unity のマニュアルには「Caching Shader Preprocessor が有効なときに使える」とありますが、実際には効きませんでした。

DXC や FXC で直接コンパイルするとき (Unity 以外の環境) は効くので、このルールは Unity の環境だけで動きます。
Shaderlyn も Unity の環境では `#pragma once` を効かせず、実際と同じく 2 度取り込みます。

## どう直すか

Unity のヘッダと同じく、インクルードガードで囲みます。

```hlsl
#ifndef MY_COMMON_INCLUDED
#define MY_COMMON_INCLUDED

float Helper() { return 1; }

#endif
```
