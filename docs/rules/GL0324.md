# GL0324: 型の引数が正しくありません

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

GLSL のファイルで、型の引数 (`<…>`) の誤りです。

- 協調行列 (`GL_KHR_cooperative_matrix` の `coopmat`) の型の引数は、要素の型・スコープ・行の数・列の数・用途の 5 つです。
  要素の型は 8・16・32 ビットの整数か、16・32 ビットの浮動小数の型 (`bfloat16_t` などを含む) です
- NV の協調行列 (`fcoopmatNV`・`icoopmatNV`・`ucoopmatNV`) の型の引数は、ビットの数・スコープ・行の数・列の数の 4 つです。
  ビットの数は、`fcoopmatNV` なら 16・32・64、ほかは 8・16・32 です
- 協調ベクトル (`coopvecNV`) と長いベクトル (`vector`) の型の引数は、要素の型と要素の数の 2 つで、要素の数は正の数です
- テンソル (`tensorARM`) の型の引数は、要素の型 (bool・整数・浮動小数) と階数 (1 以上) の 2 つです
- 型の引数を取らない型 (`float<16>` など) の型の引数
- 数の引数が定数の整数の式でないもの (const でない変数を書いたものなど)。`constant_id` の特殊化の定数は書けます

```glsl
#version 450 core
#extension GL_KHR_cooperative_matrix : enable
#extension GL_KHR_memory_scope_semantics : enable
#extension GL_EXT_shader_explicit_arithmetic_types : enable
layout(local_size_x = 64) in;

int rows = 8;

coopmat<float16_t, gl_ScopeSubgroup, 8, gl_MatrixUseA> a;          // 型の引数が 4 つ
coopmat<float16_t, gl_ScopeSubgroup, rows, 8, gl_MatrixUseA> b;    // rows は定数でない
float<16> c;                                                        // float は型の引数を取らない

void main() { }
```

協調行列を shared の変数やブロックのメンバーにしたものは、[GL0403](GL0403.md) が報告します。

## なぜ問題か

型の引数が正しくないと型が決まらないので、glslang (Vulkan の SDK の `glslangValidator` と `glslc`) がコンパイルを止めます。

## どう直すか

型の引数を、拡張の仕様どおりの数と値で書いてください。行や列の数を変えたいときは、`const` の変数か、`layout(constant_id = …)` の特殊化の定数にしてください。
