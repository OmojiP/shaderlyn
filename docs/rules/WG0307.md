# WG0307: 添字が正しくありません

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

WGSL のファイルで、定数の添字が範囲の外 (負の数か、大きさ以上の数) か、添字が整数でない状態です。naga はコンパイルの誤りにします。

```wgsl
fn f() -> f32 {
    let a = array<f32, 3>(0.0, 1.0, 2.0);
    var x: array<i32, 1>;
    let y = x[1.0];   // 添字は i32 か u32
    return a[3];      // 大きさは 3
}
```

大きさは、ベクトルと行列は型から、配列は変数の型 (`array<f32, 3>`) か初期値 (`array<f32, 3>(…)`・`array(a, b, c)`) から求めます。

## なぜ問題か

シェーダーモジュールを作れず、パイプラインが作られません。

## どう直すか

添字を範囲の中の整数にしてください。

## 誤検出だと思ったら

大きさを `override` で決める配列と、ポインターを通した添字は検査しません。
