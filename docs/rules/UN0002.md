# UN0002: ファイルの先頭に BOM が重なっています

分類: Usage / 既定の重要度: 警告

Unity の環境の `.shader` だけで出ます。

## 何を検出するか

ファイルの先頭に、UTF-8 の BOM (U+FEFF) が 2 つ以上並んでいる `.shader` です。

```
Assets/Shaders/A.shader(1:1): warning UN0002: ファイルの先頭に BOM (U+FEFF) が 2 個あります。Unity は読めますが、見えない文字が先頭に残っています。重なった BOM を消してください。
```

BOM の付いたファイルを、別のエディタやツールでもう一度 BOM を付けて保存すると、こうなることがあります。

## なぜ問題か

Unity 6.6 で確かめたところ、Unity は BOM が重なった `.shader` を読めます。そのためエラーではなく警告にしています。

| ファイルの先頭 | Unity の結果 |
| --- | --- |
| BOM 1 つ | 読める |
| BOM 2 つ | 読める (この指摘) |
| ゼロ幅スペース (U+200B) / U+200C / U+200D / U+2060 / ノーブレークスペース (U+00A0) | `Parse error: syntax error, unexpected $end, expecting TOK_SHADER` ([SL0001](SL0001.md)) |

ただし、ファイルの先頭に見えない文字が残っています。ほかのツールでは先頭に余分な文字があるものとして扱われ、
構文エラーになることがあります。エディタでは見えないので、原因に気づきにくいです。

## どう直すか

BOM を 1 つにするか、BOM なしの UTF-8 で保存し直してください。

## 誤検出だと思ったら

意図して BOM を重ねることはまずありません。どうしても残す場合は、設定ファイルの `rules:` で `UN0002: none` にしてください。
