# HL0360: 値を返さずに終わる経路があります

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

値を返す関数に、`return` を通らずに末尾へ到達する経路がある状態です。

```hlsl
float3 missing1(float x)
{
    if (x > 0) { return 1; }   // else が無い
}

float3 missing2()
{
}

float3 missing3()
{
    discard;                   // discard は return の代わりにならない
}
```

`discard` はそのピクセルの処理を終わらせますが、
コンパイラは値を返す関数に `return` を求めます。
Unity 6 (DX11) で確かめた実際の挙動です。

正しいものは報告しません。

```hlsl
float3 ok1(float x) { if (x > 0) { return 1; } else { return 2; } }
float3 ok2(float x) { if (x > 0) { return 1; } return 2; }
float3 ok3(int x)   { switch (x) { default: return 1; } }
float3 ok4()        { for (int i = 0; i < 4; i++) { return 1; } }
```

## 判定の仕方

「必ず抜ける」を次のように数えます。

| 形                              | 必ず抜けるか                                     |
| ------------------------------- | ------------------------------------------------ |
| `return`                        | はい                                             |
| ブロック                        | 中のどれか 1 文が必ず抜けるなら、はい            |
| `if` / `else`                   | 両方に `else` があり、両方が必ず抜けるなら、はい |
| ループ (`for` / `while` / `do`) | はい (判定しない)                                |
| 式文・宣言・空文・`discard`     | いいえ                                           |
| それ以外                        | はい                                             |

最後の行が重要です。知らない形は「抜ける」に倒します。
`switch` や構文の誤りから作られた文がこれに当たります。
逆に倒すと、実際には必ず返している関数を誤って指摘することになります。
見落とすほうが安全です。

### 構成ごとに判定する

```hlsl
float4 F(float x)
{
#ifdef _B
    return 1;
#endif
}   // 報告する (!_B のとき)
```

`#ifdef` の両側を 1 本の木に並べて解析しているので、並べた木のまま数えると `_B` の中の `return` が
`!_B` の構成でも効くように見えます。本体の文の出現条件から構成を列挙し、
構成ごとに、その構成に存在する文だけで判定します。関数自身が存在しない構成は数えません。
シンボルを有効にしたバリアントの木は、その木を 1 つの構成として判定します。

## どう直すか

すべての経路で値を返してください。
末尾に `return` を足すのが最も簡単です。

## ループを判定しない理由

コンパイラは境界が定数のループを展開します。
そのため次の形は誤りになりません。

```hlsl
float3 f() { for (int i = 0; i < 4; i++) { return 1; } }
```

展開できるかどうかをここで判定することはできないので、報告しない側に倒しています。

その代わり `float3 f() { while (true) { } }` を見落とします。
コンパイラはこれを誤りとしますが、上の形と区別が付きません。
そう書く人はまずいないため、見落とす側を選んでいます。

## 誤検出だと思ったら

`switch` だけで返している関数は報告しません (上の表のとおりです)。
ループを含む関数も報告しません。
