# WG0302: 実引数の型に合う形がありません

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

WGSL のファイルで、組み込み関数か値の作成に、受け付けない型の実引数を渡している状態です。WGSL は i32・u32・f32 の間を暗黙に変換しません。naga はコンパイルの誤りにします。

```wgsl
fn f(a: u32) -> vec2f {
    let c = cross(vec4(0., 1., 2., 3.), vec4(0., 1., 2., 3.));  // cross は vec3 だけ
    let d = dot(vec4<f32>(), vec3<f32>());                      // 形が違う
    let e = i32(vec2<f32>(0.0));                                // ベクトルはスカラーに変換できない
    let s = select(true, 1, false);                             // 2 つの値の型が違う
    return vec2f(a);                                            // u32 から vec2f は作れない (vec2f(f32(a)))
}
```

今は次のものを検査します。

- スカラーの値の作成 (`i32(…)` など) のベクトル
- ベクトルの値の作成の、要素の型と違う具体的なスカラーとベクトル、成分の数の違う 1 つのベクトル
- 型引数を書いた配列の値の作成 (`array<i32, 1>(1.0)`) の、要素の型に変換できない実引数
- 行列の値の作成の、数でない実引数 (配列など)
- `cross` の 3 成分の浮動小数点数のベクトルでない実引数、`dot`・`distance`・`min`・`max`・`clamp` などの形の違う実引数、浮動小数点数だけの関数 (`sin` など) の整数の実引数
- `select` の、スカラーとベクトルでない値 (構造体・配列・ポインター) と、型の合わない 2 つの値
- `textureSample` などの、テクスチャでない 1 つ目の実引数
- `subgroupAnd`・`subgroupOr`・`subgroupXor` の、i32・u32 でない実引数

## なぜ問題か

シェーダーモジュールを作れず、パイプラインが作られません。

## どう直すか

実引数を、関数が受け付ける型に変換してから渡してください (`vec2f(f32(a))`、`f32(i)`)。

## 誤検出だと思ったら

型が分からない実引数は検査しません。
