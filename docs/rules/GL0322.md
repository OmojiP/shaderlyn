# GL0322: main の定義の形が正しくありません

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

GLSL のファイルで、`main` に仮引数を書いたものと、`main` の戻り値を `void` 以外にしたものです。

```glsl
#version 450
layout(location = 0) out vec4 color;

int main(int mode)      // 仮引数がある・戻り値が int
{
    color = vec4(1.0);
    return 0;
}
```

`void main(void)` は書けます。`main` の定義だけを見ます。

## なぜ問題か

GLSL の `main` は仮引数を取らず、値を返しません。入力と出力は `in` / `out` の変数で受け渡します。
glslang (Vulkan の SDK の `glslangValidator` と `glslc`) がコンパイルを止めます。

## どう直すか

`void main()` と書き、仮引数で受け取っていた値は `in` の変数や `uniform` から読んでください。
返していた値は `out` の変数に書いてください。
