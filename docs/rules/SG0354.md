# SG0354: 空でありうる並びには使えません

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

Slang の可変長の型の仮引数 (`each T`・`let each D : int`) は、空 (0 個) でありえます。空でありうる並びを、空でない並びが要る場所に使っている状態です。
slangc はコンパイルの誤り (E30411・E30412・E30415・E30440) にします。

```slang
int bad<let each D : int>()
{
    return __first(D);                 // 誤り: D は空でありうる
}

int good<let each D : int>() where nonempty(D)
{
    return __first(D);                 // 通る
}

void consume<let each D : int>() where nonempty(D) {}

void forward<let each D : int>()
{
    consume<D>();                      // 誤り: 空でありうる D を渡す
}

int x = good<>();                      // 誤り: 空の型引数
int y = __first(makeTuple());          // 誤り: 空のタプル
int opt<let each D : int>() where optional nonempty(D) { return 0; } // 誤り: nonempty は optional にできない
```

`__trimFirst(D)`・`__trimLast(D)` の結果も、空でありうる並びです。

## なぜ問題か

空の並びには、最初や最後の要素がありません。

## どう直すか

関数に `where nonempty(D)` を書いて、空でない並びだけを受け取るようにしてください。
