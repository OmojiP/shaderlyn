# UN1051: コンパイラの指定についての注意

分類: Usage / 既定の重要度: 情報

## 何を検出するか

エラーにはならないものの、意図と違う結果になりうるコンパイラの指定です。

| 書いたもの | 報告する条件 | 何が起きるか |
| --- | --- | --- |
| `use_dxc d3d11` | Unity 6.6 以降 | 非推奨。DX12 を DXC にする |
| `require inlineraytracing` | Unity 2023.2〜6.3 | インラインのレイトレーシングを使える GPU が無いと判定し、シェーダーをコンパイルしない (6.4 から DXC) |

文は「何が起きているか」から始め、直し方があればそれを続けます。

## どう直すか

- 6.6 以降は `use_dxc dx12` と書きます
- インラインのレイトレーシングは Unity 6.4 以降で使います。2023.2〜6.3 でもこのシェーダーを使うなら、
  `multi_compile _ UNITY_DEVICE_SUPPORTS_INLINE_RAY_TRACING` で分け、キーワードが無効な構成にレイトレーシングを使わない処理を書きます。
  2023.2〜6.3 は、DX12 で RTX 3060 Ti でも `SystemInfo.supportsInlineRayTracing` が False で、このキーワードは有効になりません
  (キーワードが無効な構成が FXC で使われることを確かめました)

## 環境による違い

Unity の環境で、Unity のバージョンが分かるときだけ報告します。
