# SG0355: ラムダ式の書き方が正しくありません

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

Slang のラムダ式 (`(int a) => { … }`) で、次のどれかを書いている状態です。slangc はコンパイルの誤り (E30111・E30112) にします。

- 戻り値の型を書かないラムダ式が、型の違う値 (整数のリテラルと浮動小数のリテラル) を返す
- コピーできない型 (`RayQuery`・`HitObject`) の変数を取り込む

```slang
void test()
{
    let lam1 = (int a) => {
        if (a > 0)
            return 1;              // int
        else
            return 3.0;            // float と食い違う
    };

    RayQuery q;
    let lam2 = (int a) => {
        q.Abort();                 // コピーできない q を取り込んでいる
    };
}
```

取り込んだ値への書き込みは [SG0309](SG0309.md) が報告します。

## なぜ問題か

ラムダ式は、取り込んだ値をコピーして持ちます。戻り値の型は、return の値から 1 つに決めます。

## どう直すか

return の値の型をそろえてください (`return 3;` か `return 1.0;`)。コピーできない型の値は、ラムダ式の仮引数で受け取るか、ラムダ式を使わずに書いてください。
