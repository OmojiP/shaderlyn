# HL0320: include が循環しています

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

`#include` が自分自身を直接または間接に取り込んでいる箇所です。

## なぜ問題か

取り込みが無限に続くため、コンパイルが成立しません。

## どう直すか

インクルードガードを追加してください。

```hlsl
#ifndef MY_HEADER_INCLUDED
#define MY_HEADER_INCLUDED
// ヘッダの内容
#endif
```

ガードがあるのにこの指摘が出る場合、
ガードのマクロ名が他のヘッダと衝突している可能性があります。
