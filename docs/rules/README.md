# ルール

組み込みルールの一覧です。ID を開くと、そのルールが何を報告するか、直し方、報告しない場合の説明があります。
重要度は設定ファイルで変えたり無効にしたりできます（[設定ファイル「rules」](../guide/configuration.md#rules)）。

## 報告しないもの

Unity と外部パッケージのヘッダの中の問題は報告しません。プロジェクトの `Library` (Package Manager が展開した `PackageCache`) と、
Unity Editor に同梱のヘッダがそれに当たり、利用者には直せないためです。
利用者が書いて取り込んだヘッダ (共通の `.hlsl` など) は、取り込むシェーダーの文脈で検査し、ヘッダの位置に報告します。

HLSL コンパイラの[エラーと警告](https://learn.microsoft.com/ja-jp/windows/win32/direct3dhlsl/hlsl-errors-and-warnings)に載っているが報告しないもの

- コンパイルしなければ分からないもの
  - レジスタの割り当て
  - 命令数
  - ループの展開
  - 一時レジスタの本数
- Unity のシェーダーでは使えない構文。
  [HL0003](HL0003.md) で「Unity では使えない」とエラーを報告し、中身は読み飛ばします。
  中身を読んでいないため、そのブロックでは「宣言が見つからない」ことを根拠とする検査も行いません
  ([SL0002](SL0002.md))
  - `class` / `interface` / `enum` / テンプレート / 演算子の多重定義 / ビットフィールド / `#line`
- 解釈しないが、報告もしないもの
  - `[[vk::binding(0, 0)]]` のような二重角括弧の注釈。
    指示するのはレジスタやディスクリプタの割り当てで、上の「コンパイルしなければ分からないもの」に入ります。
    読み飛ばしても見送る検査は 1 つも無いため、報告しません
