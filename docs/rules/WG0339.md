# WG0339: 型が大きすぎます

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

WGSL のファイルで、配列か構造体の大きさが 2147483647 バイトを超えている状態です。naga はコンパイルの誤りにします。

```wgsl
alias LargeArray = array<u32, 1 << 29>;    // 4 × 2^29 = 2^31 バイト
struct TwoArrays {
    arr1: array<u32, 1 << 28>,
    arr2: array<u32, 1 << 28>,             // 合わせて 2^31 バイト
}
```

## なぜ問題か

シェーダーモジュールを作れず、パイプラインが作られません。

## 修正方法

配列を小さくするか、大きさを決めない配列 (`array<u32>`) を `var<storage>` のバッファーに置いてください。
