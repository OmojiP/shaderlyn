# GD0321: switch と break / continue の書き方が正しくありません

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

Godot シェーダー言語のファイルで、`switch` の文の組み立てか、`break` / `continue` の置き場所が正しくない状態です。Godot はコンパイルの誤りにします。

```glsl
shader_type spatial;

void fragment() {
    int a = 1;
    int k = 2;
    switch (1.0) { case 1: break; }   // switch の式は int か uint
    switch (a) {
        case 1u:                       // case の値は switch の式と同じ型
            break;
        case k:                        // 変数は書けない (同じ型の const は書ける)
            break;
        case 1:
        case 1:                        // 同じ値を 2 度
            break;
        default:
            break;
        default:                       // default は 1 つだけ
            break;
    }
    for (int i = 0; i < 2; i++) {
        switch (i) {
            case 0:
                continue;              // ループの中の switch の中にも continue は書けない
        }
    }
    break;                             // ループと switch の外
}
```

`case` の値に書けるのは、`switch` の式と同じ型の整数のリテラル (`int` の場合は `-1` のように符号を付けられる) と、同じ型の `const` の名前だけです。
`(1)` や `1 + 1` のような式は書けません。`case` / `default` は `switch` の波括弧の中にそのまま書きます (`{ }` の中には書けません)。

## なぜ問題か

Godot がシェーダーをコンパイルできず、マテリアルが描画されません。

GLSL と違い、Godot は `switch` の中の `continue` を許しません。

## どう直すか

`case` の値を `switch` の式の型の定数にしてください。`switch` の中でループを続けたいときは、`switch` の後ろに条件を書いて `continue` してください。

## 誤検出だと思ったら

`case` に書いた `const` の値が式で決まるとき (`const int K = 1 + 1;`) は、値の重複を調べません。
