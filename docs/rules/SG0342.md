# SG0342: インターフェイスの適合が循環しています

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

Slang のファイルで、インターフェイスに適合する構造体のフィールドをたどると、同じインターフェイスへ戻る状態です。slangc はコンパイルの誤り (E41002・E41003) にします。

```slang
interface IFoo { float getValue(); }
interface IBar { float process(); }

struct BarImpl : IBar
{
    IFoo foo;                 // IBar → IFoo
    float process() { return foo.getValue(); }
}

struct FooImpl : IFoo
{
    IBar bar;                 // IFoo → IBar → IFoo と戻る
    float getValue() { return bar.process(); }
}
```

フィールドの配列・`Optional<J>`・入れ子の構造体のフィールドもたどります。ポインター (`IFoo*`) と `static` のフィールドは値を持たないので、たどりません。

輪に入る構造体の名前で報告します。インターフェイスの名前では、それに適合する型がどれも輪に入るときだけ報告します (循環しない実装が 1 つでもあれば、slangc もインターフェイスの側は誤りにしません)。

## なぜ問題か

インターフェイスの値 (動的なディスパッチ) は、適合する型の値を格納するための領域を持ちます。適合する型がそのインターフェイスの値を含むと、大きさが決まりません。

## 修正方法

循環するフィールドをポインター (`IFoo*`) にするか、インターフェイス型でない具体的な型にしてください。
