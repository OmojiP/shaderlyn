# GD0002: そのステージでは使えません

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

Godot シェーダー言語のファイルで、そのステージでは使えない組み込み関数を使っている状態です。Godot はコンパイルの誤りにします。

- フラグメントだけの組み込み関数 (`dFdx`・`dFdy`・`fwidth` とその `Coarse` / `Fine`) は、`spatial`・`canvas_item`・`sky` のシェーダーでだけ使えます。
  `particles`・`fog`・`texture_blit` では、どこで使っても誤りです
- フラグメントだけの組み込み関数と、ステージ関数の中でだけ使える組み込み関数 (`canvas_item` の `texture_sdf`・`sdf_to_screen_uv` など) は、
  `vertex` 関数の中と、`vertex` 関数から (ほかの関数を通してでも) 呼ぶ利用者の関数の中では使えません

```glsl
shader_type spatial;

float edge() {
    return fwidth(1.0);      // vertex から呼ばれるので使えない
}

void vertex() {
    float a = dFdx(1.0);     // vertex の中では使えない
    VERTEX.y += edge();
}
```

`vertex` から呼ぶ関数の中では、その関数で最初に使ったものを報告します (Godot と同じ)。

組み込みの変数 (`FRAGCOORD` など) をそのステージ関数に無い所で使ったものは、宣言されていない名前 ([CF0310](CF0310.md)) として報告します。
利用者の関数の中では、どの関数でも使える組み込み (`TIME` など) と定数 (`PI` など) だけが使えます。

## なぜ問題か

Godot がシェーダーをコンパイルできず、マテリアルが描画されません。
微分の関数は、隣り合う画素の値を比べるので、フラグメントの処理でしか意味を持ちません。

## どう直すか

`fragment` 関数 (か `light` 関数) で使ってください。値を頂点の処理で使うなら、別の方法 (頂点の属性、テクスチャ) で渡してください。
