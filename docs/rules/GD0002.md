# GD0002: そのステージでは使用できません

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

Godot シェーダー言語のファイルで、そのステージでは使用できない組み込み関数を使用している状態です。Godot はコンパイルの誤りにします。

- フラグメントだけの組み込み関数 (`dFdx`・`dFdy`・`fwidth` とその `Coarse` / `Fine`) は、`spatial`・`canvas_item`・`sky` のシェーダーでだけ使用できます。
  `particles`・`fog`・`texture_blit` では、どこで使用しても誤りです
- フラグメントだけの組み込み関数と、ステージ関数の中でだけ使用できる組み込み関数 (`canvas_item` の `texture_sdf`・`sdf_to_screen_uv` など) は、
  `vertex` 関数の中と、`vertex` 関数から (ほかの関数を通してでも) 呼ぶ利用者の関数の中では使用できません
- `discard` は `spatial`・`canvas_item` のシェーダーでだけ使用できます。`vertex` 関数の中と、`vertex` 関数から呼ぶ利用者の関数の中では使用できません

```glsl
shader_type spatial;

float edge() {
    return fwidth(1.0);      // vertex から呼ばれるので使用できない
}

void vertex() {
    float a = dFdx(1.0);     // vertex の中では使用できない
    VERTEX.y += edge();
}
```

`vertex` から呼ぶ関数の中では、その関数で最初に使用したものを報告します (Godot と同じ)。

varying も、最初に書き込んだ関数で使用できるところが決まります (Godot は関数を書いた順に解析します)。

- 書き込めるのは `vertex` と `fragment` 関数だけです (`light` や利用者の関数では書き込めません)
- `vertex` で書き込んだものは `fragment` で、`fragment` で書き込んだものは `vertex` で書き換えられません
- `bool` の varying は `fragment` で書き込んでから使用します (`vertex` では書き込めません)
- `vertex` の中と `vertex` から呼ぶ関数の中では、`vertex` で書き込んだ varying だけを使用できます
- out / inout の仮引数には、その関数で書き込める varying だけを渡せます。組み込み関数の out の仮引数には渡せません ([GD0306](GD0306.md))

```glsl
shader_type spatial;

varying float v;

void vertex() {
    v = 1.0;
}

void fragment() {
    v = 2.0;                 // vertex で書き込んだので書き換えられない
}

void light() {
    v = 0.0;                 // light では書き込めない
}
```

組み込みの変数 (`FRAGCOORD` など) をそのステージ関数に存在しない所で使用したものは、宣言されていない名前 ([CF0310](CF0310.md)) として報告します。
利用者の関数の中では、どの関数でも使用できる組み込み (`TIME` など) と定数 (`PI` など) だけが使用できます。

## なぜ問題か

Godot がシェーダーをコンパイルできず、マテリアルが描画されません。
微分の関数は、隣り合う画素の値を比較するので、フラグメントの処理でしか意味を持ちません。`discard` も画素を捨てる命令です。

## 修正方法

`fragment` 関数 (か `light` 関数) で使用してください。値を頂点の処理で使用する場合は、別の方法 (頂点の属性、テクスチャ) で渡してください。
