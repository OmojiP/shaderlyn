# WG0311: 条件が bool ではありません

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

WGSL のファイルで、条件が `bool` でない状態です。WGSL は数を真偽値に変換しません。naga はコンパイルの誤りにします。

```wgsl
fn f(n: u32) {
    if n { }                     // n != 0u と書く
    loop {
        continuing {
            break if 1;          // break if も bool
        }
    }
    _ = select(1, 2, 9001);      // select の 3 つ目も bool
}
const_assert(5);                 // const_assert も bool
```

検査するのは `if`・`while`・`for`・`break if`・`const_assert` の条件と、`select` の 3 つ目の実引数 (`vecN<bool>` も書ける) です。

## なぜ問題か

シェーダーモジュールを作れず、パイプラインが作られません。

## どう直すか

比較式 (`n != 0u`) にしてください。
