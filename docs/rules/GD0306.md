# GD0306: out の実引数に渡せない値です

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

Godot シェーダー言語のファイルで、関数の `out` / `inout` の仮引数に、書き込めない値を渡している状態です。Godot はコンパイルの誤りにします。

```glsl
shader_type spatial;

uniform float u;
const vec3 K = vec3(1.0);

void f(out float x) { x = 1.0; }

void fragment() {
    vec3 v = vec3(1.0);
    float a = 1.0;
    f(u);            // uniform
    f(K.x);          // const の変数のメンバー
    f(TIME);         // 書き込めない組み込み
    f(a + 1.0);      // 式
    f(v[0]);         // ベクトルの添字 (Godot では演算になる)
    float r = modf(1.5, 2.0); // 組み込み関数の out の仮引数も同じ
}
```

渡せるのは、書き込める変数、配列の要素 (`a[0]`)、メンバーとスウィズル (`v.x`、`v.yz`) です。`const` の仮引数 (`void g(const float x)`) には何でも渡せます。

## なぜ問題か

Godot がシェーダーをコンパイルできず、マテリアルが描画されません。

## どう直すか

局所変数を渡し、呼び出しの後で元の場所に写してください。ベクトルの成分は `v.x` のように書けば渡せます。

## 誤検出だと思ったら

同じ名前の関数が多重定義されていて、その位置の仮引数の修飾子が多重定義ごとに違うときは調べません。varying を渡したものは、ステージの規則で別に調べます。
