# WG0322: エントリポイントの形が正しくありません

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

WGSL のファイルで、エントリポイント (`@vertex`・`@fragment`・`@compute` の関数) の入出力の書き方が正しくない状態です。naga はコンパイルの誤りにします。

```wgsl
struct VertexOut {
    @location(0) a: vec4f,            // @builtin(position) が存在しない
}

@vertex
fn vs() -> VertexOut { return VertexOut(vec4f()); }

@fragment
fn fs(input: vec4f) -> vec4f {        // input にも戻り値にも @location か @builtin が存在しない
    return input;
}
```

今は次のものを検査します。

- 仮引数と戻り値 (構造体の場合はそのメンバー) の `@location` か `@builtin`
- 頂点シェーダーの `@builtin(position)` の出力
- `@blend_src`: 構造体のメンバーにだけ書け、`@location(0)` の 2 つのメンバーに `@blend_src(0)` と `@blend_src(1)` を 1 つずつ書く。2 つの型は同じで、ほかのメンバーには `@location` を書けない。頂点シェーダーでは使用できない
- `@builtin(clip_distances)` の型は `array<f32, N>` (N は 8 以下)

## なぜ問題か

シェーダーモジュールを作れず、パイプラインが作られません。

## 修正方法

入出力に `@location(n)` か `@builtin(…)` を書いてください。頂点シェーダーは `@builtin(position) vec4f` を返します。
