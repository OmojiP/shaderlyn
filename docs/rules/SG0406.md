# SG0406: この型はフィールドにできません

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

Slang のファイルで、構造体のフィールドの型に、参照の型 (`Ref<T>`・`RefParam<T>`・`BorrowInParam<T>`・`OutParam<T>`・`BorrowInOutParam<T>`) を書いている状態です。
slangc はコンパイルの誤り (E30030) にします。

```slang
struct A { Ref<float> f; }      // 報告する
struct B { OutParam<float> p; } // 報告する
struct C { float v; }           // 正しい
void g() { Ref<float> local; }  // 正しい。局所変数は参照にできる
```

## なぜ問題か

参照はほかの値を指すだけで、値そのものを持ちません。構造体の値に格納できません。

## 修正方法

値を持たせる場合は、型引数の型 (`float`) をそのままフィールドにしてください。別の場所の値を指したい場合は、ポインター (`float*`) にしてください。
