# HL0348: 構造体の ++ / -- は無視されます

分類: Correctness / 既定の重要度: 警告

## 何を検出するか

FXC でコンパイルされるコードで、構造体の値を `++` / `--` で増減している式です。

```hlsl
struct Counter { float value; };

Counter c = (Counter)0;
c++;          // 報告する。FXC ではエラーにならず、何もしない
c.value++;    // 正しい。メンバーは数値型
```

## なぜ問題か

FXC は構造体の増減をエラーにせず、値を変えないコードにします。書いた計算が行われないまま、シェーダーは動きます。
Unity 2022.3〜6.6 の FXC と、手元の FXC (Windows SDK 10.0.26100) で確かめました。

DXC はどの版でもエラーにします。DXC でもコンパイルされるコードでは、このルールではなく [CF0406](CF0406.md) で報告します。

## どう直すか

メンバーごとに増減してください。

```hlsl
c.value++;
```

## 環境による違い

- Unity: パスが FXC だけでコンパイルされるとき (`#pragma use_dxc` などが無いとき) に報告します。
  DXC でもコンパイルされるなら CF0406 です。
- 汎用の HLSL: `hlsl: compiler: fxc` のときに報告します。DXC (既定) では CF0406 です。
