# SG0350: ループの繰り返しの回数を決められません

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

Slang の、`[Differentiable]`・`[ForwardDifferentiable]`・`[BackwardDifferentiable]` の関数の中に、繰り返しの回数を決められないループを、
`[MaxIters(n)]` も `[ForceUnroll]` も付けずに書いている状態です。slangc はコンパイルの誤り (E30510) にします。

```slang
static const int N = 4;

[Differentiable]
float f(float x)
{
    float s = 0;
    for (int i = 0; i < N; i++) { s += x; }        // コンパイルできる (定数と比較して 1 ずつ増やす)
    for (int i = 0; i < (int)x; i++) { s += x; }   // 誤り (比較対象の値が定数でない)
    int j = 0;
    while (j < 5) { s += x; j++; }                // 誤り (while のループ)
    for (int k = 0; k < 5; k++) { k = (int)x; }    // 誤り (本体で k を書き換える)
    [MaxIters(8)]
    for (int m = 0; m < (int)x; m++) { s += x; }   // コンパイルできる
    return s;
}
```

回数を決められるのは、初期値に定数を代入した変数を条件で定数と比較し (`<`・`<=`・`>`・`>=`・`!=`)、定数ずつ増減する (`++`・`--`・`+=`・`-=`) `for` のうち、
本体でその変数を書き換えないものです。条件が存在しない `for (;;)` と、`break` か `return` で抜けるループは対象外です。

`[ForceUnroll]` のループのうち、展開できないものも報告します (E40020)。微分する関数の中かどうかは問いません。

- `[ForceUnroll(-2)]` のように、回数に負の数を書いたもの
- 条件で変数と比較する値が定数でないもの (uniform・定数バッファーのメンバー・エントリポイントの仮引数・展開しない外側のループの変数・代入し直す局所変数)

```slang
[numthreads(1, 1, 1)]
void main(uniform int n)
{
    [ForceUnroll]
    for (int j = 0; j < n; ++j) { }          // 誤り (n は実行するまで決まらない)
    [ForceUnroll]
    for (int i = 0; i < 4; ++i)
    {
        [ForceUnroll]
        for (int k = 0; k < i; ++k) { }      // コンパイルできる (外側を展開すると i は定数)
    }
}
```

`break`・`return` で抜けるループと、`while` のループは見ません (抜ける条件で回数が決まることがあるため)。

## なぜ問題か

逆向きの微分 (`bwd_diff`) は、ループの回数ぶんの中間の値を覚えておく必要があります。回数が決まらないと、slangc は微分を作れません。

## 修正方法

ループに `[MaxIters(n)]` で最大の回数を書くか、`[ForceUnroll]` で展開してください。
`[ForceUnroll]` のループの回数が決まらない場合は、`[ForceUnroll]` を外すか、比較する値を定数 (`static const` など) にしてください。
