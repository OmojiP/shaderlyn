# SG0101: この宣言はここに書けません

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

Slang のファイルで、その場所には書けない宣言を書いている状態です。slangc はコンパイルの誤り (E30102) にします。

```slang
void f(struct { int a; } x) { }          // 型を書く位置に構造体を定義できない
typealias A = struct S { };              // typealias の右も同じ

struct Container
{
    namespace ns { }                     // 構造体の中に namespace は書けない
    extension S1 { }                     // extension も書けない
}

interface IFoo
{
    enum E { A, B }                      // インターフェイスの中に enum は書けない
}

float4 main() : SV_Target
{
    float helper(int x) { return x; }    // 関数の中に関数は定義できない
    return 0;
}
```

今は次のものを検査します。

- 型を書く位置 (仮引数・戻り値・型引数・`typealias`・`as` / `is`・継承など) の構造体の定義。`struct S { } f()` のような、戻り値の型の構造体も
- 構造体と `extension` の中の `namespace`・`extension`・`interface`・`__constraint`。インターフェイスの中の `namespace`・`extension`・`interface`・`enum`・`struct`
- ファイルの直下の `__init` と `associatedtype`
- 関数の中の関数の定義 (関数の中の局所の構造体のメソッドは書ける)
- `extension` とインターフェイスの中の、`static` でないフィールド (`int x;`・`let x = 0;`。E31400)。インターフェイスの値の要件は `static const` で書く
- `extension` と `__func_extension` のジェネリックの仮引数の既定値 (`extension<T = int> Foo<T>`。E20104)。仮引数は拡張する型から決まる

## なぜ問題か

slangc がコンパイルできません。

## どう直すか

構造体は文として先に宣言し、型を書く位置にはその名前を書いてください。入れ物の中に書けない宣言は、ファイルの直下に移します。
