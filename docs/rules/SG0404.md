# SG0404: この型は資源を包めません

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

Slang のファイルで、`StructuredBuffer` (RW・Append・Consume を含む) か `Optional` の型引数に、資源の型か、資源をメンバーに持つ構造体を書いている状態です。
slangc はコンパイルの誤り (E38204・E30902) にします。

```slang
struct WithTexture { Texture2D t; }

StructuredBuffer<Texture2D> textures;           // 資源の型
StructuredBuffer<WithTexture> items;            // 資源を含む構造体
float f(Optional<SamplerState> s) { return 0; } // Optional も資源を包めない
StructuredBuffer<Texture2D.Handle> handles;     // 資源への参照 (Handle) は包める
```

資源の型は、テクスチャ・サンプラー・バッファー・`ParameterBlock`・`ConstantBuffer` です。構造体の `static` のメンバーは数えません。

## なぜ問題か

GPU のコンパイル先 (SPIR-V・HLSL など) では、資源はバッファーの中身にできません。slangc がコンパイルできません。

## 修正方法

資源への参照 (`Texture2D.Handle`・`DescriptorHandle<T>`) をバッファーに格納するか、資源を別の変数にしてください。

## 誤検出だと思ったら

CPU・CUDA と Metal のコンパイル先は、資源をバッファーに入れられます。設定ファイルの [`slang: target`](../guide/configuration.md#slang) に `cpp` / `cuda` / `ptx` / `metal` を書くと、`StructuredBuffer` の検査をしません (`Optional` は検査します)。
