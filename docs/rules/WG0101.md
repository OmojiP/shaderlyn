# WG0101: この属性はここに書けません

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

WGSL のファイルで、属性をその場所に書けない状態です。naga はコンパイルの誤りにします。

```wgsl
@must_use
@group(0) @binding(0)
var<storage> x: array<u32>;       // @must_use は関数にだけ書ける

struct S {
    @must_use a: i32,             // 構造体のメンバーにも書けない
}

@must_use
fn f(a: i32) { }                  // 値を返さない関数にも書けない

@must_use
@must_use
fn g() -> i32 { return 1; }       // 同じ属性を 2 度は書けない
```

構造体のメンバーに書けるのは `@align`・`@size`・`@location`・`@builtin`・`@interpolate`・`@invariant`・`@blend_src`・`@per_primitive` です。

## なぜ問題か

シェーダーモジュールを作れず、パイプラインが作られません。

## どう直すか

属性を、その属性が書ける場所に移すか、消してください。
