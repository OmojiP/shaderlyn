# SG0318: static const には初期値が要ります

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

Slang のファイルで、関数の外か構造体の `static const` の変数に、初期値を書いていない状態です。slangc はコンパイルの誤り (E31225) にします。

```slang
static const int globalVar;       // 誤り
static const int count = 4;       // 初期値を書けば通る

interface IShape
{
    static const int sides;       // インターフェイスの要件は書ける
}
extern static const int size;     // extern は書ける (リンクのときに決まる)
```

## なぜ問題か

`static const` は定数なので、値が決まらないと使えません。

## どう直すか

初期値を書いてください。アプリケーションから値を入れるなら、`static const` ではなく uniform (`const` を外したもの) にしてください。
