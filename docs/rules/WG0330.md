# WG0330: アドレスを取れない値です

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

WGSL のファイルで、ベクトルの成分のアドレスを `&` で取っている状態です。naga はコンパイルの誤りにします。

```wgsl
fn f() {
    var v: vec2<f32>;
    let p = &v.x;       // ベクトルの成分は指せない
    var m: mat2x2<f32>;
    let q = &m[0][0];   // 行列の列の成分も同じ
    let r = &m[0];      // 行列の列 (ベクトル) は指せる
}
```

## なぜ問題か

WGSL では、ベクトルの 1 つの成分を指すポインターを作れません。シェーダーモジュールを作れず、パイプラインが作られません。

## 修正方法

ベクトル全体のポインター (`&v`) を渡し、使用する側で成分を選んでください。
