# SG0346: class の値は new で作ってください

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

Slang のファイルで、`class` の値を `new` を書かずに作っている状態です。slangc はコンパイルの誤り (E30066) にします。

```slang
class Counter
{
    int v;
    __init(int start) { v = start; }
}

void f(Counter other)
{
    Counter a = Counter(4);        // 誤り
    Counter b = (Counter)4;        // 誤り
    Counter c = new Counter(4);    // new で作る
    Counter d = (Counter)other;    // 同じ class の値の型変換はコンパイルできる
}
```

実引数が存在しないか、数のリテラルだけの作り方を見ます。

## なぜ問題か

`class` は参照の型なので、値は `new` で作ります。

## どう直すか

`new Counter(4)` と書いてください。
