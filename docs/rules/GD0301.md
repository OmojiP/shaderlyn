# GD0301: この型には演算子を使用できません

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

Godot シェーダー言語のファイルで、演算子を使用できない型の組に使用している状態です。Godot はコンパイルの誤りにします。

```glsl
shader_type spatial;

void fragment() {
    float a = 1.0 + 1;          // float と int (暗黙の変換は存在しない)
    vec3 b = vec3(1.0) + vec4(1.0);
    mat4 m = -mat4(1.0);        // 行列の符号は反転できない
    bool c = vec2(1.0) < vec2(2.0); // < はスカラーの数だけ
}
```

型の組は、Godot 4.7.2 のシェーダーのコンパイラ (`ShaderLanguage::_validate_operator`) と同じです。

| 演算子 | 使用できる型の組 |
| --- | --- |
| `+` `-` `*` `/` | 同じ型の数 (スカラー・ベクトル・行列)、スカラーとそれを要素に持つベクトル・行列 (順は問わない)、`*` はベクトルと同じ大きさの行列 (順は問わない) |
| `%` `<<` `>>` | 同じ整数の型、整数のベクトルとその要素の型のスカラー (スカラーは右) |
| `&` `\|` `^` | 同じ整数の型、整数のベクトルとその要素の型のスカラー (順は問わない) |
| `<` `<=` `>` `>=` | 同じ型の `int` / `uint` / `float` のスカラー |
| `==` `!=` | 同じ型 (構造体どうし) |
| `&&` `\|\|` `!` | `bool` |
| 符号の反転、`++` `--` | 整数と浮動小数点数のスカラーとベクトル (`bool` と行列は不可) |
| `+=` など | 左と同じ型か、左のベクトル・行列の要素の型のスカラー。`*=` は左のベクトルと同じ大きさの行列 |
| `?:` | 2 つの枝が同じ型 |

代入 (`=`) と初期化の型の違いは [CF0410](CF0410.md) が報告します。

## なぜ問題か

Godot がシェーダーをコンパイルできず、マテリアルが描画されません。

GLSL と違い、Godot シェーダー言語には暗黙の変換がありません。`int` と `float` を混ぜた式も誤りです。
例外は、関数の呼び出しの実引数に書いた整数のリテラルだけです (`sin(1)`、`vec2(1, 2)`)。

## 修正方法

型をそろえてください。

```glsl
float a = 1.0 + 1.0;
float b = 1.0 + float(i);
mat4 m = mat4(1.0) * -1.0;
bvec2 c = lessThan(vec2(1.0), vec2(2.0));
```

## 誤検出だと思ったら

型が不明な式と、添字を付けない配列の値は検査しません。
