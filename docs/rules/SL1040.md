# SL1040: シェーダー名の構造が不正です

分類: Naming / 既定の重要度: 警告

## 何を検出するか

`Shader "名前"` の名前の構造に問題がある箇所です。

- 名前が空
- 先頭または末尾に空白がある
- `/` の前後に空の階層がある (`A//B`、`/A`、`A/`)
- 階層の先頭または末尾に空白がある (`A/ B`)

## なぜ問題か

シェーダー名は Unity のマテリアルインスペクタで
スラッシュ区切りのメニュー階層になります。
構造が壊れているとメニューに表示されないか、選択できない項目になりますが、
Unity は警告を出しません。

前後の空白は特に厄介で、見た目には正常に見えるのに
`Shader.Find()` での検索が一致しないという形で現れます。

## どう直すか

```shaderlab
Shader "Company/Category/Name"   // 各階層に空白や空要素が無いこと
```

## 誤検出だと思ったら

スラッシュを含まない名前 (`Shader "MyShader"`) は問題としません。
階層に属さないシェーダーはメニューの最上位に表示されるだけで、正常に動作します。
