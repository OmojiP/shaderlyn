# HL0343: コンストラクタの引数が合いません

分類: Correctness / 既定の重要度: エラー

対応する HLSL のコード: 3014 (`ERR_ARGUMENTS_BASETYPE`)

## 何を検出するか

数値型のコンストラクタに渡した値の成分の数が、その型と合っていない状態です。

```hlsl
float3 a = float3(1, 2);        // 3 個必要
float2 b = float2(1, 2, 3);     // 2 個なのに 3 個
float3 c = float3(uv);          // uv は float2。成分が足りない
```

正しいものは報告しません。

```hlsl
float3 a = float3(1, 2, 3);
float3 b = float3(uv, 0);       // 平らにして 3 個
float3 c = float3(1);           // スカラーは全成分へ複製される
float2 d = float2(float4(1,2,3,4));  // 1 つだけ渡す形は切り捨てが許される
```

値を 1 つだけ渡す形だけが例外です。
スカラーの複製と成分の切り捨てが許されるので、足りない場合だけ誤りになります。
2 つ以上渡す場合は、平らにした成分の数がちょうど一致していなければなりません。

## 誤検出だと思ったら

引数の型が 1 つでも分からない場合は報告しません。
数のリテラルは、型が決まらなくても成分 1 つとして数えます。
