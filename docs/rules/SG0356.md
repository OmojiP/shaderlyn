# SG0356: この値のアドレスは取れません

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

Slang のファイルで、アドレスを取れない値に `__getAddress(x)` を使っている状態です。slangc はコンパイルの誤り (E31160) にします。

```slang
StructuredBuffer<float> constants;

void f(int param)
{
    float* p = __getAddress(constants[0]);   // 読むだけの資源の要素
    int* q = __getAddress(param);            // GPU のコンパイル先の、仮引数
    int local = 0;
    int* r = __getAddress(local);            // GPU のコンパイル先の、局所変数
}
```

局所変数と仮引数は、設定ファイルでコンパイル先を GPU のもの ([`slang: target`](../guide/configuration.md#slang) の `spirv` など) にしたときだけ見ます。
CPU と CUDA のコンパイル先では、局所変数のアドレスを取れます。

読むだけの資源の要素の `&s[i]` は [SG0309](SG0309.md) が報告します。

## なぜ問題か

GPU のコンパイル先の局所変数と仮引数は、アドレスを持つメモリーに置かれません。読むだけの資源の要素には、書き込めるポインターを作れません。

## どう直すか

アドレスの要る値は、書ける資源 (RWStructuredBuffer など) か groupshared の変数に置いてください。
