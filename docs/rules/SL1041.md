# SL1041: Pass 名が重複しています

分類: Correctness / 既定の重要度: 警告

## 何を検出するか

同じ SubShader 内に、同じ名前の `Pass` が複数ある箇所です。

## なぜ問題か

`UsePass "シェーダー名/PASS名"` で参照したときに、
どちらの Pass が使われるかは保証されません。

Unity は Pass 名を大文字へ正規化して保持します。
そのため `Forward` と `FORWARD` は Unity にとって同じ名前であり、
このルールも大文字小文字を区別せずに重複を判定します。

## どう直すか

いずれかの Pass の名前を変えてください。
役割が同じ Pass が本当に 2 つ必要な場合は、
`ForwardBase` / `ForwardAdd` のように役割が分かる名前を付けます。

## 誤検出だと思ったら

別々の SubShader にある同名の Pass は報告しません。
品質レベルごとに同じ役割の Pass を用意するのは通常の書き方です。
