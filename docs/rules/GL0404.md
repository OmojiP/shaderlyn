# GL0404: テッセレーションの入力の配列の大きさが違います

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

テッセレーションの制御・評価のシェーダーで、`patch` でない入力の配列 (とブロックの配列) の大きさを、`gl_MaxPatchVertices` でない数にしている状態です。
glslang はコンパイルの誤りにします。

```glsl
#version 450
layout(triangles) in;

layout(location = 0) in vec2 uvs[16];   // 16 ではなく、省くか gl_MaxPatchVertices にする

void main()
{
    gl_Position = vec4(uvs[0], 0.0, 1.0);
}
```

`gl_MaxPatchVertices` は、glslang の既定の資源では 32 です。大きさを数で書いたものだけを検査します。

## なぜ問題か

glslang (Vulkan の SDK の `glslangValidator` と `glslc`) がコンパイルを止めます。
入力のパッチの頂点の数は、描画のときに決まります。シェーダーの中では、大きさを省いて `gl_PatchVerticesIn` で数を知ります。

## どう直すか

大きさを省いてください。

```glsl
layout(location = 0) in vec2 uvs[];
```
