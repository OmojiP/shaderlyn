# SG0344: static でないメンバーは値から使ってください

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

Slang のファイルで、static でないメンバー (メソッドとフィールド) を、値の無い場所から使っている状態です。slangc はコンパイルの誤り (E30100・E30120) にします。

```slang
struct Test
{
    int a;
    void instanceMethod() { }

    static void staticMethod()
    {
        instanceMethod();          // static のメソッドから、static でないメソッド
        int b = this.a;            // static のメソッドの中の this
    }
}

struct Color { int Red; }

void f()
{
    int x = Color.Red;             // 型の名前から、static でないフィールド
}
```

仮引数と局所変数で隠した名前と、同じ名前の関数の外の関数は見ません。extension でメンバーが足されうる型の `Type.member` も見ません。

## なぜ問題か

static のメソッドと型の名前には、メンバーを持つ値 (`this`) がありません。

## どう直すか

メソッドを static にするか、値を受け取ってそこから使ってください (`static void staticMethod(Test t) { t.instanceMethod(); }`)。
定数として使うなら、フィールドを `static const` にしてください。
