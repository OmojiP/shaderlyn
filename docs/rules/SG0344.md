# SG0344: static でないメンバーは値から使用してください

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

Slang のファイルで、static でないメンバー (メソッドとフィールド) を、値が存在しない場所から使用している状態です。slangc はコンパイルの誤り (E30100・E30120) にします。

```slang
struct Test
{
    int a;
    void instanceMethod() { }

    static void staticMethod()
    {
        instanceMethod();          // static のメソッドから、static でないメソッド
        int b = this.a;            // static のメソッドの中の this
    }
}

struct Color { int Red; }

void f()
{
    int x = Color.Red;             // 型の名前から、static でないフィールド
}
```

仮引数と局所変数で隠した名前と、同じ名前の関数の外の関数は見ません。extension や property でメンバーが追加されうる型の `Type.member` も見ません。

## なぜ問題か

static のメソッドと型の名前には、メンバーを持つ値 (`this`) がありません。

## 修正方法

メソッドを static にするか、値を受け取ってそこから使用してください (`static void staticMethod(Test t) { t.instanceMethod(); }`)。
定数として使用する場合は、フィールドを `static const` にしてください。
