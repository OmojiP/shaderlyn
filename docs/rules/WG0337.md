# WG0337: const_assert の条件が成り立ちません

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

WGSL のファイルで、`const_assert` の条件が `false` になる状態です。naga はコンパイルの誤りにします。

```wgsl
const N = 4;
const_assert N > 8;   // false
```

## なぜ問題か

`const_assert` は、前提 (配列の大きさ、定数の範囲など) が崩れたことをコンパイルで知らせるためのものです。シェーダーモジュールは作られません。

## どう直すか

定数の値か、条件を見直してください。
