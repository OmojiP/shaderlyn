# WG0303: この実引数は定数式でなければなりません

分類: Correctness / 既定の重要度: エラー

## 何を検出するか

WGSL のファイルで、定数式でなければならない実引数に、実行時の値 (`let`・`var`・仮引数・`override`) を渡している状態です。naga はコンパイルの誤りにします。

```wgsl
fn f(id: u32) {
    _ = subgroupBroadcast(123, id);  // 値を受け取る呼び出しの番号は定数式
}
```

今は `subgroupBroadcast` と `quadBroadcast` の 2 つ目の実引数を検査します。

## なぜ問題か

シェーダーモジュールを作れず、パイプラインが作られません。

## どう直すか

番号を `const` か数のリテラルにしてください。実行時に決まる番号の呼び出しから値を受け取る場合は、`subgroupShuffle` を使用します。
