HLSL outside Unity can now be analyzed.

- **Environment selection** (`environment`): plain HLSL (DXC, FXC), Unreal Engine and custom engines
- **HLSL 2021** syntax (`template`, `enum class`, operator overloading, methods) and Shader Model 6.1–6.9 intrinsics
- Configurations of valued symbols (`#if QUALITY == 2`)
- For Unity, whether each pass and API compiles with FXC or DXC is determined and checked accordingly
- Analysis results for Unity shaders are the same as in 0.1.1
- **Breaking change** (custom rules): Unity-specific parts moved to the `Shaderlyn.Unity` package ([migration guide](https://github.com/OmojiP/shaderlyn/blob/main/docs/guide/migration-0.2.md), in Japanese)

See the [CHANGELOG](https://github.com/OmojiP/shaderlyn/blob/main/CHANGELOG.md#020---2026-10-14) (in Japanese) for details.

Unity 以外の HLSL の解析に対応。

- **環境の選択** (`environment`): 汎用の HLSL (DXC・FXC)、Unreal Engine、独自のエンジン
- **HLSL 2021** の構文 (`template`・`enum class`・演算子の多重定義・メソッド) と、シェーダーモデル 6.1〜6.9 の組み込み関数
- 値を持つシンボル (`#if QUALITY == 2`) の構成に対応
- Unity で、パスと API ごとに FXC と DXC のどちらでコンパイルされるかを判断して検査
- Unity のシェーダーの解析結果は 0.1.1 と同じ
- **破壊的変更** (自作ルール向け): Unity 固有の部分を `Shaderlyn.Unity` パッケージに分離 ([移行の手順](https://github.com/OmojiP/shaderlyn/blob/main/docs/guide/migration-0.2.md))

詳細は [CHANGELOG](https://github.com/OmojiP/shaderlyn/blob/main/CHANGELOG.md#020---2026-10-14) を参照。
