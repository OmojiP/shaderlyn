GLSL declarations, types and calls are now checked.

- **Semantic checks for GLSL**: declarations, types and calls are checked by the rules shared by C-family languages (CF)
- Hover, go to definition, completion and signature help in the VS Code extension now work for GLSL
- Fixed false reports when analyzing the Unreal Engine 5.5 engine
- **Breaking change**: 33 rules shared by C-family languages were renumbered with the `CF` prefix. Update suppression comments, configuration files and baselines ([migration guide](https://github.com/OmojiP/shaderlyn/blob/main/docs/guide/migration-0.3.1.md), in Japanese)

See the [CHANGELOG](https://github.com/OmojiP/shaderlyn/blob/main/CHANGELOG.md#031---2026-10-29) (in Japanese) for details.

GLSL の宣言・型・呼び出しの検査に対応。

- **GLSL の意味の検査**: C 系の言語に共通のルール (CF) で、宣言・型・呼び出しを検査
- VS Code 拡張の説明・定義へ移動・補完・引数の案内が、GLSL でも使用可能
- Unreal Engine 5.5 のエンジンを解析したときの誤った報告を修正
- **破壊的変更**: C 系の言語に共通のルール 33 個の ID を `CF` で振り直し。抑制コメント・設定ファイル・ベースラインの書き換えが必要 ([移行の手順](https://github.com/OmojiP/shaderlyn/blob/main/docs/guide/migration-0.3.1.md))

詳細は [CHANGELOG](https://github.com/OmojiP/shaderlyn/blob/main/CHANGELOG.md#031---2026-10-29) を参照。
