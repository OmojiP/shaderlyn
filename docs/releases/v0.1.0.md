First public release.

- **Static analysis of Unity ShaderLab and HLSL**: 52 rules (ShaderLab, mapping between Properties and HLSL, HLSL, URP)
- Code split by `#ifdef` is checked in both branches
- **VS Code extension**: diagnostics, hover, completion and go to definition
- **CI**: a GitHub Action (inline PR annotations, Code Scanning) and the output formats `text`, `json`, `sarif` and `github`
- The `.shaderlyn.yaml` configuration file, suppression comments and baselines
- NuGet packages for writing custom rules in C#
- Native AOT single-file executables (5 platforms)

See the [CHANGELOG](https://github.com/OmojiP/shaderlyn/blob/main/CHANGELOG.md#010---2026-10-02) (in Japanese) for details.

最初の公開バージョン。

- **Unity の ShaderLab と HLSL の静的解析**: 52 のルール (ShaderLab、Properties と HLSL の対応、HLSL、URP)
- `#ifdef` で分かれるコードは、どちらの分岐も検査
- **VS Code 拡張**: 指摘・ホバー・補完・定義へ移動
- **CI**: GitHub Action (PR への注釈、Code Scanning)、出力の形式 `text`・`json`・`sarif`・`github`
- 設定ファイル `.shaderlyn.yaml`、抑制コメント、ベースライン
- C# で自作ルールを書くための NuGet パッケージ
- Native AOT の単一の実行ファイル (5 プラットフォーム)

詳細は [CHANGELOG](https://github.com/OmojiP/shaderlyn/blob/main/CHANGELOG.md#010---2026-10-02) を参照。
