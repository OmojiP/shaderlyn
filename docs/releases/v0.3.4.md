Godot shading language, Slang and WGSL support.

- **Godot** (`.gdshader`, `.gdshaderinc`): reports what Godot 4.7.2 rejects, on the same line (GD rules). Supports `res://` includes and the renderer setting
- **Slang** (`.slang`): reports what slangc 2026.19 rejects, on the same line (SG rules). Imported modules are analyzed too
- **WGSL** (`.wgsl`): reports what naga 30 rejects, on the same line (WG rules)
- For every language, no errors are reported for files the compiler accepts
- The VS Code extension provides hover, go to definition and completion for all three languages

See the [CHANGELOG](https://github.com/OmojiP/shaderlyn/blob/main/CHANGELOG.md#034---2026-11-19) (in Japanese) for details.

Godot シェーダー言語・Slang・WGSL に対応。

- **Godot** (`.gdshader`・`.gdshaderinc`): Godot 4.7.2 がエラーにする箇所を、同じ行で報告 (GD のルール)。`res://` の取り込みとレンダラーの設定に対応
- **Slang** (`.slang`): slangc 2026.19 がエラーにする箇所を、同じ行で報告 (SG のルール)。`import` したモジュールも解析
- **WGSL** (`.wgsl`): naga 30 がエラーにする箇所を、同じ行で報告 (WG のルール)
- どの言語も、コンパイラが通すファイルではエラーの報告なし
- VS Code 拡張で、3 つの言語の説明・定義へ移動・補完が使用可能

詳細は [CHANGELOG](https://github.com/OmojiP/shaderlyn/blob/main/CHANGELOG.md#034---2026-11-19) を参照。
