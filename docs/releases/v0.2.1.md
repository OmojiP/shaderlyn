Unreal Engine declarations are generated from C++, and Unity behavior now matches Unity 6.6.

- **`--unreal-generate`**: generates declarations from the engine and project C++ to check Unreal Engine shaders
- Diagnostics in shared headers show which shader and Pass included them
- Handling of `HLSLINCLUDE`, `#include` inside headers and entry points inside cbuffers now matches Unity 6.6
- **Breaking change**: rule IDs were reassigned. Update suppression comments, configuration files and baselines ([migration guide](https://github.com/OmojiP/shaderlyn/blob/main/docs/guide/migration-0.2.1.md), in Japanese)

See the [CHANGELOG](https://github.com/OmojiP/shaderlyn/blob/main/CHANGELOG.md#021---2026-10-16) (in Japanese) for details.

C++ からの Unreal Engine の宣言の作成と、Unity 6.6 の振る舞いへの対応。

- **`--unreal-generate`**: エンジンとプロジェクトの C++ から宣言を作り、Unreal Engine のシェーダーを検査
- 共通のヘッダの中の指摘に、どのシェーダーのどの Pass から取り込んだかを表示
- Unity の `HLSLINCLUDE`・ヘッダの中の `#include`・cbuffer の中のエントリポイントの扱いを、Unity 6.6 の振る舞いに合わせて変更
- **破壊的変更**: ルール ID を付け替え。抑制コメント・設定ファイル・ベースラインの書き換えが必要 ([移行の手順](https://github.com/OmojiP/shaderlyn/blob/main/docs/guide/migration-0.2.1.md))

詳細は [CHANGELOG](https://github.com/OmojiP/shaderlyn/blob/main/CHANGELOG.md#021---2026-10-16) を参照。
