Finer checks for conditional compilation.

- `#if` blocks that split a statement, and macros whose body depends on conditions, are checked per branch. Errors that occur only when separate `#if` blocks are active at the same time are reported too
- `#if` conditions that hold in no configuration are reported
- Completion in the VS Code extension is narrowed to what can be written at the cursor
- Errors missed in 0.1.0 are now reported, so the same code may get more diagnostics. If you use `--error-on` in CI, check locally before updating

See the [CHANGELOG](https://github.com/OmojiP/shaderlyn/blob/main/CHANGELOG.md#011---2026-10-04) (in Japanese) for details.

条件付きコンパイルの検査を細分化。

- 文の途中で分かれる `#if` と、条件で中身が変わるマクロを、分岐ごとに検査。別々の `#if` が同時に有効な場合だけ起きる誤りも報告
- どの構成でも成り立たない `#if` の条件を報告
- VS Code 拡張の補完を、カーソルの位置で書けるものに限定
- 0.1.0 で見逃していた誤りを報告するため、同じコードでも指摘が増える場合あり。CI で `--error-on` を使用している場合は、更新の前に手元での確認を推奨
