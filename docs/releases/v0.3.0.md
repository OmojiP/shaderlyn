Unreal Engine shaders are checked against the engine and project settings.

- **Unreal Engine**: shaders are checked with the shader registrations, permutations and project settings read from C++. Material shaders get declaration checks too
- Configurations that reach `#error` are reported (HL0009, UN0103)
- **GLSL** syntax errors are reported (the `glsl` environment)
- The CLI also uses the nearest configuration file for each file. Rule IDs in the configuration file can be regular expressions
- An API for configurations in custom rules, and a Skill for AI coding agents
- **Breaking change** (custom rules and custom environments): type names and namespaces of syntax trees and environments changed. No changes are needed if you only use the tool ([migration guide](https://github.com/OmojiP/shaderlyn/blob/main/docs/guide/migration-0.3.0.md), in Japanese)

See the [CHANGELOG](https://github.com/OmojiP/shaderlyn/blob/main/CHANGELOG.md#030---2026-10-25) (in Japanese) for details.

エンジンとプロジェクトの設定に沿った、Unreal Engine のシェーダーの検査に対応。

- **Unreal Engine**: C++ から取得したシェーダーの登録・パーミュテーション・プロジェクトの設定で検査。マテリアルのシェーダーも宣言を検査
- `#error` に到達する構成を報告 (HL0009・UN0103)
- **GLSL** の構文の誤りを報告 (環境 `glsl`)
- CLI も、ファイルごとに一番近い設定ファイルを使用。設定ファイルでルール ID を正規表現で指定可能
- 自作ルール向けの、構成を扱う API と、AI のコーディングエージェント向けの Skill を追加
- **破壊的変更** (自作ルール・独自の環境向け): 構文木と環境の型名・名前空間を変更。ツールとして使用するだけなら書き換えは不要 ([移行の手順](https://github.com/OmojiP/shaderlyn/blob/main/docs/guide/migration-0.3.0.md))

詳細は [CHANGELOG](https://github.com/OmojiP/shaderlyn/blob/main/CHANGELOG.md#030---2026-10-25) を参照。
