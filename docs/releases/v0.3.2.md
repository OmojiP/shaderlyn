Unity projects can be analyzed on machines without the Unity Editor.

- **`--unity-generate`**: writes out the files needed for analysis, so projects can be analyzed on GitHub-hosted runners without `Library` or the Unity Editor
- Fixed false errors in the URP built-in shaders of Unity 6.3.26f1 and later
- Fixed bugs in macro token pasting (`##`)

See the [CHANGELOG](https://github.com/OmojiP/shaderlyn/blob/main/CHANGELOG.md#032---2026-11-02) (in Japanese) for details.

---

Unity Editor が存在しないマシンでも、Unity のプロジェクトを解析可能。

- **`--unity-generate`**: 解析に使用するファイルを書き出し。`Library` と Unity Editor が存在しない GitHub のホストランナーでも解析可能
- Unity 6.3.26f1 以降の URP の標準のシェーダーに出ていた、誤ったエラーを修正
- マクロの `##` (連結) の不具合を修正

詳細は [CHANGELOG](https://github.com/OmojiP/shaderlyn/blob/main/CHANGELOG.md#032---2026-11-02) を参照。
