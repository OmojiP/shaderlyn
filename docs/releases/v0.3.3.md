GLSL results now match glslang 16.6.0.

- **GLSL-specific rules (GL)**: reports what glslang rejects, on the same line
- Among glslang's test shaders, no errors are reported for files glslang accepts
- Keywords, implicit conversions and available functions follow `#version` and the enabled extensions, as in glslang
- The `glsl:` section in the configuration file (compilation target, `auto-map-locations` and so on)
- UN0301 (no shader stage specified) is now an error, and SL1030 is now info

See the [CHANGELOG](https://github.com/OmojiP/shaderlyn/blob/main/CHANGELOG.md#033---2026-11-05) (in Japanese) for details.

GLSL の検査結果を glslang 16.6.0 に準拠。

- **GLSL 固有のルール (GL)** を追加。glslang がエラーにする箇所を、同じ行で報告
- glslang のテスト用シェーダーのうち、glslang がエラーにしないファイルでは、Shaderlyn もエラーの報告なし
- キーワード・暗黙の変換・使用可能な関数を、glslang と同じく `#version` と有効にした拡張で判断
- 設定ファイルの `glsl:` の節 (コンパイル先、`auto-map-locations` など) を追加
- UN0301 (シェーダーステージの指定が存在しない) をエラーに、SL1030 を情報に変更

詳細は [CHANGELOG](https://github.com/OmojiP/shaderlyn/blob/main/CHANGELOG.md#033---2026-11-05) を参照。
